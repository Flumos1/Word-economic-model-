Что подтверждено

Первая реальная оценка протокола v5 по паре T1 h=1:

  • C1 PASS — относительная потеря RMSE/CRPS 0.9465 / 0.9670 на окне W1 при пороге 0.97.
  • C2 PASS — скорректированные p-значения Romano–Wolf 0.0457 (W1 RMSE) и 0.0084 (W2 CRPS), FWER 0.10.
  • C5 PASS — кандидат не хуже компаратора на вторичных фактах.

Что НЕ подтверждено

  • C4 — FAIL по RMSE. Относительная потеря 1.0775 в рецессионных месяцах W1_EXT (порог ≤ 1.00), условный Giacomini–White отвергает в пользу компаратора (p ≈ 5.3e-07). По CRPS C4 PASS (0.9303), но C4 требует прохождения по каждому loss.
  • C6 — нет. В forward-журнале 0 из 12 разрешённых прогнозов; различных целевых периодов 1 из 4. Гейт C6 физически не может быть пройден до накопления журнала.
  • SHADOW_TEST, LIMITED_DEPLOYMENT и ACTIVE для этого кандидата не достигнуты.

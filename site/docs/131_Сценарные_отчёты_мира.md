## 1. Метод

Сценарии считаются на реальном MRIO FIGARO 2019 (50 стран: 49 + ROW, 64 отрасли, `Z` 3200×3200,
USD_mn; данные — `data/mrio/figaro/figaro_2019`, вне git). Используется статическая модель
Леонтьева `x = (I − A)⁻¹ (y + fda)`, `A = Z diag(x)⁻¹`; сценарий меняет конечный спрос
(энергетический/импортный шок) или издержки импорта (FX pass-through), после чего сравнивается
новое равновесие с базовым. Это **сравнительная статика**: без цен, замещения, динамики и
балансового приспособления; числа — иллюстрация структуры связей, а не прогноз.

Допущения: коэффициенты `A` фиксированы; шок энергии — снижение конечного спроса на 5% в
CPA_B/CPA_C19/CPA_D35; импортный шок — рост импортных издержек на 10/20% с пропорциональным
сокращением конечного спроса; FX — pass-through 10/20% в импортные издержки для выбранной страны.
Базовая проверка: `Σx` 169,60 трлн USD, `ρ(A)=0,5750`, балансы сходятся (≤6e-9).

## 3. SFC-проверки сценариев (task-29)

К каждому сценарному отчёту добавлен блок `sfc` (`docs/133`, модуль
[src/amfe/world/sfc_io.py](../src/amfe/world/sfc_io.py)): страновые счета с тождеством
`S = I + CA`, `ΣCA = 0` и шагом потоки–запасы `opening + transactions + revaluation = closing`.
При `--sfc` блок попадает в JSON каждого сценария, в Markdown-отчёт, в `report_index.json`
(`sfc`, `checks.all_sfc_pass`) и в дашборд (HTML/MD).

Реальный прогон (`--sfc --sfc-investment-share 0.2`, FIGARO 2019):
блок одинаков для всех пяти сценариев, потому что сценарий меняет выпуск, а не счётные
тождества (это и есть проверка согласованности сценария с потоками–запасами):

| Показатель | Значение (USD_mn) |
|---|---:|
| ВВП (Σva+Σvaa) | **85 733 601.60** |
| Конечный спрос (Σy+Σfda) | **85 733 601.60** |
| Сбережения S (доля инвестиций 0.2) | **17 146 720.32** |
| Инвестиции I | **17 146 720.32** |
| CA мира (ΣCA) | **−0.0** |
| NFA (закрывающие, открывающие = 0) | **−0.0** |

Проверки: невязка двух сверок CA (**EX_int−IM_int** против **GDP−FD**) = **5.6e-09**;
`ΣGDP − ΣFD` = **1.5e-08**; `ΣCA` = **−8.6e-09**; max `|S − I − CA|` = **4.7e-09**;
SFC-шаг: невязки тождества и чистой стоимости = **0.0**, `pass = true`;
`checks.all_sfc_pass = true` во всех пяти сценариях. Пример `S = I + CA`
(доля инвестиций 0.2): DE: 818 547.17 − 705 397.49 = **+113 149.67** = CA; US:
4 149 598.52 − 4 214 361.28 = **−64 762.76** = CA; CN: 2 608 080.50 − 2 931 531.35 =
**−323 450.85** = CA.

CA (счёт текущих операций по IO-таблице): топ-профицит — SA +193 056.59; RU +187 356.24;
ROW +163 033.43; UK +115 420.63; DE +113 149.67. Топ-дефицит — CN −323 450.85;
MX −121 559.46; FR −91 583.92; IN −75 942.21; US −64 762.76. Интерпретация: SA/RU/DE —
чистые поставщики промежуточной продукции, CN/MX/FR/IN/US — чистые потребители.
Цифры S/I зависят от доли инвестиций (0.2 — конвенция отчёта); CA и все тождества от неё
не зависят.

**Ограничения SFC-блока (обязательно).** Поглощение принято как `A_c = FD_c`: датасет хранит
конечный спрос по блоку страны-производителя, поэтому назначение конечных товаров не
идентифицируется, и `CA` — это баланс **промежуточной** торговли, а **не официальный BoP**
(нет конечных товаров/услуг, факторных доходов и трансфертов). S/I не идентифицированы
отдельно (нет компонент конечного спроса) — тождество верно для любой доли, доля задаёт только
величины. NFA — единственный запас, открывающие позиции нулевые, переоценка экзогенна; блок
относится к базовой таблице одного года (2019), динамики NFA нет. Знаки и величины нельзя
читать как платёжный баланс или прогноз; ROW остаётся агрегатом. Pipeline-прогоны
`--sfc` фиксируют блок при доле инвестиций 0 (`S = CA`, `I = 0`), отчётный слой пересчитывает
его при 0.2 для сопоставимости — CA, `ΣCA` и невязки при этом идентичны.

## 4. Ограничения (обязательно)

- Сравнительная статика: нет цен, замещения, динамики, ожиданий и балансового SFC-приспособления;
  FX/импортные шоки — механический pass-through, а не поведенческая реакция.
- `A` фиксирована на 2019; реальные коэффициенты меняются; ROW — агрегат, не экономика.
- Абсолютные числа зависят от курса EUR→USD (World Bank 2019) и от агрегации 64→64 (без
  дополнительной агрегации); топ-списки чувствительны к масштабу страны.
- Это не прогноз и не допуск: статус `RESEARCH_ONLY`; сценарии нельзя публиковать как ожидаемые
  потери/выгоды без OOS-валидации и ценового слоя.
- Сырые таблицы не публикуются; в отчётах только агрегаты.

## 5. Воспроизведение

```powershell
# pipeline-уровень: сценарий + SFC-блок в отчёте пайплайна
python tools/world_pipeline.py --root data/mrio/figaro --dataset figaro_2019 `
  --build --solve --sfc --scenario energy --share 0.05 `
  --energy-industries CPA_B,CPA_C19,CPA_D35 --out build/world/pipeline/energy
python tools/world_pipeline.py --root data/mrio/figaro --dataset figaro_2019 `
  --build --solve --sfc --scenario import --share 0.20 --out build/world/pipeline/import20
python tools/world_pipeline.py --root data/mrio/figaro --dataset figaro_2019 `
  --build --solve --sfc --scenario fx --country DE --pass-through 0.20 `
  --out build/world/pipeline/fx_de20

# отчётный уровень: 5 сценариев + SFC-блок в JSON/MD/индексе/дашборде
python tools/world_reports.py --root data/mrio/figaro --dataset figaro_2019 `
  --energy-industries CPA_B,CPA_C19,CPA_D35 --fx-countries DE `
  --sfc --sfc-investment-share 0.2 --out build/world

python tests/test_world_reports.py    # 21 тест (6 — SFC)
python tests/test_sfc_io.py           # 12 тестов
```

Отчётный индекс — `build/world/report_index.json`; дашборд — `build/world/dashboard.html`
(статический, без JS/внешних URL).

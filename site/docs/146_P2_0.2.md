## 5a. Релизный манифест

`build/p2_release/p2_release_0_2.json`: schema `AMFE-P2-RELEASE/1.1.0`, release `P2 0.2`,
version `0.2`, status `RESEARCH_RELEASE`, **admission=false**, inputs 17 (SHA-256/bytes каждого
входа: протокол покрытия OECD, сценарный индекс, pipeline-отчёт, D1-отчёт и манифест данных,
docs/145, docs/146, docs/130, инструменты, тесты). Сборка детерминирована: при фиксированных `--generated-at/--date/--git-commit` повторный
прогон даёт **байт-идентичный** манифест (SHA-256 записан в самом манифесте и зависит
от хэшей входов: после изменения любого входа, включая этот документ, он меняется —
детерминизм проверяется на фиксированной ревизии дерева).
Команда: `python tools/p2_release.py --release 0.2 --data-root "F:\Мировая экономика модель\data\mrio"`.
Старый манифест P2 0.1 (`--release 0.1`, schema `AMFE-P2-RELEASE/1.0.0`) не изменён.

## 8. Ограничения и что не сошлось

- **Сравнительная статика**: нет цен, замещения, динамики и обратных связей; FX и энергетические
  шоки — механические возмущения коэффициентов/спроса, а не прогноз (docs/127, docs/131).
- **Остатки идентичностей** ненулевые в допуске 0,1% (балансировка исходной OECD-таблицы):
  baseline material residual 26 471,49 USD млн на выпуске 168 481 393 (≈0,00016); SFC
  S−(I+CA) max 93,56 USD млн.
- **Прогон только на 2019**: 2015/2022 в этом релизе не прогонялись (сценарии на 2019 заняли
  ~7,4 мин + загрузка/факторизация; время-бокс). Это ограничение релиза, не результат.
- **SFC-допущения** (адресность конечного спроса, разделение C/I) — см. §4; SFC — бухгалтерский
  блок, не поведенческая модель.
- **D4 RESEARCH_ONLY**: динамика вне допуска; возврат в допуск не планируется в P2 0.2.
- **admission=false**: релиз не является допуском; ни один кандидат не допущен, статусы выше
  CANDIDATE/SHADOW_TEST не присваиваются.
- Данные OECD сторонние: в git не коммитятся; в манифесте только SHA-256, счётчики и агрегаты.

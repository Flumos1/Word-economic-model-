# 150. Агентный симулятор: спецификация и минимальный ABM с SFC

Версия 1.0.0 · 2026-11-16. Волна 21, трек E (план — [docs/145](145_AMFE_2.0_план.md)). Задача:
`task-42`. Код — [src/amfe/agentic/simulator.py](../src/amfe/agentic/simulator.py),
тесты — [tests/test_agentic.py](../tests/test_agentic.py).

Это **спецификация агентного слоя и минимальный прототип**, а не модель реальной экономики. Прототип
проверяет два свойства, которые обязаны выполняться до любых содержательных выводов: **двойная
запись** (сумма операций = 0) и **согласованность с SFC-счетами** (в закрытой экономике
`S = I + CA`, `CA = 0`). Симулятор не калиброван на данных, не прогнозирует и не является допуском
или инвестиционной рекомендацией.

## 1. Место в архитектуре 2.0

Агентный слой — уровень **L5** ([docs/145](145_AMFE_2.0_план.md) §1): он получает цены/издержки от
L3 (MRIO/SFC) и L4 (рынки), а его агрегаты должны сходиться со счетами системы. Контракт интеграции
(ворота G2): «агентные операции → счета» — сумма операций агентов = изменение счетов, ни одна
операция не создаёт и не уничтожает финансовые требования без парной записи.

## 2. Типы агентов и их решения

| Агент | Решения | В прототипе |
|---|---|---|
| Домохозяйства (N) | потребление/сбережение, предложение труда, налоги, спрос на деньги | да: MPC-потребление, сбережение = доход − потребление − налог, труд 1 ед./домохозяйство |
| Фирмы (M) | производство, найм, закупки промежуточных товаров, цены, инвестиции | да: линейная технология `y = a·L`, закупки у соседней фирмы по кругу, цена = наценка × удельные издержки, инвестиции из выручки |
| Банк | кредит, ликвидность, ставки, капитал | да: кредит по требованию с лимитом, ставки по кредитам/депозитам, прибыль банка |
| Государство | налоги, расходы, трансферты, заимствование | да: подоходный налог, госзакупки, пособия по безработице, займ у банка |
| Инвесторы | портфель, риск/доходность, переток капитала | **нет** (в прототипе сбережения — депозиты; фондовый рынок вне scope) |
| ИИ-агенты | доля закупок, исполняемая ИИ; правила доверия и разрешений | **частично**: параметр «доля ИИ-агентов в закупках» α; поведение — снижение стоимости закупок (эффективность), без отдельного бюджета/доверия |

Режимы (постановка):

| Режим | Что означает | В прототипе |
|---|---|---|
| Традиционный | все решения — люди/фирмы по обычным правилам; ИИ-агентов нет | да (`α = 0`) |
| Смешанный | часть закупок/рутины делегирована ИИ-агентам, ответственность — у человека | да (`0 < α < 1`) |
| Агентный | ИИ-агенты ведут значимую долю операций в рамках лимитов | только как предельный случай α (`α ≥ 0.5` в демо) |

Правила доверия/разрешений (спека, в прототипе не реализованы как отдельный слой):

1. Каждая операция ИИ-агента имеет владельца-человека/фирму и проходит те же лимиты (кредит,
   ликвидность), что и «ручная» операция; превышение лимита — fail-closed.
2. ИИ-агент не может менять архитектуру/параметры модели; он исполняет операции в рамках
   предрегистрированных правил (аналог «параметры автоматически, архитектура — с человеком»).
3. Полный аудит: каждая операция — запись в ledger с меткой, суммы и SHA-256 журнала операций.
4. Запрет операций вне SFC: если операция не раскладывается в двойную запись — она отклоняется.

## 3. Связь с 17 блоками предметной модели и SFC

| Блок (docs/02 §3) | В ABM | Комментарий |
|---|---|---|
| 1. Производство | да | линейная технология, труд, промежуточные закупки |
| 2. Распределение | да | wages, доходы домохозяйств |
| 3. Перераспределение | да | налоги и пособия |
| 4. Совокупный спрос | да | потребление + госзакупки + инвестиции |
| 5. Инвестиции | да (упрощённо) | собственные инвестиции из выручки, капитал в memo-счёте |
| 6. Банки и кредит | да | кредит по требованию, лимит, ставки |
| 12. Госфинансы | да (упрощённо) | налог, расходы, пособия, займ |
| 7. Межотраслевые связи | частично | закупки по кругу, без полной MRIO-матрицы |
| 8–11, 13–17 | нет | логистика, энергия, торговля/валюты, ЦБ, активы, ожидания, институты, геополитика, наука |

SFC-связь: симулятор — «нижний» подслой L5, который должен сойтись с L3. Инварианты прототипа
(см. §5) — это те же проверки, которые позднее будут применяться к интеграции «агентные операции →
счета мира».

## 4. API

```python
from amfe.agentic.simulator import (
    Parameters, AgenticSimulator, run_demo, format_demo,
    ParameterError, LedgerError, SFCError, ConvergenceError,
)

params = Parameters(periods=16, seed=20261116, ai_share_start=0.0, ai_share_end=0.5,
                    shock_period=8, shock_employment_drop=0.15)
result = AgenticSimulator(params).run()   # SimulationResult
period = result.periods[-1]               # PeriodResult: агрегаты и checks
demo = run_demo()                         # 3 прогона: baseline / income_shock / income_shock_ai
print(format_demo(demo))
result.as_dict()                          # JSON-сериализуемое представление
```

CLI: `python -m amfe.agentic.simulator` (печатает демо-отчёт; `PYTHONPATH=src`).

Параметры (`Parameters`): `n_households`, `n_firms`, `periods`, `seed`, `wage`, `labour_supply`,
`productivity`, `input_coeff`, `markup`, `tax_rate`, `benefit`, `gov_share`, `deposit_rate`,
`loan_rate`, `invest_rate`, `repay_rate`, `mpc_min/max`, `ai_share_start/end`, `ai_switch_start/end`,
`shock_period`, `shock_employment_drop`, `damping`, `tolerance`, `max_iterations`,
`max_loan_per_firm`. Все значения валидируются; невалидные — `ParameterError`.

## 5. Инварианты и fail-closed

| Инвариант | Проверка | Исключение |
|---|---|---|
| Двойная запись | каждая транзакция: сумма postings = 0 | `LedgerError` |
| Финансовая консервация | сумма финансовых stock-счетов = 0 после периода | `SFCError` |
| SFC закрытой экономики | `S = I + CA` (`CA = 0`), по потоковым saving-счетам и Δкапитала | `SFCError` |
| Тождество банка | чистые активы банка = накопленная прибыль (проценты) | `SFCError` |
| Сходимость цен | итерация `p = markup·unit_cost(p)` с демпфированием, ≤ `max_iterations` | `ConvergenceError` |
| Кредитный лимит | кредит фирмы ≤ `max_loan_per_firm` | `SFCError` |
| Положительные цены | цена > 0 на каждой итерации | `ConvergenceError` |
| Закрытая экономика | нет счетов `ext.*` | `SFCError` |

Внешних секторов нет: `CA = 0` по построению; экспорт/импорт/валюты — вне scope прототипа.

## 6. Демо: шок занятости/дохода + доля ИИ-агентов 0 → 50%

Сценарий: 20 домохозяйств, 5 фирм, 16 периодов, seed 20261116; шок занятости в периоде 8
(спрос на труд −15%); ИИ-доля закупок растёт линейно 0 → 0.5 с периода 4 по период 12. Все прогоны
проходят проверки §5 (двойная запись, SFC, тождество банка, сходимость).

| Показатель | baseline (t=15) | шок дохода (t=15) | шок + ИИ 0→50% (t=15) |
|---|---|---|---|
| Занятость (из 20) | 20 | 15 | 15 |
| Безработица | 0% | 25% | 25% |
| Потребление, ден. ед. | 16.00 | 13.40 | 13.40 |
| Индекс цен | 1.1685 | 1.1711 | **1.1208** |
| Saving = Investment | 4.962 | 4.353 | 4.210 |
| Операций в ledger | 1 070 | 1 086 | 1 086 |

Динамика ИИ-сценария: α = 0 (t≤4) → 0.25 (t=8) → 0.5 (t≥12); индекс цен падает с 1.1604 (t=0) до
1.1208 (t=15) — эффект канала закупок: ниже промежуточные издержки → ниже удельные издержки и цены.
Шок занятости снижает занятость и потребление, но не цены (спрос падает слабее издержек в этой
калибровке). Проверка SFC выполняется в каждом периоде: `saving == investment` (например, 4.353 =
4.353 для шокового прогона), финансовые счета дают ровно нуль.

**Как читать:** это механическая иллюстрация согласованности и направлений, а не оценка эффекта ИИ.
Знаки эффектов зависят от калибровки; никаких «точных» выводов из демо не следует.

## 7. Ограничения (честно)

1. **Не доказывает поведение реальной экономики.** Прототип не калиброван, не проверен на данных,
   не прошёл внешнюю валидацию; числа — условные.
2. **Нет поведенческой модели ИИ.** α — экзогенная доля закупок с постоянным эффектом снижения
   издержек; нет обучения, стратегий, доверия, делегирования, конфликтов целей.
3. **Нет инвесторов/портфелей**, фондового рынка, валют, внешнего сектора и ЦБ.
4. **Упрощённая реальная сторона:** капитал в memo-счёте, нет амортизации, запасов и
   полноценного рынка капитальных товаров; фирмы производят по ожидаемому спросу.
5. **Нет межотраслевой MRIO-матрицы:** закупки по кругу с одним промежуточным коэффициентом;
   интеграция с L3 — следующий шаг.
6. **Ожидания адаптивные и простые** (ожидаемый спрос = прошлые продажи); нет обучения,
   рациональных ожиданий и гетерогенных стратегий.
7. **Демо — не сценарий политики:** шок и ИИ-доля заданы вручную; причинных выводов нет.
8. Цены — индекс удельных издержек с наценкой; нет денежной инфляции, ставки ЦБ и инфляционных
   ожиданий.

## 8. План калибровки на реальных данных (следующие шаги)

1. **Источники:** SFC/MRIO L3 (FIGARO/WIOD/OECD) — доли труда/капитала, промежуточные коэффициенты,
   госдоля; ряд наблюдений (CPI, занятость, потребление) для моментных условий.
2. **Калибровка:** моментный мэтчинг (доли дохода, норма сбережения, наценки, кредитная нагрузка),
   байесовская/имитационная оценка; параметры — только с предрегистрацией критериев.
3. **Валидация:** walk-forward/OOS на агрегатах; сравнение с наивными моделями; проверка
   устойчивости к шокам параметров (sensitivity grid).
4. **Интеграция:** агентные операции → счета мира; проверка `S = I + CA` на уровне системы, включая
   внешний сектор (тогда `CA ≠ 0`).
5. **ИИ-слой:** отдельные стратегии ИИ-агентов, правила доверия/разрешений и аудит операций;
   оценка эффекта на закупки/цены/занятость только после бэктеста.

## 9. Риски

| Риск | Мера |
|---|---|
| Ложное впечатление «модели всего» | статус research toy, дисклеймер в модуле/доках/CLI, нет прогнозов |
| Числа из демо уйдут в публикацию как «эффект ИИ» | явная пометка «условная иллюстрация», нет claims о реальности |
| Нарушение SFC при расширениях | инварианты §5 обязательны, fail-closed, тесты на каждое расширение |
| Некалиброванные параметры | план §8: моментный мэтчинг + OOS, предрегистрация критериев |
| Смешение с допуском | агентный слой не меняет статусы CANDIDATE/SHADOW_TEST/ACTIVE |

## 2. Каноническая схема датасета

Машиночитаемая схема — `src/amfe/mrio/schema.py` (`SCHEMA = "amfe.mrio.dataset.v1"`), файл набора —
`<root>/<dataset_id>/dataset.json` (UTF-8, детерминированная запись, SHA-256).

| Поле | Тип | Смысл |
|---|---|---|
| `schema`, `schema_version` | str | `amfe.mrio.dataset.v1`, `1.0.0` |
| `countries` | str[] ≥ 10 (P2) | коды стран/регионов; RoW — отдельный «страна-блок» |
| `industries` | str[] ≥ 30 (P2) | отрасли (NACE/ISIC-совместимые коды) |
| `years` | int[] (возрастающие, уникальные) | год(ы) наблюдения; один файл = один срез |
| `units` | str | только `USD_mn` (млн долл. США, текущие цены, producer values) |
| `Z` | float[n][n], `n = len(countries)·len(industries)` | промежуточное потребление: строка — производящая (страна|отрасль), столбец — использующая |
| `y` | float[n] | конечный спрос по строке (включая экспорт в конечное потребление) |
| `x` | float[n] | валовой выпуск |
| `va` | float[n] | добавленная стоимость по столбцу |
| `source` | object | `{name, url, licence, retrieved_at, third_party}` — происхождение |
| `trade_weights` | object | двусторонние веса стран (опционально) |
| `fx` | object | нац. валюта за 1 USD (опционально; нужен для EUR-источников) |
| `prices` | object | дефляторы/индексы цен (опционально) |

**Проверяемые тождества** (EQ-IO-001 в docs/53 — SPECIFIED_ONLY, проверяется, не постулируется):

- строка: `x[i] = Σ_j Z[i][j] + y[i]`;
- столбец: `x[j] = Σ_i Z[i][j] + va[j]`;
- глобально: `Σ va = Σ y` и `Σ x = Σ Z + Σ y`;
- итоги по странам: `x`, `y`, `va` и межстрановые потоки (`exports`, `imports`,
  `net_exports`; `Σ net_exports = 0` для замкнутого мира с блоком RoW);
- неотрицательность `Z, y, x, va` (допуск машинного нуля — `tolerance`);
- масштаб P2: ≥ 10 стран и ≥ 30 отраслей (`check_p2_scale`, отдельно от конструктора, чтобы
  маленькие синтетические фикстуры оставались тестируемыми).

Валидатор возвращает `ValidationReport` (`checks`, `metrics`, `errors`, `warnings`); метрики —
агрегаты и итоги по странам, **без матрицы** (их можно печатать и коммитить).

## 3. Как получить данные (команды)

```powershell
# окружение
$env:AMFE_MRIO_ROOT = "D:\amfe\mrio"     # локальный корень (в git не попадает)
$env:PYTHONPATH     = (Resolve-Path src).Path

# 1) проверить источники и статус локальных данных
python tools/mrio_data.py --check                 # живой зонд сети
python tools/mrio_data.py --check --no-network    # только записанные факты

# 2) положить конвертированный набор
#    <root>\<dataset_id>\dataset.json   (каноническая схема §2)

# 3) проверить и записать манифест
python tools/mrio_data.py --validate
python tools/mrio_data.py --manifest --out generated/mrio_manifest.json
```

Пример получения FIGARO (единственный источник с работающим API без ключа):

```python
# GET https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/NAIO_10_CP1700?format=JSON&lang=EN
# ответ ~135 МБ JSON -> разобрать, перевести EUR->USD_mn (поле fx), собрать Z/y/x/va,
# записать <root>/figaro_2020/dataset.json и выполнить --validate
```

**Чего в этой волне нет:** конвертера «файл источника → канонический JSON». Это следующая работа
трека данных; сейчас готовы интерфейс, валидатор, fail-closed загрузчик, манифест и CLI, поэтому
конвертер подключается без изменения потребителей (P2-модель, калибровка, сценарный движок).

## 4. Что делать при `BLOCKED_DATA` (пошагово, для пользователя)

`--check`/`--manifest` вернут `exit 2` и статус `BLOCKED_DATA`, если
`AMFE_MRIO_ROOT/<dataset_id>/dataset.json` отсутствует. Действия:

1. **Выбрать источник** (§1). Рекомендуемый порядок: (а) FIGARO — API без ключа, быстрый старт;
   (б) OECD ICIO — полный P2-охват, скачивание вручную из браузера; (в) WIOD — простая лицензия
   CC BY 4.0, но 2000–2014; (г) Eora — максимальный охват, нужна академическая регистрация.
2. **Проверить лицензию** и записать `source.licence`, `license_verified` (для OECD/Comtrade/BEA/
   Eurostat в этой волне `false`).
3. **Скачать** файлы (вручную/по API) в любой временный каталог вне git.
4. **Конвертировать** в канонический JSON §2 (единицы обязательно `USD_mn`; RoW — отдельный блок;
   `y` включает конечное потребление и экспорт; `va` = выпуск − промежуточное потребление).
5. **Положить** в `<root>/<dataset_id>/dataset.json` и выполнить
   `python tools/mrio_data.py --validate` (ожидаемо: `ok=True`, ≥10 стран, ≥30 отраслей).
6. **Записать манифест**: `python tools/mrio_data.py --manifest` (хеши + статус; манифест можно
   коммитить, он без сырых значений).

**Что нужно от пользователя, чтобы трек пошёл дальше:** файл источника (или API-ключ, если
выбирается Comtrade/BEA), письменное подтверждение лицензии/условий использования и решение,
какой источник считается основным для P2. Без этого статус остаётся `BLOCKED_DATA` — это
честный статус, а не ошибка кода.

## 6. Ограничения и риски

1. **Реальных MRIO-данных в репозитории нет и не будет** (лицензионная политика docs/84): только
   код, схема, синтетические фикстуры, манифесты. Статус `BLOCKED_DATA` — ожидаемый.
2. **Конвертера нет** — интерфейс готов, но перевод файлов OECD/FIGARO/WIOD в канонический JSON
   ещё не написан; это главный разрыв до реального P2-датасета.
3. **Лицензии** OECD/Comtrade/BEA/Eurostat не подтверждены в этой волне; Eora требует
   академической регистрации, WIOD — CC BY 4.0 (подтверждено).
4. **Неполнота схемы:** поставки/использование по продуктам, налоги на продукты, импортные
   матрицы, основные фонды и запасы в каноническую схему не входят (только Z/y/x/va + метаданные);
   расширение — новая версия схемы.
5. **Глобальное тождество** `Σ va = Σ y` требует блока Rest-of-World и согласованной оценки
   (basic/producer values); без RoW таблица не замкнута — валидатор это покажет как ошибку.
6. **Валюты/цены:** FIGARO/Eurostat — EUR, Comtrade — USD (единицы), Eora/OECD — проверить;
   конвертация в `USD_mn` и дефляторы — ответственность конвертера, не загрузчика.
7. **Третий источник истины для C4/допуска:** MRIO-данные не меняют замороженные протоколы;
   P2 использует их только как данные этапов 2–5.
8. Сетевой зонд — точечная проверка (не гарантия доступности); OECD отдаёт 403 не-браузерным
   клиентам, это записано в матрице.

## 1. Канал и загрузка

Страница `https://www.oecd.org/en/data/datasets/inter-country-input-output-tables.html`
отдаётся только с полноценной браузерной сессией (UA + Accept-Language + `sec-fetch-*` +
cookies `affinity/__cf_bm/_cfuvid`; без них 403). В её HTML — **прямые ссылки на официальный
файловый сервис OECD** `https://webfs-sti.oecd.org/files/STI-PIE/ICIO/2025/…` (не обход защиты
и не зеркало: ссылки публикует OECD). Особенность webfs: `Range`-запросы → 206, полный `GET`
большого файла → 403, поэтому загрузчик качает блоками по Range с проверкой `Content-Range` и
SHA-256.

Скачано (`--download-2025`, 5 блоков + ReadMe, всего **604 162 926 байт**; `--check-archive`
→ **PASS**):

| Файл | Байт | CSV-лет |
|---|---|---|
| `1995-2000_SML.zip` | 110 135 258 | 6 |
| `2001-2005_SML.zip` | 99 391 392 | 5 |
| `2006-2010_SML.zip` | 111 587 430 | 5 |
| `2011-2015_SML.zip` | 116 134 326 | 5 |
| `2016-2022_SML.zip` (SHA-256 `46db55c4…175befb`) | 166 241 019 | 7 |
| `ReadMe_ICIO_small.xlsx` | 328 422 | — |

Структура (официальный ReadMe): **81 экономика × 50 отраслей**, current prices **USD million**,
один CSV на год; промежуточный спрос `Z` (`<ISO3>_<IND>`), конечный спрос — матрица
`<ISO3>_<HFCE|NPISH|GGFC|GFCF|INVNT|DPABR>` (поставщик × страна-потребитель), нижние строки
`TLS`, `VA`, `OUT`/`X`, колонка `OUT`.

## 2. Конвенция конечного спроса (ключевое исправление)

Канонический вектор `y` собран как **сумма FD-матрицы по всем странам-потребителям**
(продуктовый итог), а не только по собственной стране строки; при этом:
- `INVNT` (изменения запасов) → `inventory_changes` (знаковый вектор, схема v1.1);
- `DISC` (если есть) → `discrepancy`; `DPABR` (прямые покупки резидентов за рубежом) остаётся
  в `y`; `TLS` остаётся на стороне добавленной стоимости: `va = VA + TLS`;
- `x` берётся из колонки `OUT` (итоги по отрасли).

Проверки (запись датасета запрещена при выходе за допуск): строковая идентичность
`x = Z·1 + y + inventory_changes + discrepancy`; колоночная `x = 1'Z + va`; глобальные
`Σx = ΣZ + Σ(y+inv+disc)` и `Σva = Σ(y+inv+disc)`. Остатки на 2019:
max |row| = **100,87 USD млн**, max |column| = **33,93 USD млн** при выпуске
168 481 393 USD млн (≤0,00006%) — в пределах допуска D1 0,1%. По всем годам:
max |row| 20,6–172,9 USD млн, max |column| 0,9–33,9 USD млн (допуск PASS).

## 6. Ограничения и остатки

- **Конвенция FD**: `y` — продуктовый итог FD-матрицы. Остатки идентичностей ненулевые
  (≤0,1%, максимум 172,9 USD млн на отдельных годах) из-за округления/несовершенной балансировки
  исходной таблицы; допуск D1 0,1% пройден, но это не «нулевой» баланс.
- `TLS` входит в `va` (как в исходной таблице); отдельного `va_adjustments` не потребовалось.
- Датасеты v1.1 (~2,5 ГБ) — только локально на F:; `src/amfe/mrio/schema.py` пока читает v1;
  интеграция v1.1 в `src/**` вне области этого трека.
- Лицензия OECD Terms: принятие/цитирование — на стороне пользователя; стандартная цитата:
  OECD (2025), OECD Inter-Country Input-Output Tables.
- Редакция 2016 (71×34, 2000–2011, D1 PASS, покрытие 95,5%) остаётся запасным датасетом
  (`data/mrio/oecd_icio`, docs/130 §7 прежней редакции в истории).

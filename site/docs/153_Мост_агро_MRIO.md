# 153. Мост «агро/соя → MRIO» (G2)

Дата: 2026-11-16. Волна 22, ворота G2. Инструмент — [tools/agri_bridge.py](../tools/agri_bridge.py),
тесты — [tests/test_agri_bridge.py](../tests/test_agri_bridge.py). Артефакты прогона —
`build/agri_bridge/agri_bridge.json` и `agri_bridge.md`; кэш агрегированной структуры затрат —
`build/agri_bridge/mrio_cost_structure.json`.

**Статус: research prototype.** Это не допуск модели, не прогноз и не торговая рекомендация:
мост соединяет уже существующий агро-прототип (`src/amfe/markets_agri`, трек C) с реальной
межстрановой таблицей «затраты–выпуск», **не меняя ядро** (`src/amfe/world`, `amfe.mrio`,
frozen-файлы не трогались). Никакие claims о допуске, T2 или ACTIVE не заявляются.

## 1. Задача и границы

Агро-модуль выдаёт диапазон цен сои/шрота по сценарию «Бразилия −15 % урожая + экспортное
трение −35 %» и иллюстративный эффект для Африки. Мост отвечает на два **разделённых** вопроса:

1. **Ценовой канал (смоделирован).** Какие изменения цен/издержек производителей в группах
   «сельское хозяйство / пищепром / прочие / животноводство» и в странах следуют из этого шока
   при реальной структуре затрат MRIO и явных долях сои/шрота в кормах и пищепроме?
2. **Количественный канал (НЕ смоделирован).** Падение выпуска, объёмов, ВВП, благосостояния и
   перераспределение торговли не оцениваются: для этого нужна модель спроса/замещения/хранения.
   Импортный счёт Африки считается при **фиксированных базовых объёмах** и явно помечен как
   ценовой канал.

Граница ответственности: мост не строит сценарий (это агро-модуль), не пересобирает MRIO (это
ядро), не делает выводов о допуске (это протокол).

## 2. Архитектура

```
SoyAgriModule.run()  (трек C, не изменяется)
   └─ цена сои/шрота: low/high (два заранее объявленных угла), Африка: bill/импорт/прод.инфляция
        │
        ├─ ценовой канал: agri_bridge
        │     MRIO (OECD ICIO 2011, 71×34, USD_mn, read-only)
        │        → агрегированная структура затрат A (AGRI/FOOD/OTHER) + кэш с SHA-256
        │        → явный слой допущений (доли сои/шрота в пищепроме, доля корма в животноводстве)
        │        → p = (I − A')⁻¹ c  (Леонтьев-цены), замыкание через виртуальный ANIMAL
        │        → цены производителей по группам и странам; pass-through → вклад в прод. CPI
        │
        └─ количественный канал: отсутствует (явно помечен `modelled: false`)
             импортный счёт Африки: из агро-модуля, при фиксированных объёмах,
             НЕ добавляется к мировым итогам (без двойного счёта)
```

Модуль моста не импортирует и не изменяет `src/amfe/world`; единственная зависимость от ядра —
чтение канонического датасета через `amfe.mrio.loaders.load_dataset`, единственная зависимость от
трека C — публичный `SoyAgriModule.run()`.

| Параметр | Значение |
|---|---|
| Источник MRIO | OECD ICIO 2011 (каноническая схема v1.1), 71 экономика × 34 отрасли = 2 414 секторов, 5 827 396 ячеек Z |
| Единицы | `USD_mn` (проверяется; другие единицы → fail-closed) |
| SHA-256 датасета | `fc753c37bf3f59006a66e1bd9152a6ecb9875773ccb5ad697cdf6eb36dafa6aa` |
| Digest валидатора | `fc6b8e273344d87fdd9c35358e61e9c75dcac92b41b5fc526f00f8b9cddfc367` |
| Размер / год | 29 150 115 байт / 2011 |
| Лицензия | OECD ICIO terms; в репозиторий попадают только производные агрегаты, сырая таблица не коммитится |
| Группы | `AGRI` = `C01T05AGR`, `FOOD` = `C15T16FOD`, `OTHER` = остальные 32 отрасли; `ANIMAL` — виртуальная группа |
| Кэш | `build/agri_bridge/mrio_cost_structure.json`, digest `9eebd957a83aca2c40da352851b1768b1f20a104d0c46454fad6062d7176232b` |

Кэш хранит агрегаты (мировую и страновые матрицы A, выпуски групп, SHA-256 датасета) и
проверяется по digest при каждом чтении; пересборка — `--rebuild-cache` (~45 с, из них ~20 с —
загрузка канонического датасета). Отсутствие кэша и датасета одновременно → exit 2 (fail-closed).

## 4. Ценовая модель (Леонтьев-цены)

Уравнение: `p = (I − A')⁻¹ c`, где `A[input, using]` — коэффициенты затрат (реальные, из Z/x),
`c` — экзогенный сдвиг затрат. Реальная структура затрат (мировая, из OECD 2011):

| Затрата ↓ / потребитель → | AGRI | FOOD | OTHER |
|---|---|---|---|
| AGRI | 0.12178 | 0.27717 | 0.00596 |
| FOOD | 0.06428 | 0.16029 | 0.00848 |
| OTHER | 0.22662 | 0.30943 | 0.50027 |
| Σ затрат (столбец) | 0.41268 | 0.74689 | 0.51471 |
| Остаток = добавленная стоимость | 0.58732 | 0.25311 | 0.48529 |

**Явный слой допущений** (соя не является отраслью ICIO, поэтому доли объявлены, а не оценены;
`source_class = "assumption"`):

| Допущение | Значение |
|---|---|
| Прямая доля сои в затратах пищепрома | 2.0 % выпуска |
| Прямая доля шрота в затратах пищепрома | 1.5 % выпуска |
| Доля корма в затратах животноводства | 45 % |
| Доля сои / шрота внутри корма | 5 % / 30 % |
| Добавленная стоимость + прочие затраты животноводства | 15 % |
| Pass-through в потребительские цены | 0.50–0.90 |
| Вес продовольствия в потребительской корзине | 0.15–0.30 |
| Доли переработанного продовольствия / мяса в корзине | 0.60 / 0.25 |

Виртуальный сектор `ANIMAL` замыкает модель: его столбец — корм (45 %) и прочие затраты (40 %),
добавленная стоимость 15 %; строка нулевая (никакая отрасль MRIO не использует «животноводство»
как промежуточный товар, поэтому это терминальный канал цен, а не дополнительный столбец FOOD —
иначе суммы затрат превысили бы единицу).

## 5. Числа (прогон на реальной MRIO + агро-сценарий)

Сценарий агро-модуля (digest `c77c933c…`): соя **420 → 464.64–621.17 USD/t** (+10.63 % … +47.90 %),
шрот **330 → 365.07–536.87 USD/t** (+10.63 % … +62.69 %).

**Цены производителей, % (низкий / высокий угол):**

| Группа | Низкий угол | Высокий угол |
|---|---|---|
| AGRI | +0.0356 | +0.1818 |
| FOOD | +0.4578 | +2.3361 |
| OTHER | +0.0082 | +0.0418 |
| ANIMAL (виртуальная) | +1.6933 | +9.6392 |

**Потребительское продовольствие (допущение pass-through):** вклад в продовольственную инфляцию
**+0.052 … +1.029 п.п.** (мир; углы дают 0.052–0.189 и 0.286–1.029 п.п.). Это диапазон, не
точечная оценка (`point_estimate: false`).

**Страны (71; вклад в продовольственную инфляцию, п.п., высокий угол):** максимум — MYS 1.195
(цена FOOD +3.32 %), CN1 1.085, BEL 1.075, NLD 1.072, SGP 1.071, CN3 1.068, ESP 1.052, KOR 1.051;
минимум — SAU 0.965, CN4 0.954, MX3 0.952, MEX и CHN 0.952. Разброс между странами небольшой
(≈0.95–1.20 п.п.), потому что доминируют объявленные допущения pass-through/весов, а не страновые
различия затрат: страновой сигнал — это разница цен FOOD (например, 2.34 % в среднем против 3.32 %
в MYS).

**Африка (из агро-модуля, отдельно, без двойного счёта):** базовый импортный счёт 4 420.5 USD млн;
изменение **+466.2 … +2 292.6 USD млн** (+10.55 % … +51.86 %); вклад в продовольственную инфляцию
**+0.026 … +0.560 п.п.** `included_in_world_totals = false`: африканский эффект — зеркальный
импортный отклик того же ценового шока и **не складывается** с мировыми ценовыми эффектами.

Итоговый digest отчёта: `e78512a352b8fcf827c41d9e1a26791205fdd1617d39f384b75cf334032f384a`;
JSON-файл прогона — 10 876 байт, SHA-256 `49f54be83782f1388be44e3efa8de0595cbc8c0a9b1255528b893a6f5ffce2e9`.

## 6. Разделение price / quantity (жёсткое правило)

| Канал | Статус | Что именно |
|---|---|---|
| Цены сои/шрота | смоделировано (диапазон) | два угла сценария агро-модуля |
| Цены/издержки производителей | смоделировано | Леонтьев-цены по группам и странам |
| Потребительские цены на продовольствие | смоделировано как диапазон | pass-through × вес × состав корзины (допущения) |
| Импортный счёт Африки | цена × **фиксированные** базовые объёмы | из агро-модуля, помечено |
| Выпуск, объёмы, ВВП, благосостояние, перераспределение торговли | **НЕ смоделировано** | `modelled: false`, `not_claimed: [...]` |

В отчёте нет полей вида «падение выпуска», «изменение объёма» или «эффект на ВВП»; любой
потребитель артефакта видит `separation.quantity_based.modelled = false` и список того, что
потребовалось бы для количественного канала (система эластичностей спроса, замещение культур и
происхождений, хранение и торговая политика, PIT-данные по торговым потокам).

## 7. Ограничения

1. **MRIO — 2011 год (OECD ICIO 2016 edition)**: коэффициенты затрат старые; версия 2025 изменит
   числа, но не метод (пересборка кэша — одна команда).
2. **Соя не является сектором ICIO**: доли сои/шрота в пищепроме и корме — объявленные допущения,
   а не оценки; они и доминируют в результате.
3. **Животноводство виртуальное**: отдельной таблицы животноводства в ICIO нет; корм и
   добавленная стоимость заданы долями.
4. **Линейная статическая модель цен**: нет замещения, реакции спроса, хранения и политики;
   цены производителей — не потребительские цены.
5. **Pass-through и веса корзины — допущения**: вклад в продовольственную инфляцию не является
   оценкой CPI-реакции.
6. **Африка не является регионом MRIO** (в таблице 71 экономики есть только MAR/TUN/ZAF):
   африканский эффект взят из агро-модуля (иллюстративный агрегат) и не выводится из MRIO-модели.
7. **Количественный канал отсутствует** и не заявляется; импортный счёт — цена × фиксированные
   объёмы.
8. **Нет PIT-данных и валидации на реальных наблюдениях**: сценарий и доли — `assumption`.
9. **Не допуск, не прогноз, не торговая рекомендация**; слой не подключён к протоколу, реестру и
   P2-манифесту.
10. **Страновые различия малы** относительно ширины диапазона допущений — не интерпретировать
    рейтинг стран как экономический вывод.

## 8. Что нужно для следующего шага (G3 и далее)

1. Откалибровать доли сои/шрота по реальным данным (USDA PSD/FAO: кормовые рационы, crush,
   структура затрат пищепрома), заменить допущения оценками с интервалами.
2. Перейти на OECD ICIO 2025 (81×50) как основной мир G2 — пересборка кэша и сравнение чисел.
3. Добавить количественный канал: система эластичностей спроса/замещения, хранение, торговая
   политика; только после этого можно говорить об объёмах и ВВП.
4. PIT-винтажи торговых потоков и производственных данных; фиксация дат публикации.
5. Провести внешнюю проверку по образцу docs/138 (независимый ревьюер, числа и хеши).
6. Подключить к воротам G3: цены/издержки → MRIO/SFC, с явным разделением ценового и
   количественного каналов.

## 9. Воспроизведение

```powershell
# 1) реальная MRIO: первый прогон пересобирает кэш (~45 с), дальше — из кэша (секунды)
python tools/agri_bridge.py --rebuild-cache
python tools/agri_bridge.py

# 2) офлайн-демо на синтетической структуре (без данных, для тестов/проверки механики)
python tools/agri_bridge.py --synthetic --json

# 3) самотест и справка
python tools/agri_bridge.py --self-test --json
python tools/agri_bridge.py --help

# 4) тесты моста (24 теста: Леонтьев-цены и residual, углы и порядок, отсутствие двойного
#    счёта, разделение price/quantity, fail-closed, кэш, CLI, честность docs)
python tests/test_agri_bridge.py
```

* Входы: агро-сценарий (в коде `SoyAgriModule`), OECD ICIO 2011 датасет (вне git) и кэш
  `build/agri_bridge/mrio_cost_structure.json`. Сеть не используется.
* Детерминизм: нет чтения часов и случайных чисел; одинаковые входы → побайтово одинаковый JSON
  и одинаковый digest. Поле `origin` (`rebuilt`/`cache`/`synthetic`) добавляется в JSON после
  расчёта digest и на digest не влияет.
* Коды возврата: `0` — успех, `2` — fail-closed (нет данных/кэша, неканонические единицы,
  непродуктивная матрица A, отрицательный/NaN сдвиг затрат, нарушение порядка границ).

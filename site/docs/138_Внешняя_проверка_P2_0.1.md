## 4. Что нужно для sign-off

1. Закрыть `R3-MEDIUM` (указатель коммита) — пересобрать манифест после коммита релиза.
2. Закрыть `R6-MEDIUM` (устаревший текст про docs/135–136) и два LOW по docs/137 (34 входа,
   фактический размер).
3. Зафиксировать docs/128 и docs/135 в git, пересобрать `build/p2_release/p2_release.json` и
   перегенерировать ревью: `python tools/external_review.py` → ожидаемый итог
   `PASS` (без MEDIUM/LOW) или `PASS_WITH_FINDINGS` только с принятыми как «известное ограничение»
   замечаниями.
4. Подписать шаблон из §6. Подпись означает проверку артефактов и чисел, а **не** научную
   валидность MRIO/SFC/сценарных допущений и не допуск модели.

## 5. Ограничения самого ревью

* Автоматический чек-лист проверяет артефакты, хеши и заявленные числа; он **не** пересчитывает
  A=Z/x, SFC-балансы и 8 сценариев из сырых Z (остатки читаются из отчётов, а не из 94 МБ
  FIGARO/29 МБ OECD). Научная валидность допущений (A_c = FD_c, статическое поглощение, FX
  pass-through без ценового замещения, GVAR-проекция стабильности) не проверялась.
* Сторонние данные (FIGARO/OECD/WIOD) не копируются и не коммитятся: проверяются только их
  дайджесты и агрегаты в манифестах; отсутствие датасета на диске даёт LOW, а не PASS.
* Дрейф рабочего дерева после релиза классифицируется отдельно (LOW): он не отменяет релизный
  коммит, но означает, что текущее дерево не совпадает с манифестом.
* Ревью детерминировано, кроме поля `generated_at`; любые изменения манифеста, статусов, claims
  или docs/137 ловятся тестами (подмена SHA, статуса, числа, admission/ACTIVE-claim, docs-числа).
* Один ревьюер, один снимок: повторная проверка обязательна после любой пересборки манифеста.

## 7. Воспроизведение

```powershell
# полный чек-лист (10 проверок; хеши 34 входов, D1–D6, claims, docs/137, --help, пересборка)
python tools/external_review.py
# быстрый прогон без пересборки манифеста и без --help
python tools/external_review.py --no-rebuild --no-help
# детерминизм: фиксированный generated_at
python tools/external_review.py --generated-at 2026-11-14T22:00:00Z
# тесты (18 тестов: чек-лист, подмена SHA/статуса/чисел/claims/docs, fail-closed, детерминизм, CLI)
```

# Контекст-пакеты архива

Файлы в этой папке **генерируются**: `tools/archivist.py pack --project <ns> --topic "<тема>"
--role <роль> --today <дата>`. Руками не правятся — правка теряет провенанс и лицензию.
Нужное изменение вносится в запись архива, после чего пакет пересобирается.

Имя файла: `<проект>--<тема>--<роль>.json` и `.md` (тема — до 40 символов, `all` — без темы).

Что внутри:

| Блок | Смысл |
|---|---|
| `entries` | записи: провенанс, evidence, лицензия, доступ, свежесть, совпадение с темой |
| `excluded` | что не попало и почему: `namespace:*`, `audience:*`, `access:restricted`, `stale`, `limit`, `archived` |
| `gaps` | чего не хватает: токены без записей, отсутствие `VERIFIED`/`PARTIAL`, просроченные |
| `licence_notices` | что можно делать с записями пакета |
| `policy` | сеть выключена, часы не читаются, `admission=false` |

Пакет детерминирован: на одну дату и один запрос — одинаковые байты. `stale` исключается по
умолчанию; `--include-stale` включает осознанно, `--allow-restricted` — только для своего проекта.

Текущие пакеты: `osint` (osint-scout), `legal` (legal-claim), `cases` (case-writer), `lead` (lead),
`amfe` (evidence-qa). Пакет — единственная форма передачи контекста между проектами; пересказ
по памяти её не заменяет.

# Conflict check и санкции

## Конфликт интересов

- стороны, аффилированные лица, конечные бенефициары;
- прошлые/текущие поручения против стороны;
- личные/финансовые связи юриста;
- несколько юрисдикций: проверять по каждой.

## Санкции / KYC

- списки ЕС/США/Великобритании/ООН/национальные;
- бенефициары, источники средств, сектор;
- экспортный контроль, dual-use;
- при совпадении — стоп, эскалация к compliance, не «обойти».

## Фиксация

- `conflict_check`: кто проверял, дата, результат, scope;
- `sanctions_check`: источник, дата, результат;
- без персональных данных в git; только ID/статус.

## Красные линии

- нельзя подписывать при незакрытом конфликте;
- нельзя работать с подсанкционным лицом без лицензии/разрешения;
- нельзя скрывать конфликт от клиента.

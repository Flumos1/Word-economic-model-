# Human Counsel: международный пул лицензированных юристов

Дата: 2026-11-22. Статус: **HUMAN_REQUIRED**. Это не «AI-юрист, который заменяет человека», а
контур, который **обязан** подключить реального лицензированного юриста в каждой юрисдикции.
AI готовит research memo; юридическую силу имеет только подпись человека.

## Зачем

Ни один юрист не лицензирован во всех странах. Профессиональная модель — **lead counsel +
проверенная сеть local counsel**:

1. **Lead counsel** (`international-counsel`) собирает вопрос, применимое право, source plan и
   проект меморандума.
2. **Human Counsel** проверяет факты, конфликт интересов, лицензию и подписывает заключение в
   конкретной юрисдикции.
3. **Local counsel** — лицензированный юрист страны, где возникает вопрос; без него вывод по этой
   юрисдикции не выдаётся.

## Что лежит здесь

| Файл | Что |
|---|---|
| `charter.md` | мандат, границы, что подписывает человек, что делает AI |
| `skills.md` | навыки human counsel и local counsel |
| `engagement_protocol.md` | как подключить, проверить лицензию, конфликт, гонорар, NDA |
| `conflict_check.md` | конфликт интересов, санкции, KYC |
| `signoff.md` | формат подписи и что нельзя подписывать |
| `jurisdiction_matrix.json` | 217 стран/экономик; статус `UNASSIGNED`/`PRIORITY_UNASSIGNED`, без выдуманных имён |
| `panel_registry.json` | пустой реестр пула; заполняется только реальными проверенными юристами |

## Важно

- В матрице **нет ни одного назначенного юриста**: `counsel_id=null` у всех. Это честно: пул
  создаётся договорами, а не выдуманными профилями.
- `UNASSIGNED` — не «юрист есть», а «нужен юрист»; заключение по такой юрисдикции невозможно.
- AI не может быть `human_verified_by`, не может подписывать, не может выдавать себя за человека.
- **AI-research memo не является юридической консультацией**; заключение появляется только после
  проверки и подписи лицензированного human counsel.
- Все персональные данные юристов — только в защищённом реестре вне git; в репозитории — ID,
  юрисдикции, статус, дата проверки, без телефонов/email.

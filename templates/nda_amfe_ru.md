# NDA — черновик для AMFE (пилот аналитики)

> **ЧЕРНОВИК. Не юридическая консультация. Требует проверки Human Counsel и адаптации под
> юрисдикцию сторон.** Не подписывается агентом; подпись — только человек. Тексты ниже — каркас
> для обсуждения, а не готовый договор.

## 1. Стороны

- **Раскрывающая сторона / Получающая сторона** — заполняется по итогам пилота
  (название, юрисдикция, реквизиты; для AMFE — по [agents/legal](../agents/legal/README.md) маршруту
  к Human Counsel).
- Подписанты — уполномоченные лица; агент не подписывает и не заверяет.

## 2. Предмет

Обмен информацией для оценки и проведения пилота сценарной аналитики AMFE (сценарии, допущения,
диапазоны, отчёты, методология). Продукт — `RESEARCH_ONLY`, модель **не допущена**
(`admission=false`); это фиксируется в приложении к NDA, чтобы не возникало ожиданий «прогноза».

## 3. Что считается конфиденциальным

- Данные Получающей стороны, переданные для пилота (агрегаты, категории, объёмы, допущения).
- Коммерческие условия, цены, сроки, содержание переписки.
- **Не является конфиденциальным:** публичные данные и артефакты AMFE (документация, отчёты о
  методологии, публичные сценарии), а также сведения, уже известные из открытых источников.

## 4. Исключения

Информация не является конфиденциальной, если она: (а) уже была у Получающей стороны законно;
(б) стала публичной не по её вине; (в) получена от третьей стороны без нарушения обязательств;
(г) должна быть раскрыта по требованию уполномоченного органа — с уведомлением другой стороны,
если это разрешено.

## 5. Обязательства Получающей стороны

1. Использовать информацию только для целей пилота.
2. Не передавать третьим лицам без письменного согласия, кроме субподрядчиков, связанных не менее
   строгими обязательствами (и с перечнем).
3. Хранить не дольше срока пилота + согласованный срок (по умолчанию 12 месяцев), затем удалить
   или вернуть по запросу.
4. Уведомить о любом подозрении на утечку в разумный срок (целевой ориентир — 72 часа) и
   содействовать расследованию.
5. Не использовать данные для обучения моделей без отдельного письменного согласия.

## 6. Данные, которые не передаются

Персональные данные, специальные категории, государственная тайна, данные под режимом,
требующим лицензии, которую AMFE не имеет. Платные лицензионные датасеты (ICE/NYMEX, IEA, Kpler,
Vortexa) не используются — правило владельца ([docs/238](../docs/238_Карта_источников_без_лицензий.md)).

## 7. Права на результат

Отчёты и производные материалы пилота — по отдельному соглашению; по умолчанию: клиент получает
право использовать отчёты внутри организации, AMFE сохраняет право на методологию и общие
(обезличенные, агрегированные) подходы.

## 8. Срок и расторжение

- Срок действия NDA: ___ месяцев с даты подписания.
- Расторжение — письменно, с сохранением обязанностей по уже переданной информации.
- Прекращение пилота не прекращает обязанности по §5–§7.

## 9. Право и споры

Применимое право и подсудность — определяет Human Counsel с учётом юрисдикций сторон; агент
не выбирает право и не даёт юридических выводов ([docs/225](../docs/225_Human_Counsel.md)).

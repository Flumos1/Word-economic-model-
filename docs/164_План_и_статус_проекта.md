## 0. Резюме: где проект сейчас

AMFE — исследовательская платформа мировой экономической модели и прогнозирования: реальные
межстрановые таблицы «затраты–выпуск» (MRIO), SFC/счета, сценарный движок, прогнозный трек с
замороженными протоколами и внешними проверками, товарные модули (нефть, агро, финансы),
агентный симулятор, реестр модулей и продуктовый слой (API, клиентские пакеты, сайт).

**Главное по статусам (честно):**

- **Ни одна модель не допущена**: `admission=false` во всех релизах; ACTIVE нет ни у одной пары
  «цель–горизонт».
- **P2 0.1 / 0.2** — `RESEARCH_RELEASE`: D1, D2, D3, D5, D6 — **PASS**, D4 (динамика) —
  `RESEARCH_ONLY` (отрицательный OOS).
- **Прогнозный трек**: T1 (CPI h=1) — `CANDIDATE`; T3 (рецессия) — `CANDIDATE`;
  `ENSEMBLE_REGIME_V4` — `SHADOW_TEST` с `conditional_data_class=true`; T2 — вне допуска.
- **C6-гейт** (12 разрешённых прогнозов и ≥4 целевых периодов): **0/12** и **1/4**, оценка

- **Ворота 2.0**: G1 (контракты, волна 21), G2 (мосты/API, волна 22), G3 (калибровка, количественный

## 1. Как читать статусы

| Статус/гейт | Значение |
|---|---|
| `RESEARCH_ONLY` | Прототип/исследование; числа можно обсуждать, но нельзя цитировать как прогноз/наблюдение |
| `CANDIDATE` | Кандидат прошёл часть критериев протокола; не допущен |
| `SHADOW_TEST` | Теневой трек: прогнозы пишутся в журнал, но не идут в продукт |
| `LIMITED_DEPLOYMENT` | Ограниченный допуск после C6 (12 прогнозов, 4 периода, loss/coverage) |
| `ACTIVE` | Полный допуск; для T1/T3 потолки протокола и 8 независимых исходов |
| C1–C6 | Критерии протокола: C1 точность, C2 значимость (Romano–Wolf), C4 хвосты/рецессии, C5 калибровка, C6 forward-гейт |
| D1–D6 | Критерии структурной модели P2: данные, статическое ядро, SFC, динамика, сценарии, интеграция |
| G1–G6 | Ворота платформы 2.0: контракты → модули → интеграция → продукты → масштаб |
| PASS / CONDITIONAL / FAIL / RESEARCH_ONLY | Формальные вердикты внешних проверок и релизов; «отрицательный результат» — тоже результат |

Правило проекта: **неприменимый критерий помечается NOT_APPLICABLE, а не PASS**; никаких claims о
допуске и точности без предрегистрации и OOS.

## 3. Что сделано (по направлениям)

### 3.1 Мировая модель P2 (структурный контур)

| Критерий | Статус | Факт |
|---|---|---|
| D1 Данные | **PASS** | FIGARO 2019 50×64 (3200 секторов, покрытие 87,28% ВВП + ROW = 100%); OECD ICIO 2016 71×34 (2000–2011); **OECD ICIO 2025 81×50, 28 лет 1995–2022**, D1 PASS ×28, покрытие 94,6–97,2%; WIOD 2016 44×56 |
| D2 Статическое ядро | **PASS** | A=Z/x, ρ(A)=0,5938 (OECD 2025), Hawkins–Simon PASS, `x=(I−A)⁻¹y` воспроизводится; невязки ≤1e−8 |
| D3 SFC | **PASS** | S=I+CA, ΣCA=0, чистая стоимость; PASS на FIGARO и OECD |
| D4 Динамика | **RESEARCH_ONLY** | GVAR 53 страны × 30 лет: лучше AR(1)/RW только в 4 из 32 ячеек → **отрицательный результат**, вне допуска (docs/128/135) |
| D5 Сценарии | **PASS** | 8 сценариев × 2 мира (энергия ±, импорт +10/+20%, FX −10/−20%), обязателен energy +50%; балансы PASS |
| D6 Интеграция | **PASS** | один пайплайн `world_pipeline.py` → core → scenarios → report; P2 0.1 и **P2 0.2** манифесты (`RESEARCH_RELEASE`) |

Плюс: SFC↔IO интеграция (docs/133), сценарные отчёты «страна × отрасль» (docs/131), мезо/микро
труд-домохозяйства на WIOD SEA (docs/136), публичный сайт RU+EN (docs/132/134).

### 3.2 Прогнозный трек (данные → протокол → оценка)

- **Данные**: автоматический сбор, плотный винтажный архив ALFRED (147 квартальных дат на ряд),
  ворота R2 — 178/333 пары, 73/123 до 2000, 0 расхождений; реконструкция PIT 1990–1996 (docs/108).
- **Протоколы**: v1→v4 заморожены; **v5.0.1** (FROZEN, SHA `48c2f6a1…`): C4 на W1_EXT, классы
  реконструированных данных, еженедельный forward-журнал; R3 1.0.1 заморожена; NF-SIM пороги C1
  заморожены; harness C1–C6 с Romano–Wolf.
- **Кандидаты**: 11 зарегистрированных id (ENSEMBLE_RW_AR, INVERSE_MSE, EQUAL, ADAPTIVE, BAYES,
  REGIME…V4, T2_SPF/T2_NOT_SPF). Текущие статусы: T1 `CANDIDATE` (C4 FAIL по RMSE W1_EXT 1,0775),
  `ENSEMBLE_REGIME_V4` — `SHADOW_TEST` (C1/C2/C4/C5 PASS, C4 RMSE 0,9734/0,9406; C4 CRPS
  0,9188/0,9819; C2 W1 p 0,0249/0,0566 — на границе), T3 `CANDIDATE` (C1/C2 FAIL, C5 PASS).
- **C6**: forward-журнал открыт (11 строк, 0 разрешённых); гейт **0/12 прогнозов, 1/4 периодов**;
  прогноз даты гейта **2027-05-07**; после — `LIMITED_DEPLOYMENT` (Q2 2027), ACTIVE — не раньше
  2027+ (потолки протокола).
- **Честные отрицательные результаты**: T1 C4 не проходит по RMSE на рецессиях; режимные
  кандидаты улучшают C4, но платят C1/C2; финансовая модель OOS **не лучше random walk**.

### 4.2 P2: что осталось после D1–D6

- **D4 (динамика)** — `RESEARCH_ONLY` **зафиксирован для P2 0.2**: альтернативы закрыты

## 6. Известные ограничения и отрицательные результаты (не прятать)

1. **D4 динамика** — отрицательный OOS; production-блока нет.
2. **Финансовый слой** — OOS не лучше random walk; прибыльной стратегии нет.
3. **Агро-валидация** — слабая поддержка: направление 8/8 (легко), покрытие 1/8, недооценка
   магнитуд; `validated=false`.
4. **PIT-калибровка нефти** — OOS_PASS, но выигрыш мал и хрупок; 2019 хуже; «факты» — приближения.
5. **Количественный канал** — reduced-form, не поведенческая модель; большие шоки вне линеаризации.
6. **Агентный слой** — иллюстративные параметры, кумулятивные агрегаты, не периодические счета.
7. **Внешние проверки** — автоматизированные чек-листы и LLM-ревью, не человеческая сертификация;
   подпись человека есть только у части релизов.
8. **Данные** — 12 из 15 источников не VERIFIED; сырые данные не в git; лицензии — эвристика.
9. **Продукты** — Client Pack v2/API v2/шлюз/FLAKS MVP+пилот/Simulator UI — research-прототипы; beta,
   SLA, публичный аудит и первые платящие клиенты — впереди; API-контракт статический + отдельный шлюз.
10. **Допуск** — ни одна модель не admitted; любые числа — исследовательские.

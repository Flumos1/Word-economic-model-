# 142. Клиентский пакет: генератор и пример на реальном сценарии

Дата: 2026-11-15. Инструмент: [tools/client_pack.py](../tools/client_pack.py). Пример:
`build/client_pack/demo_bank_energy_plus50/` (в git не коммитится).

## 1. Что делает

Превращает **один реальный сценарный отчёт** (`build/world/reports/<id>.json`) в пакет, который
получает платный исследовательский клиент:

| Файл | Формат | Что внутри |
|---|---|---|
| `01_Executive_Summary` | DOCX + PDF | 2–4 страницы: главное, топ-эффекты, ограничения |
| `02_Scenario_Report` | DOCX + PDF | полные таблицы «страна × отрасль», итоги, проверки |
| `03_Analyst_Pack` | XLSX | листы: Сводка, Страны, Отрасли, SFC, Проверки |
| `04_Machine_Readable` | JSON | машиночитаемый отчёт для интеграции |
| `05_Dashboard` | HTML | офлайн-панель, без JS/внешних ресурсов |
| `06_Methodology_Appendix` | DOCX + PDF | данные, метод, версии, ограничения |
| `07_Reproducibility` | JSON | SHA-256 входа/выходов, датасет, команда пересборки |
| `08_Licence_and_Disclaimer` | DOCX + PDF | лицензии данных, статус research-only |
| `09_Board_Deck` | PPTX (fallback MD) | 5 слайдов для руководства |
| `README.md` | Markdown | состав пакета и дисклеймер |

Правила: детерминизм при фиксированном `--generated-at`, fail-closed (нет/битый отчёт — пакет не
пишется), только производные агрегаты (никаких сырых Z), без внешних URL и JavaScript.

## 2. Команда

```powershell
python tools/client_pack.py `
  --report build/world/reports/energy_plus50.json `
  --client "Demo Bank" `
  --out build/client_pack/demo_bank_energy_plus50 `
  --generated-at 2026-11-15T09:00:00Z `
  --json
```

PDF-конвертация — через LibreOffice (`soffice`), если найден; иначе остаются DOCX (в README
помечается). PPTX требует `python-pptx`; без него пишется Markdown-версия колоды.

## 3. Пример на реальном сценарии (FIGARO 2019, energy +50%)

- Сценарий: `energy_plus50` — рост конечного спроса на 50% в CPA_B/CPA_C19/CPA_D35.
- **Δ выпуска: +2 534 517,09 USD млн (+1,49%)**; базовый выпуск 169 599 264,17 USD млн.
- Топ стран по |Δ|: ROW 579 878,01; US 551 286,39; CN 214 863,11.
- Топ отраслей: CPA_D35 699 644,33 (27,6%); CPA_B 612 759,25 (24,2%); CPA_C19 507 313,54 (20,0%).
- Проверки: балансы PASS, продуктивность PASS, ρ(A)=0,575, Hawkins–Simon PASS.
- Пакет: 15 файлов, ~662 КБ (DOCX/PDF/XLSX/PPTX/HTML/JSON).

## 4. Ограничения

- Это research-пакет: не допуск и не инвестиционная рекомендация; сценарии — сравнительная статика.
- Сырые данные FIGARO/OECD/WIOD не передаются; только производные агрегаты.
- PDF может содержать служебные метки конвертера (не байт-детерминирован); DOCX/JSON/HTML
  детерминированы при фиксированном времени.
- Кастомизация под клиента (его отрасли/страны/шаблон) — следующий шаг; сейчас пакет строится по
  готовому отчёту, без ручной вёрстки.

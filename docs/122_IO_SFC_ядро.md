## 1. Область

Статическая часть межстранового/межотраслевого слоя (P2): один снимок технологий в одной
стоимостной базе за один период. Ядро проверяет и решает **баланс Леонтьева** (EQ-IO-001,
статус `SPECIFIED_ONLY`) и даёт **SFC-контракт учёта** потоков/запасов. Динамика (EQ-IO-002,
`HYPOTHESIS`) не реализуется; цены, дефляторы и валютные курсы не вводятся.

## 2. Контракт данных IO

```python
{"countries": [...], "industries": [...],
 "Z": [[...]], "y": [...], "x": [...], "va": [...], "units": "USD_mn"}
```

* `n = len(countries) * len(industries)`; порядок **country-major**:
  `index(country c, industry i) = c * len(industries) + i`;
* `Z[i][j]` — продукт `i`, использованный отраслью `j` (строки — продукты, столбцы — отрасли);
* `y` — конечный спрос по продуктам; `x` — валовой выпуск; `va` — добавленная стоимость по
  отраслям; `units` — одна стоимостная база (по умолчанию `USD_mn`);
* строки и столбцы — один и тот же список секторов («страна/отрасль»), поэтому таблица квадратная.

Тождества, проверяемые **fail-closed** (никакой «тихой» балансировки):

```
EQ-IO-001:   x = Z 1 + y          (по продуктам)
             x = Z^T 1 + va        (по отраслям, замыкание добавленной стоимости)
```

`x_i <= 0` запрещено: коэффициент `A = Z / x` по столбцам требует строго положительного выпуска.

## 3. Уравнения

**Технология.** `A = Z diag(x)^{-1}`, т.е. `A[i][j] = Z[i][j] / x[j]` (столбец `j` делится на `x_j`).

**Решение Леонтьева.**

```
x = A x + y,        x = (I - A)^{-1} y = ( sum_{k>=0} A^k ) y .
```

**Продуктивность (Перрон–Фробениус).** `A >= 0` продуктивна тогда и только тогда, когда
`rho(A) < 1`; тогда `(I - A)^{-1} >= 0` и ряд `sum A^k` сходится. Граница `rho = 1` трактуется как
непродуктивная. `rho` вычисляется как `max |lambda_i|` (для `A >= 0` это корень Перрона).

**Условие Хокинса–Саймона.** Все ведущие главные миноры `I - A` положительны. Миноры берутся из
LU-разложения без выбора ведущего элемента: минор порядка `k` равен произведению первых `k`
диагональных пивотов, поэтому «все пивоты положительны» и есть Хокинс–Саймон; нулевой пивот — это
нулевой минор, т.е. отказ. Для `A >= 0` условие эквивалентно `rho(A) < 1` (проверяется тестом на
случайных матрицах).

**Добавленная стоимость.** `va_j = x_j - x_j * sum_i A[i][j]` — баланс по столбцу
(промежуточные затраты отрасли `j`), не мера трудоёмкости.

**Мультипликаторы.** `m_j = sum_i (I - A)^{-1}[i][j]` — полный выпуск на единицу конечного спроса
отрасли `j`.

**Сценарии.**

```
шок конечного спроса:   x' = (I - A)^{-1} (y + dy),      dx = (I - A)^{-1} dy
шок технологий:         A' = A + dA,  x' = (I - A')^{-1} (y + dy')
```

Оба сценария отказывают (исключение), если шок делает коэффициент/спрос отрицательным,
технологию непродуктивной или выпуск отрицательным: «отрицательный выпуск» не возвращается.

**SFC-контракт.** Матрица `M[holder][issuer]` — требования держателя на эмитента; одна и та же
запись одновременно актив держателя (строка) и обязательство эмитента (столбец):

```
closing = opening + transactions + revaluation      (поэлементно)
NW_i    = row_sum_i - column_sum_i
NW_closing,i = NW_opening,i + net_lending_i + revaluation_gain_i
sum_i NW_i = 0                                        (замкнутый мир)
external_c = sum_{i in c, j not in c} M[i][j] - sum_{i not in c, j in c} M[i][j]
sum_c external_c = 0                                  (межстрановые позиции погашаются)
bilateral(a,b) = -bilateral(b,a)
```

`revaluation` — единственная фаза со знаком (переоценка может быть отрицательной).

## 4. Допущения

1. Коэффициенты `A` постоянны внутри снимка; сравнение снимков — задача вызывающего кода.
2. Одна стоимостная база: нет дефляторов, валютных курсов и ППС; строки и столбцы складываются
   только внутри этой базы.
3. Нет временного шага в IO; SFC-шаг — это период учёта, а не поведенческая динамика.
4. Статистические расхождения не балансируются: несогласованная таблица отвергается.
5. SFC — учётный контракт (бухгалтерия), а не модель портфельного выбора; один класс требований,
   без разбиения по инструментам.
6. Реальный остальной мир — отдельные счета с меткой страны `ROW`; «мир» замкнут по построению.
7. Допуск сравнивается с масштабом данных (`tolerance * max(1, |величина|)`), а не абсолютно.

## 5. Критерии приёмки

| Критерий | Проверка |
|---|---|
| Баланс `x = Z 1 + y` и `x = Z^T 1 + va` | `check_balance()` ≤ `1e-9 * scale`; нарушение — исключение |
| `x > 0`, неотрицательность `Z`, `y`, `va` | `IODataset` отвергает `x <= 0` и отрицательные потоки |
| Продуктивность `rho(A) < 1` | `is_productive()`, отказ в `inverse()`/`gross_output()` |
| Хокинс–Саймон | `hawkins_simon()["pass"]`; совпадение с `rho(A) < 1` на случайных `A` |
| `(I-A)(I-A)^{-1} = I` | `matrix_inverse_product()` ≤ 1e-9 |
| Решение воспроизводит таблицу | `gross_output(y) ≈ x` (3×3 и 300 секторов) |
| Итерация сходится к прямому решению | `iterate()`: `converged`, совпадение ≤ 1e-7 |
| Агрегация без двойного счёта (I08) | суммы `Z`, `y`, `x`, `va` сохраняются, баланс сохраняется |
| Сценарии по алгебре | `dx = (I-A)^{-1} dy`, `x' = (I-A')^{-1} y`; непродуктивный/отрицательный шок отвергнут |
| SFC-инварианты | закрывающие = открывающие + транзакции + переоценка; `sum NW = 0`; `sum external = 0` |
| Детерминизм/неизменяемость | повторные вызовы дают равные результаты; входной dict копируется |
| Масштаб 10×30 = 300 секторов | валидация, `rho < 1`, Хокинс–Саймон, обратная матрица, решение |

Тесты: **20 тестов, все зелёные** (`python tests/test_io_core.py`, ~1.6 с, без сети и внешних данных).

## 6. Пример сценария с числами

Синтетическая таблица 3 страны (US, EU, CN) × 3 отрасли (AGRI, MANU, SERV), 9 секторов,
`A[i][i] = 0.15`, `A[i][j] = 0.02` при `i != j` (сумма столбца 0.31), `x = [100, 120, 80, 110, 90,
130, 95, 105, 115]`, `USD_mn`. Величины получены из `src/amfe/world/io_core.py`.

Базовая таблица: `sum x = 945`, `sum y = 652.05`, `sum va = 652.05`, `rho(A) = 0.31`,
Хокинс–Саймон пройден, все мультипликаторы `m_j = 1.449275`.

**Шок конечного спроса** `dy = +20` для US/MANU (индекс 1), остальное без изменений:

* `sum dy = 20`, `dx_total = +28.985507`, итоговый выпуск `973.985507`;
* `dx = [+0.666333, +23.654839, +0.666333, +0.666333, ..., +0.666333]` — прямой эффект в
  US/MANU и одинаковый косвенный в остальных восьми секторах;
* общий мультипликатор `dx_total / dy = 1.449275`, остаток материального баланса `2.8e-14`.

**Шок технологий** `dA[US/SERV → US/MANU] = +0.05`, `dA[CN/SERV → US/MANU] = +0.05` (US/MANU
становится ресурсоёмкой по услугам):

* `rho(A') = 0.320499 < 1`, Хокинс–Саймон после шока пройден;
* `dx_total = +17.449440`, итоговый выпуск `962.449440`;
* `dx` = `+7.320742` (US/SERV), `+7.320742` (CN/SERV), `+0.401137` в остальных семи секторах.

**SFC-пример** (5 счетов: US_HH, US_FIRM, US_GOV, EU_HH, EU_FIRM). Открывающие требования:
US_HH на US_FIRM 20 и на US_GOV 5; US_FIRM на EU_HH 10. Транзакции: US_HH +2 к US_FIRM,
US_FIRM +1 к EU_HH. Переоценка: требование US_FIRM к EU_HH −3. Закрывающие чистые стоимости:
US_HH `+27`, US_FIRM `−14`, US_GOV `−5`, EU_HH `−8`, EU_FIRM `0`; сумма `0`. Внешняя позиция
US `+8`, EU `−8`, сумма `0`; закрывающие = открывающие + транзакции + переоценка поэлементно,
все остатки `≤ 1e-12`, `consistency()["pass"] = true`.

## 8. Ограничения

1. **Нет реальных данных и калибровки.** Таблица из §6 синтетическая; при подключении MRIO
   (WIOD/OECD ICIO и т.п.) понадобится политика согласования статистических расхождений, которой
   здесь намеренно нет: текущий контракт отвергает несогласованную таблицу.
2. **Статика.** Коэффициенты не меняются во времени; EQ-IO-002 (динамика) не реализована.
3. **Нет цен и валют.** Одна стоимостная база; пересчёт текущих/постоянных цен, ППС и курсов —
   отдельный слой.
4. **SFC отделён от IO.** Согласование SFC-счетов с IO (доходы, сбережения, капитальный счёт) не
   построено: реализован только учётный контракт потоков/запасов и межстранового погашения.
5. **Один класс требований в SFC.** Разбиение по инструментам (депозиты, кредиты, облигации,
   equity) — расширение третьей размерности, инварианты должны проверяться по каждому инструменту.
6. **Стоимость вычислений.** `(I-A)^{-1}` — плотная `O(n^3)`; для 300 секторов это доли секунды,
   для тысяч секторов нужна разреженная алгебра.
7. **Численные допуски.** Порог `1e-9` относительный; на плохо обусловленных реальных таблицах
   возможны предупреждения о продуктивности у границы `rho ≈ 1`.
8. **Нет неопределённости.** Интервалы, винтажи и вероятностные сценарии не моделируются: ядро
   детерминировано по построению.
9. Никаких заявлений о прогностическом качестве: это вычислительное и проверочное ядро, а не
   модель прогноза.

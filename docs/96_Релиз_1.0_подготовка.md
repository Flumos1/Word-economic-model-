1. **Допущенная модель (admitted model).** Ни один кандидат не прошёл C4 (структурно) и C6; статусы
   `SHADOW_TEST`/`LIMITED_DEPLOYMENT`/`ACTIVE` не присвоены. Релиз не является допуском.
2. **C6 / forward-подтверждение.** `registry/forecasts.jsonl` открыт 2026-11-12, записей 0;
   ≥12 разрешённых прогнозов появятся не раньше 2027-11.
3. **Закрытие C4/W1 и протокол v5.** Есть только анализ и черновик v5 (docs/88); протокол v4
   остаётся замороженным, решение — за владельцем.
4. **Первая реальная оценка T2 (рост ВВП), T3 (рецессия) и окна W3.** W3 загрязнено знанием
   эпизода; T2/T3 требуют отдельного прогона.
5. **DFM/FRED-MD** как член компаратора (реестр UNVERIFIED, не используется).
6. **SPF как член основного компаратора** (маппинг T2 готов, docs/86; T1/T3 не маппятся).
7. **Незавершённые треки третьей волны** (docs/93–95, 97–99) — поставляются параллельно волной
   D-148 и в этот релизный коммит не входят.
8. **Сырые сторонние данные** в репозитории (запрещено `licence_policy`; только приватные
   артефакты, retention 90 дней) и **обучение ML/LLM на данных FRED/ALFRED**.
9. **Утверждения о превосходстве платформы** за пределами T1 CPI г/г h=1 — нужны T2/T3, закрытие
   C4 и forward-доказательства C6.
10. **Юридические выводы** из лицензионных аудитов (docs/84, docs/90 — чтение условий, не
    юридическая консультация).

## 5. Инструкция воспроизведения

Требования: Python 3.11+ (CI — 3.11; локально проверено 3.12), `numpy`; git; для data-зависимых
тестов — доступ к приватным артефактам (GitHub CLI с правами `actions: read`) или свой прогон
`data-refresh`.

```bash

cd Word-economic-model-
git checkout <коммит релиза 1.0; после тегирования — v1.0.0>
python -m pip install numpy

# 1) артефактные проверки без регрессии (быстро)

python tools/release_check.py --date 2026-11-12 --out build/release_check.json \
  --markdown-out build/release_check.md

# 3) полная сводная регрессия (альтернативный запуск)
python tools/regression_report.py --json-out build/regression_report.json

# 4) недельный интеграционный бюллетень
python tools/weekly_report.py --date 2026-11-12 --out build/weekly_report.md
```

- `release_check` без `--skip-tests` возвращает exit 2 (CONDITIONAL), а не 0: «0 блокеров» не
  означает «релиз тегирован».

## 9. Как обновлять release notes

1. Пересчитать LF-нормализованные SHA-256 замороженных артефактов и отчётов:
   ```
   python -c "import hashlib,sys; b=open(sys.argv[1],'rb').read(); print(hashlib.sha256(b.replace(b'\r\n', b'\n')).hexdigest())" protocols/r3_specification.json
   ```
2. Обновить `protocols/release_notes_1.0.json` (разделы `frozen_artifacts`, `artifacts`, `status`,
   `data`, `verification`, `ci`) и таблицу в §4 этого документа.

   `python tools/release_check.py --skip-tests=true` (статус).
4. После изменения `licence_register.json`/`composition` — перегенерировать состав компаратора и
   его пин (это делает соответствующий трек), затем повторить п.1–3.

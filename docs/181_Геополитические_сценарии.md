# 181. Библиотека геополитических сценариев (блок 16, M16)

Дата: 2026-11-18. Задача: `task-63` (docs/177 §4.2, M16; docs/174 кейсы UC-19/40/41/05/07/22).
Статус: **RESEARCH_ONLY, `gating=false`, `causal_claim=false`** — сценарий не является прогнозом,
причинным выводом или инвестиционной рекомендацией; допуска нет.

Артефакты:
- [`protocols/geopolitics_scenarios.json`](../protocols/geopolitics_scenarios.json) — декларативная
  библиотека (schema `AMFE-GEOPOL-SCENARIO/1.0.0`), **15 сценариев**;
- [`tools/geopolitics_scenarios.py`](../tools/geopolitics_scenarios.py) — валидация + прогон через
  существующий MRIO-движок (`world_pipeline`/`world_reports`), отчёты только агрегатами;
- [`tests/test_geopolitics_scenarios.py`](../tests/test_geopolitics_scenarios.py) — **22 теста**;
- отчёты прогонов: `build/geopolitics/` (git-ignored).

## 1. Что это

Библиотека описывает геополитический шок как **данные**: семейство, акторы, секторы, канал,
размер, длительность, затухание, направление, источник, PIT-дата, допущения. Инструмент проверяет
запись, строит возмущение и считает сравнительную статику на MRIO (FIGARO 2019: 50 стран × 64
отрасли CPA; сырые таблицы в git не хранятся). На выходе — страна×отрасль маргиналы, топ-списки и
несколько ячеек, без `Z/x/y/va` и без сырых рядов.

## 2. Состав библиотеки (15 сценариев)

| Семейство | Кол-во | Примеры |
|---|---:|---|
| `sanctions` | 3 | Иран-2018 (USA + партнёры), Россия-2022 (DEU/POL/ITA/FIN и DEU/USA/GBR/NLD) |
| `tariffs` | 3 | CHN→USA, DEU/FRA/ITA→USA, CHN→DEU/FRA/ITA/NLD/ESP/BEL |
| `export_restriction` | 3 | ограничения экспорта сырья/технологий |
| `conflict` | 2 | конфликт с торговым/логистическим каналом |
| `industrial_policy` | 2 | субсидии/протекция (from = to = страна) |
| `chokepoint` | 1 | Ормуз/пролив |
| `agreement` | 1 | торговое соглашение/диверсия |

Поля записи: `family`, `actors` (`from`/`to`, ISO3), `sectors` (CPA/FIGARO), `channel`
(trade/price/demand diversion), `size`, `duration`, `decay`, `direction`
(`damage`/`both`/`gain`), `source`, `pit_date`, `assumptions`. Валидатор отвергает дубликаты id,
неизвестные страны/секторы, размеры вне границ, битые записи; прогон fail-closed: нет протокола
или данных → `BLOCKED_*` (exit 2), ошибка записи/балансов → exit 1, ничего не пишется.

## 3. Асимметрия и исторические якоря

- **P-008:** у каждого отчёта есть блок beneficiaries. Для чистого барьера (санкции/тариф,
  сжимающий межстрановые коэффициенты) положительных ячеек нет — `beneficiaries.status = none`,
  «выгод нет»; для declared diversion (переключение спроса) выгодоприобретатели считаются и
  проверяются на zero-sum.
- **Sign-only:** Иран-2018 и Россия-2022 проверяются **только по знаку** трёх ячеек
  страна×отрасль; блок direction-check не публикует величин и не является причинной оценкой.
- `gating=false` и `causal_claim=false` проверяются тестами во всех отчётах.

## 4. Запуск

```bash
# весь пакет (нужен локальный MRIO-датасет; см. docs/146)
python tools/geopolitics_scenarios.py --dataset figaro_2019 --out build/geopolitics

# только выбранные сценарии
python tools/geopolitics_scenarios.py --only sanctions_iran_2018,sanctions_russia_2022

# синтетический прогон без приватных данных (для CI/демо)
python tools/geopolitics_scenarios.py --synthetic --json

# проверка библиотеки без прогона
python -m unittest tests.test_geopolitics_scenarios
```

## 5. Тесты (22)

Покрыто: покрытие acceptance-требований (≥12 сценариев, ≥4 семейства, ≥6 стран, ≥10 отраслей);
обязательные поля и границы; sign-only direction-check; дубликаты/коллизии сигнатур; битые
записи; прогон всех сценариев с PASS-балансами; отсутствие raw в отчётах; побайтовый детерминизм
и digest от параметров; явные `beneficiaries=none` для чистого барьера и найденные выгоды для
diversion; zero-sum diversion; согласованность асимметрии с маргиналами; затухание как
декларация, не динамика; якоря Россия-2022/Иран-2018 по знаку; отсутствие величин в
direction-check; fail-closed (нет протокола / невалидный протокол / неизвестный актор или сектор);
CLI synthetic; `gating=false`, `causal_claim=false` везде.

## 6. Ограничения (честно)

1. **Сравнительная статика**, не динамика: длительность/затухание — декларация, не временной ряд.
2. **Не причинный вывод:** сценарий показывает направление и относительный размер при заданных
   допущениях; исторические якоря — только знак.
3. **FIGARO 2019** — один срез; перенос на другие годы не проверен.
4. Нет поведенческих реакций, финансового канала, вторичных санкций и эндогенного ответа политики.
5. Библиотека — экспертные допущения; источники/PIT указаны, но не верифицированы внешним аудитом.
6. Блок 16 остаётся **prototype** (docs/177); кейсы UC-19/40/41/05/07/22 остаются PARTIAL.

# 128. GVAR на реальных межстрановых данных (World Bank) — первый OOS-прогон

Дата: 2026-11-14. Статус: **реальный прогон выполнен; GVAR прототип на агрегатах не превосходит
AR(1) — отрицательный/смешанный результат, заявлений о преимуществе нет.** Файлы:
[tools/gvar_real.py](../tools/gvar_real.py), [tests/test_gvar_real.py](../tests/test_gvar_real.py);
модель — существующий [src/amfe/world/gvar.py](../src/amfe/world/gvar.py) (не изменялась, docs/123).
Кэш сырых ответов API и отчёт с числами — `data/mrio/wb/` (в git не коммитится).

## 1. Данные и лицензии

* Источник: **World Bank WDI API** (`https://api.worldbank.org/v2/...`), без ключа. Скачивание
  проверено; ответы кэшируются в `data/mrio/wb/wb_<INDICATOR>.json` вместе с URL и временем
  получения (повторный прогон без сети использует кэш; `--refresh` перекачивает).
* Индикаторы: `NY.GDP.MKTP.KD.ZG` (реальный рост ВВП, % — переменная `g`), `FP.CPI.TOTL.ZG`
  (инфляция CPI, % — `pi`), `NY.GDP.MKTP.CD` (ВВП в текущих USD — для агрегатов и весов),
  `NE.TRD.GNFS.ZS` (торговля/ВВП), `SP.POP.TOTL` (население).
* Годы: **1995–2024** (30 наблюдений на страну). Лицензия WDI — открытые данные (CC BY 4.0);
  сырые значения в репозиторий не пишутся, в отчёт попадают только производные числа.
* Покрытие: запрошено **55** экономик, полный ряд 1995–2024 имеют **53** (полный список — в
  `sample.country_codes` отчёта); отсеялись `ARG` и `ARE` — в WDI у них пропуски роста или инфляции
  внутри окна. Панель: 53 страны × 30 лет × 2 переменные.
* **Веса.** World Bank API не даёт двусторонней торговли. По умолчанию используется
  прокси-модель **GDP-share**: `w_ij = GDP_j / Σ_{k≠i} GDP_k`, `w_ii = 0`, средние уровни ВВП за
  окно. Если существует `data/mrio/figaro/dataset.json` (или `data/mrio/dataset.json`) с полем
  `trade_weights`, раннер читает его только на чтение и использует вместо прокси (тест
  подтверждает, что файл не изменяется). В этом прогоне MRIO-файла не было → веса GDP-share.

## 2. Спецификация

GVAR прототип (doi: `src/amfe/world/gvar.py`): для каждой страны

```
y_it = c_i + Σ_{l=1..p} A_il y_i,t-l + Σ_{l=1..p} B_il y*_i,t-l + e_it,
y*_it = Σ_{j≠i} w_ij y_jt,       y_it = (g_it, pi_it).
```

Оценка — OLS поэлементно на сбалансированной панели; стабильность — по глобальной companion-форме
`N·K·p`; IRF — по той же форме; прогноз — детерминированный, h=1..4.

Базовые модели: **AR(1)** с константой (по каждой стране/переменной, рекурсивно) и **random walk**
(последнее наблюдение). OOS — расширяющееся окно: начала 2010–2023 (14 начал), h=1..4; горизонт h
оценивается на всех началах, где есть фактическое значение. Агрегаты: US, EA (18 стран еврозоны из
панели), CN, WORLD (все 53, веса по ВВП). Метрики — RMSE и MAE в процентных пунктах.

Оценки на полной выборке: **p=1 стабилен** (макс. модуль собственного числа 0.8464, 30 наблюдений,
2 переменные), **p=2 нестабилен** (1.3166). В rolling-окнах: p=1 стабилен в 6 из 14 начал, p=2 — в 0
из 14; p=2 включён в таблицы как есть (его OOS-ошибки хуже почти везде — это ожидаемо для
нестабильной системы и является диагностикой, а не «моделью-победителем»).

## 6. Итог сравнения

* **Агрегаты.** На WORLD h=1 GVAR_p1 проигрывает AR(1): рост 2.5104 против 2.3271, инфляция 1.5423
  против 1.4386; на h=2–4 WORLD GVAR_p1 немного лучше AR(1) по росту (2.0433/2.0791/2.1777 против
  2.1252/2.1145/2.1870). На US и EA AR(1) лучше почти на всех горизонтах и обеих переменных; на CN
  по росту GVAR_p1 лучше AR(1) на h=2–4 (2.1736/2.7348/2.9632 против 2.1566/2.8200/3.0015 — на h=2
  хуже), но по инфляции AR(1) заметно лучше (1.1683 против 1.7338 на h=1).
* **Страны.** По росту h=1 GVAR_p1 лучше AR(1) лишь в 9 из 53 стран и лучше RW в 32 из 53; по
  инфляции h=1 — лучше AR(1) в 33 из 53 и лучше RW в 46 из 53. Медианные RMSE по странам: рост h=1
  GVAR 3.0691 / AR(1) 2.8084 / RW 3.1483; инфляция h=1 GVAR 2.8009 / AR(1) 2.7655 / RW 3.5203.
* **Вывод.** Торгово-взвешенные внешние факторы не дают устойчивого выигрыша над простым AR(1) на
  агрегатах; GVAR_p1 систематически лучше random walk (это ожидаемо — RW не использует динамику), но
  хуже AR(1) там, где важны собственные лаги (US, EA). p=2 нестабилен и не рассматривается как
  рабочий вариант. **Никакого заявления о преимуществе GVAR нет.**

## 7. Ограничения

1. **Веса — прокси.** GDP-share вместо двусторонней торговли; при появлении MRIO `trade_weights`
   прогон повторится автоматически (код читает файл), и веса станут торговыми.
2. **Короткие ряды.** 30 годовых наблюдений, rolling-оценки на 15–27 наблюдениях: оценки VARX(p)
   шумные, p=2 нестабилен на полной выборке и во всех rolling-окнах.
3. **Эндогенность/идентификация.** GVAR — reduced-form; IRF по Cholesky/unit-шоку зависит от
   упорядочивания стран и переменных; причинных выводов нет. Слабая экзогенность внешних факторов
   предполагается, но не тестируется.
4. **Нет point-in-time.** WDI — текущая редакция: GDP и CPI пересматриваются, OOS-ошибки смещены
   в пользу моделей, «знающих» пересмотры; для честного OOS нужны винтажи (ср. D-147 в проекте).
5. **Кризисы в OOS.** 2020–2023 (COVID, инфляционный всплеск) дают большие ошибки; в отдельных
   странах (TUR, BGR, IRN, ROU) инфляция в десятки процентов — RMSE там не сопоставим с остальными
   и приведён отдельно, без победителя.
6. **Агрегаты — не модель.** US/EA/CN/WORLD считаются как взвешенное среднее прогнозов стран, а не
   как отдельные агрегатные уравнения; агрегатные ряды в GVAR не входят.
7. **Данные не в git.** Кэш `data/mrio/wb/` и `gvar_report.json` — производные артефакты, не
   коммитятся; воспроизведение требует сети (или сохранённого кэша).
8. **Это не допуск.** GVAR не подключён к протоколу допуска, к forward-registry и не является
   кандидатом; результат — исследовательский OOS-прогон.

## 8. Воспроизведение

```
python tools/gvar_real.py                     # кэш/скачивание, OOS, data/mrio/wb/gvar_report.json
python tools/gvar_real.py --refresh           # перекачать WB
python tools/gvar_real.py --lags 1,2 --max-h 4 --origins 15
python tests/test_gvar_real.py                # 17 тестов, без сети (фикстура WB-ответа)
```

Отчёт: `data/mrio/wb/gvar_report.json` — покрытие, веса, стабильность, IRF, метрики по агрегатам и
странам/горизонтам, `report_sha256`; `oos.metrics` — RMSE/MAE/n по (модель × группа × переменная ×
горизонт); `oos.per_country` — по странам. Все числа в §3–5 получены из него.

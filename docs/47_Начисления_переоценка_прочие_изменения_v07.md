# AMFE-17 — расширение однострановых счетов v0.7
Дата: 2026-11-11. Код: src/amfe/extended_accounts.py; тесты: tests/test_extended_accounts_v07.py.

## Новые операции
1. **Начисление зарплаты**: возникает дебиторская задолженность домохозяйств (+) и кредиторская задолженность фирмы (−), меняются доходы/чистая стоимость, но не банковские депозиты.
2. **Погашение начисленной зарплаты**: сокращается задолженность, депозит фирмы уменьшается, депозит домохозяйств увеличивается; новое изменение чистой стоимости равно нулю.
3. **Переоценка реального актива**: меняет балансовую стоимость запасов или основного капитала без операции текущего счёта.
4. **Прочее изменение объёма актива**: списание/потеря стоимости актива без сделки; отдельно от переоценки и от текущих операций.

## Расширенное тождество
Для каждого сектора s и периода:
NW_s(t+1)−NW_s(t) = C_s + R_s + O_s,
где C_s — изменения чистой стоимости от транзакций, R_s — переоценка, O_s — прочие изменения объёма. Для транзакций C_s=ΔReal_s+ΔNFA_s; для каждого финансового инструмента Σ_s ΔF_(s,j)=0. Доказательство по индукции из docs/46 сохраняется при добавлении независимых R/O-строк к изменению реальных активов: на каждом шаге изменение NW равно сумме соответствующих компонент. Это **структурная** теорема, не проверка рыночной оценки и не доказательство экономической адекватности.

## Пример
Начисление зарплаты 25: фирма −25 чистой стоимости, домохозяйства +25, денежный остаток не меняется. Платёж 10 уменьшает непогашенную задолженность до 15, не меняя уже начисленный доход.
Производство 40, переоценка +5, прочая потеря −3: конечная стоимость запасов 42, из которых 40 — изменение по операциям, +5 — переоценка, −3 — прочее изменение.

## Ограничения
- Добавлена только задолженность фирмы перед домохозяйствами по зарплате, без универсальной дебиторской задолженности, кредиторских договоров и процентов к начислению.
- Переоценка/прочие изменения реализованы **только для реальных активов фирмы**. Переоценка финансовых инструментов и зеркальная оценка обеих сторон обязательства не реализована.
- Реальный капитал и запасы пока в единой условной стоимостной единице; отдельные цены/количества и метод оценки отсутствуют.
- Не введены полноценные счета образования, распределения и использования дохода, валовые/чистые сбережения, капитальные трансферты, налоги на продукты и систему SNA 2008.
- Низкоуровневый конструктор Transaction v0.6 проверяет алгебру, но не все ограничения экономической семантики по имени операции.
- Существующие проверки v01–v07 включены в GitHub Actions; удалённый PASS не подтверждён.

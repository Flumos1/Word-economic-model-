## Что изменено по сравнению с v1

| № | Изменение |
|---|---|
| M1 | Скользящее окно оценивания 180 месяцев / 60 кварталов (чувствительность 120 и 240); рекурсивный вариант допустим только с тестом Clark–West и в допуск не засчитывается |
| M2 | Сравниваются прогностические методы (модель, окно, процедура), а не истинность моделей |
| M3 | Основной компаратор — равновесная комбинация базовых моделей; окно отбора 1985–1989 удалено |
| M4 | Записана глубина версий данных; прогнозы делятся на REAL_TIME и PSEUDO_REAL_TIME, в допуск идут только первые; панель ALFRED для DFM до 1999 года — задача R2; лицензионные заметки |
| M5 | SPF убран из оцениваемых баз T3 (его «рецессия» — отрицательный рост ВВП); добавлено правило Сам; SPF для T3 — только описательный |
| M6 | Сравнения с SPF — на датах сроков возврата анкет SPF |
| M7 | C6 считает **разрешившиеся** прогнозы (не менее 12); без 8 независимых исходов длинные горизонты ограничены статусом LIMITED_DEPLOYMENT |
| M8 | C4 — тест Giacomini–White с инструментом «индикатор рецессии NBER» |
| M9 | Порог C1 = min(0,97; 5-й процентиль «шума» из симуляции NF-SIM), исследование выполняется и замораживается до оценки кандидатов |
| M10 | Основной контроль множественных проверок — Romano–Wolf stepdown (FWER 0,10); Benjamini–Hochberg — вторичный |
| M11 | C3 (множество уверенности моделей) только отчётный, не блокирующий |
| M12 | Оцениваемый прогноз — точное распределение; неточные вероятности — только в сценарном слое |
| M13 | Модели-основания и LLM: те же версии данных; результат засчитывается лишь из журнала будущих прогнозов, периода после даты отсечения знаний либо хронологически согласованной модели; иначе CONTAMINATED |
| M14 | Для 2020-03…2021-02 обязательны робастный вариант и вариант с исключением периода; W3 в допуск не идёт |

Дополнительно в журнал будущих прогнозов добавлены контрольные группы (RW, равновесная комбинация, SPF, внешние наукасты) и фиксация версии правила оценки.

## Известные ограничения черновика
- Размеры выборок в NF-SIM взяты из длины окон W1 и W2 (тест проверяет это соответствие); сама симуляция не выполнена, значение q05 неизвестно.

- Тест Romano–Wolf и поправка HLN указаны названиями; параметры реализации (число бутстрэп-повторов, блочная длина) определяются на R3.

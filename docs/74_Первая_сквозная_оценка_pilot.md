# AMFE — первая сквозная оценка: pilot проверки конвейера (2026-11-11)
Версия 1.1.0 · 2026-11-11. Отчёт: [protocols/first_evaluation_report.json](../protocols/first_evaluation_report.json) (SHA-256 `e942ca27…84c4`). Код: [tools/run_first_evaluation.py](../tools/run_first_evaluation.py). Запуск: `python tools/run_first_evaluation.py --start 2018-01-01 --end 2019-12-31 --mode latest`. **Это pilot проверки конвейера, а не результат допуска: `pilot=true`, `admission=false`, `data_class=PSEUDO_REAL_TIME`.**

## Зачем
Впервые собраны в один прогон все слои: PIT-данные → семь базовых моделей → зафиксированный состав компаратора → потери, пороги NF-SIM и C1/C2 из harness. Цель — проверить, что интерфейсы и правила согласованы до честной вневыборочной оценки; пилот не даёт и не может дать статус кандидата.

## Постановка пилота (и явные ограничения)
- Окно W2, начала 2018-01…2019-12. Кандидаты — **члены компаратора** (проверка конвейера, не реальные кандидаты); компаратор — равновесное среднее этих членов, отчёт `pilot_only=true`, `ranking="none"`.
- `mode="latest"` — `data_class=PSEUDO_REAL_TIME`: винтажный архив разрежен (10 годовых винтажей 1996–2020); admission на таких данных **запрещён** (guard в `tools/evaluate.py`, R3 0.7 и docs/73).
- Фактические значения — из последней версии ряда (first-publication actuals — отдельный слой R2).
- **T3-метки** считаются по записанным датам объявлений NBER (`protocols/nber_dates.json`): метка входит в оценку, только если объявление, покрывающее её, было до origin (cutoff = последняя объявленная впадина минус горизонт). T3-числа — выход конвейера, не результат.
- Порог C1 берётся из NF-SIM для полной длины W2; для короткого поддиапазона 2018–2019 он не является статистически корректным (оговорено в отчёте полем `threshold_caveat`).
- Плотностные потери (CRPS смеси) и окно W1 отложены.

## Что было найдено и исправлено после независимой проверки (docs/73)
- **T3-метки:** фиксированный 12-месячный лаг заменён на даты объявлений NBER (иначе look-ahead до 21 месяца для впадин 1991, 2001, 2009, 2020). Добавлены тесты на cutoff для 1991/1993/2009/2021/2022.
- **data_class guard:** `evaluate_admission()` теперь требует класс данных и блокирует допуск на PSEUDO_REAL_TIME/UNSTATED (только CANDIDATE).
- **R3-спецификация 0.7:** убраны неверные утверждения («кода нет», «даты NBER не скачаны», «12-месячный лаг — консервативный»), обновлены хеши кода и факты ворот R2 (87 пар, GDPC1 40/40).

## Что пилот не доказывает
Не является допуском; нет W1, C3–C6 и множественных проверок; данные PSEUDO_REAL_TIME; actuals — последняя версия; плотности не подключены; диапазон начал для h=12 выходит за границу W2 по цели (допустимо только для pipeline, не для оценки).

## Следующие шаги

4. Заморозка R3 после сверки дельты — и только затем первая реальная оценка зарегистрированных кандидатов.

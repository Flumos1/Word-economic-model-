## Зачем
Впервые собраны в один прогон все слои: PIT-данные → семь базовых моделей → зафиксированный состав компаратора → потери, пороги NF-SIM и C1/C2 из harness. Цель — проверить, что интерфейсы и правила согласованы до честной вневыборочной оценки; пилот не даёт и не может дать статус кандидата.

## Постановка пилота
- Окно W2, диапазон начал 2018-01…2019-12 (T2 h=4 — квартальные начала, поэтому их 4; T3 h=12 — 12; T1 h=12 — 13).
- `mode="latest"` — локальный винтажный архив разрежен (10 годовых винтажей 1996–2020), поэтому все прогнозы помечаются PSEUDO_REAL_TIME.
- Фактические значения — из последней версии ряда (first-publication actuals — отдельный слой R2).
- Кандидаты в пилоте — **члены компаратора** (проверка конвейера, не реальные кандидаты); компаратор — равновесное среднее этих членов.
- Плотностные потери (CRPS смеси) и окно W1 отложены; в отчёте явно перечислены `deferred`.

## Чего пилот не доказывает (важные ограничения)
1. **Не является допуском**: нет W1, нет C3–C6, нет множественных проверок, кандидаты — члены компаратора, а не зарегистрированные кандидаты.
2. **Не REAL_TIME**: `mode="latest"`; при разреженном винтажном архиве origin 2019 берёт винтаж 2013 (формально PIT, но устаревшая информация). Честная оценка требует плотного винтажного архива (следующий шаг R2).
3. **Actuals — последняя версия**, а не первая публикация; это меняет и уровень, и сравнение.
4. **Плотности не проверены**: CRPS смеси и пул квантилей ещё не подключены; отчёт ограничен RMSE/Brier/log score.
5. Диапазон начал пилота для h=12 выходит за границу W2 по цели (пилот фильтрует только начала) — это допустимо для проверки конвейера, но не для оценки.

## Что нашлось при интеграции
- Все интерфейсы (`DataContext`, `forecast`, `target_actual`, composition, `evaluate`) согласованы; PIT-слой не даёт данных после origin; отказы моделей изолированы.
- Расхождение, найденное и исправленное до запуска: composition-документ хранит членов по (потеря, горизонт) — раннер сначала читал их неверно; исправлено (`members_for`).
- Разреженность винтажей и отсутствие first-publication actuals — главные ограничители честной оценки; оба входят в R2/R3-план.

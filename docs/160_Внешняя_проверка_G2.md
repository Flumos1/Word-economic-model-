## 4. Границы: что означает `PASS`

1. **Проверяется арифметика, а не экономика.** Ревьюер подтверждает, что числа в документах
   соответствуют JSON-артефактам и что границы заявлены. Экономическая обоснованность выбора
   (эластичности, доли корзин, сценарий Ормуза) — не его предмет.
2. **Артефакты не перезапускаются** (кроме ABM-демо): прогон каждого моста занимает минуты, а
   требование — проверить опубликованное. Поэтому «PASS» относится к артефактам того прогона,
   хеши которого зафиксированы.
3. **Хеши артефактов берутся из документов.** Если артефакт перегенерирован после написания
   документа, хеш «протухает» и замечание MEDIUM/LOW возвращается — это намеренное поведение,
   а не шум.
4. **Сканы текста — эвристика**: паттерны запрещённых claims и окно отрицаний не понимают смысл
   предложения целиком; ложные срабатывания возможны, и их нужно разбирать руками.
5. **Человеческая подпись обязательна.** `READY_FOR_HUMAN_SIGN_OFF` значит только, что
   автоматических блокеров нет; подпись в docs/160 ставит человек, и ревьюер не присваивает ни
   допуск, ни статус CANDIDATE/SHADOW_TEST.
6. **Сырые данные не читаются**: ревьюер работает только с производными агрегатами в `build/` и не
   копирует сторонние ряды.
7. **Исключение для публично-доменных агрегатов** (волна 24): файл под `data/` с расширением
   `.csv` допускается, только если он в явном allow-list, рядом лежит provenance-сайдкар с
   лицензией «public domain», серией и совпадающим SHA-256; иначе G8 даёт BLOCKER/HIGH.
   Это соответствует политике docs/84 («производные агрегаты — если лицензия позволяет»).

## 6. Воспроизведение

```powershell
python tools/external_review_g2.py                     # полный прогон, пишет build/external_review_g2/
python tools/external_review_g2.py --no-abm --no-help   # быстрый режим (без ABM/--help)
python tools/external_review_g2.py --no-write --json   # отчёт в stdout, ничего не пишет
python tools/external_review_g2.py --repo <path>        # проверка другой копии репозитория
python tests/test_external_review_g2.py                # 13 тестов
```

Коды возврата: `0` — `PASS`/`PASS_WITH_FINDINGS`; `1` — `FAIL` (есть BLOCKER/HIGH); `2` — ревью
не может выполниться (нет обязательного входа), ничего не записано.

## 7. Ограничения

1. **Автоматический чек-лист**, а не независимый эксперт: он проверяет числа и структуры, но не
   воспроизводит экономические решения G2.
2. **Паттерны привязаны к формату документов**: число, записанное в неожиданном формате, будет
   «не найдено» (замечание), а не «угадано»; изменение формата документов требует правки паттернов
   и тестов.
3. **Хеши живут один прогон**: артефакты с `generated_at`/`seconds` не байт-детерминированы, поэтому
   документ обязан фиксировать конкретный прогон.
4. **Подпись человека** не автоматизируется; `READY_FOR_HUMAN_SIGN_OFF` — не допуск.
5. **Нет проверки лицензионной совместимости** источников и полноты данных — это реестр источников
   (docs/162), а не ревьюер.
6. **Тесты ревьюера проверяют ревьюера, а не модель**: они ловят регрессии чек-листа, но не
   «правильность» G2-чисел.

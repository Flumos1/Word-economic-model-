# 123. GVAR-прототип: межстрановой VARX с торговыми весами

Дата: 2026-11-14. Волна 8. Статус: **прототип P2, к admission-протоколу НЕ подключён**;
frozen-файлы, registry и tools не менялись. Код: `src/amfe/world/gvar.py`;
тесты: `tests/test_gvar.py` (14 tests OK). Основание: docs/56 §2.4 — «GVAR как первый межстрановой
кандидат (дёшево, проверено), торговые веса — из MRIO».

## 1. Зачем и границы

Первый дешёвый межстрановой динамический кандидат: страновые VARX(p) с глобальными факторами,
взвешенными по торговым весам. Это **не** полноценная GVAR-модель (нет оценённых весов, нет
финансовых запасов, нет реальных данных) и **не** кандидат на admission: результат прототипа не
сравнивается с компаратором и не претендует на статус. Цель — исполняемый, детерминированный и
тестируемый каркас, на который можно навесить реальные данные и предрегистрацию.

## 2. Модель

Для страны `i` (K переменных, p лагов):

```
y_i,t = c_i + Σ_{l=1..p} A_i,l · y_i,t−l + Σ_{l=1..p} B_i,l · y*_i,t−l + ε_i,t
y*_i,t = Σ_{j≠i} w_ij · y_j,t ,   Σ_{j≠i} w_ij = 1,  w_ij ≥ 0,  w_ii = 0
```

- `y*_i` — «глобальный фактор»: средневзвешенное по торговым весам состояние остальных стран.
- Это дискретный переход специального вида — частный случай **EQ-DYN-001** (docs/53);
  наблюдение — шумное наблюдение **EQ-OBS-001** (винтажи в прототипе не моделируются).
- Веса `w` — **вход** (схема MRIO), а не оцениваемый параметр; в прототипе они постоянны во времени.
- Динамика линeйна, без режимов, без контеграции, без финансовых потоков, FX и денежной политики.

## 3. Идентификация

- **Оценка:** OLS по уравнению, на сбалансированной панели (одинаковые переменные и длины рядов у
  всех стран), регрессоры — константа, собственные лаги и лаги глобального фактора.
- **Допущение:** слабая экзогенность иностранных факторов для малой открытой экономики (стандартное
  допущение GVAR). Оно **не тестируется** в прототипе и раскрыто как ограничение; при реальных
  данных требуется отдельная проверка (см. §6).
- **Структурные IRF:** нижний множитель Холецкого глобальной ковариации остатков; порядок —
  страны в порядке `dataset["countries"]`, переменные отсортированы. Порядок произволен и влияет на
  мгновенные отклики — это disclosed limitation. Альтернатива `method="unit"` — шок в одну
  наблюдаемую серию без ортогонализации.
- **Стабильность:** глобальная компаньон-форма размерности `N·K·p`: страновые уравнения
  складываются в один VAR(1) состояния `[Y_t, Y_{t−1}, …, Y_{t−p+1}]`, блоки `(i,j)` при `i≠j`
  равны `w_ij·B_i,l`. Собственные числа включают межстрановые spillover'ы; стабильность ⇔ все
  |λ|<1.
- Кросс-страновые ограничения на коэффициенты не накладываются; GMM/Bayes не используются.

## 4. Интерфейс и API

Вход:

```python
dataset = {
  "countries": ["A", "B", "C"],
  "series": {"A": {"x": [..], "z": [..]}, "B": {...}, "C": {...}},
  "weights": {"A": {"B": 0.6, "C": 0.4}, "B": {"A": 0.5, "C": 0.5}, "C": {"A": 0.3, "B": 0.7}},
}
```

`GVAR(dataset, lags=p)`:

- `model.is_stable()` / `model.stable` / `model.stability()` — собственные числа, `max_modulus`;
- `model.irf(country, variable, horizons=12, shock_size=1.0, method="unit"|"cholesky")` — отклики
  всех стран/переменных по горизонтам 0…H;
- `model.forecast(steps=4)` — детерминированные траектории h=1..4 для всех стран/переменных;
- `model.export_coefficients()` / `model.to_json()` / `model.digest()` — экспорт коэффициентов
  (JSON, без сырых рядов, с идентификацией и оговорками), канонический JSON и SHA-256;
- `model.coefficients[country]` — матрица `(K, 1+2Kp)`: `[c, A_1..A_p, B_1..B_p]`;
  `model.residuals[country]`, `model.residual_covariance()`.

**Fail-closed** (`GVARError`): нет `countries`/`series`/`weights`; пустой или дублирующий список
стран; несовпадение множеств стран; разные наборы переменных; разные длины рядов; NaN/inf;
слишком короткий ряд для числа параметров; отрицательные веса; неизвестная страна в весах;
ненулевой собственный вес; строка весов не суммируется в 1 (для входа `GVAR`); `lags<1`;
неизвестная страна/переменная/метод в `irf`. Для сырых торговых долей есть
`normalize_weights(weights, countries)` — нормирует строки в 1.

## 5. Проверка на синтетике с известной динамикой

DGP: 3 страны, 1 переменная, `own=0,5`, `foreign=0,2`, независимый шум σ=0,005, n=2000
(seed 11), веса как в §4. Оценка `lags=1`:

| Страна | c | A (own) | B (foreign) | resid std |
|---|---|---|---|---|
| A | 0,0001 | 0,4998 | 0,2130 | 0,00507 |
| B | 0,0002 | 0,5093 | 0,2038 | 0,00504 |
| C | −0,0001 | 0,5022 | 0,2112 | 0,00502 |

Истинные 0,5/0,2 восстанавливаются в допуске 0,03 (конечная выборка, персистентность). Глобальная
стабильность: `max_modulus = 0,713`, dimension 3; нестабильный DGP (`own=1,05`) даёт
`max_modulus > 1` и `stable=False`.

Пример IRF (unit-шок +1 в серию `x` страны A), горизонты 0…8:

| h | A | B | C |
|---|---|---|---|
| 0 | 1,0000 | 0,0000 | 0,0000 |
| 1 | 0,4998 | 0,1019 | 0,0634 |
| 2 | 0,2682 | 0,1093 | 0,0786 |
| 3 | 0,1547 | 0,0910 | 0,0726 |
| 5 | 0,0615 | 0,0512 | 0,0463 |
| 8 | 0,0197 | 0,0190 | 0,0185 |

Собственный отклик положителен и затухает; spillover в B и C положителен уже на h=1 (веса
`w_BA=0,5`, `w_CA=0,3`) и затухает к нулю. Пример прогноза h=1..4 для того же прогона:
A ≈ [0,0021; 0,0015; 0,0009; 0,0005], B ≈ [0,0024; 0,0014; 0,0007; 0,0003],
C ≈ [0,0038; 0,0022; 0,0014; 0,0009] (значения зависят от seed/DGP; тесты проверяют
согласованность прогноза с экспортированными уравнениями, а не сами числа).

Тесты (`tests/test_gvar.py`, 14): интерфейс/экспорт, восстановление коэффициентов, мультивариантный
случай, стабильность/нестабильность, IRF (знак/затухание, cholesky/unit, валидация), веса
(сумма=1, отрицательные, self, неизвестные, нормировка), fail-closed (нет стран/весов,
несовпадение переменных/длин, NaN, короткий ряд), согласованность прогноза с экспортом,
детерминизм (одинаковый JSON/дайджест).

## 6. Критерии приёмки для перехода к реальным данным

Прототип переходит к реальным данным только при выполнении всех пунктов; до этого — никаких
заявлений о качестве прогноза.

1. **Данные и веса.** Не менее 3–5 стран с одинаковым набором переменных (например, реальный
   рост, инфляция, ставка/курс) и достаточной длиной: `T − p ≥ 3·(число параметров на уравнение)`
   (для `K=3, p=2` это ≈ 60+ наблюдений на страну). Веса — из MRIO по годам, `Σ_j w_ij=1`,
   `w_ii=0`, `w_ij≥0`; веса и их источник (год, таблица) фиксируются в data-докe. Проверка:
   `normalize_weights` + fail-closed при нарушении.
2. **Спецификация.** `p` выбирается по BIC/AIC на обучающем окне (до W1), а не по всему sample;
   выбор фиксируется до оценки. Переменные и порядок Холецкого фиксируются заранее.
3. **Стабильность.** Глобальная компаньон-форма на каждом rolling-окне оценки: `max_modulus < 1`
   (жёсткий fail-closed), иначе кандидат не оценивается (не «стабилизируем» подгонкой).
4. **Диагностика.** Остатки: Ljung–Box (автокорреляция) и проверка слабой экзогенности
   иностранных факторов (например, Granger-тесты/тест на предопределённость); при провале —
   отказ или переход к GMM/IV, но только как новый предрегистрированный дизайн.
5. **Out-of-sample.** Под протоколом v5 (W1/W2, REAL_TIME-класс) сравнение с RW/AR и замороженным
   компаратором по RMSE и CRPS; C1/C2/C4/C5. Перед прогоном — регистрация кандидата (id, код,
   SHA-256, `registered_before_evaluation=true`), как для любых кандидатов.
6. **Воспроизводимость.** Фиксированные seed'ы, версии данных (PIT), детерминированный
   `to_json()`/`digest()`; повторный прогон даёт те же числа; в отчёте — дайджест экспорта.
7. **Экономическая согласованность.** Знаки IRF соответствуют теории (положительный spillover по
   торговле, затухание), без «взрывных» откликов; при несоответствии — не принимать.

До выполнения п.1–5 прототип остаётся вне admission: **C1/C2/C4/C5/C6 не считаются, статус не
присваивается**, registry не пополняется.

## 7. Ограничения (честно)

- **Малая выборка и параметрический голод.** На страну `K(2p)+1` параметров; при `N` странах
  глобальная система имеет `N·K·p` состояний. Короткие ряды → шумные коэффициенты и
  сверхоптимизм in-sample (в синтетике допуск восстановления 0,03 при n=2000 — это оптимистичный
  случай; на реальных 30–60 годах месячных данных ошибки будут больше).
- **Эндогенность/одновременность.** OLS по уравнению состоятелен только при слабой экзогенности
  `y*`; общие мировые шоки (нефть, глобальный цикл, пандемия) нарушают её. Оценка не
  инструментальная, причинных интерпретаций IRF не даёт.
- **Веса экзогенны, постоянны и не оценены.** MRIO-веса могут быть устаревшими; сеть торговли
  меняется; эндогенность весов (торговля ↔ рост) не моделируется. Нормировка строк обязательна.
- **Нет финансового контура.** Нет запасов/потоков, FX, ставок, долга — то, что AMFE-контур
  (docs/56 §2.4) как раз умеет; GVAR здесь «лёгкий» прогнозный слой, а не замыкание балансов.
- **Нет контеграции.** Уровневые ряды с общим трендом дают ложную персистентность; прототип не
  тестирует коинтеграцию и не накладывает ограничений.
- **Линейность, без режимов/выбросов.** COVID-2020 и структурные сдвиги не обрабатываются.
- **Cholesky-порядок произволен.** Мгновенные отклики зависят от порядка; в тестах проверяется
  только детерминизм и знаки, а не идентификация.
- **Статистический вывод.** Экспортируются только точечные оценки и остаточные std; HAC/бутстрап
  не считаются, p-value нет — для admission потребуется отдельный слой оценки.
- **Синтетика не подтверждает экономику.** Тесты проверяют математическую корректность
  (оценка/стабильность/IRF/детерминизм), а не прогностическую ценность на реальных данных.
- **Нет PIT/винтажей.** EQ-OBS-001 с винтажами заявлен в docs/53, но здесь наблюдение одно и
  «последней» версии; для v5-класса REAL_TIME потребуется point-in-time слой.

## 8. Воспроизведение

```powershell
python tests/test_gvar.py
```

Мини-пример:

```python
import sys; sys.path.insert(0, "src")
from amfe.world.gvar import GVAR
from tests.test_gvar import synthetic          # только для демонстрации, не для admission
model = GVAR(synthetic(n=2000, seed=11), lags=1)
model.is_stable(), model.stability()["max_modulus"]      # (True, 0.713...)
model.irf("A", "x", horizons=8)["response"]["B"]["x"]    # spillover: 0, 0.10, 0.11, ...
model.forecast(steps=4)["path"]["C"]["x"]
model.digest()                                           # SHA-256 канонического JSON
```

Ожидаемый дайджест демонстрационного прогона (n=2000, seed=11, own=0.5, foreign=0.2):
`409b953777220696b00a972014c6cc131c7b780b898fed5dc59fbac3cf7c1c97`. Дайджест зависит от DGP/seed
и приведён как проверка детерминизма, а не как «результат».

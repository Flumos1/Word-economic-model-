## Математическая область локальной проверки
Для каждой валюты и инструмента сумма знаковых финансовых позиций равна нулю. Для каждого сектора и периода:
NW_close - NW_open = Σ transactional ΔNW + Σ revaluation ΔNW.
При конвертации требуется равенство стоимости обеих ног по действующим курсам. При изменении курса переоценка вычисляется по существующим валютным позициям; сумма по миру равна нулю из зеркальности. Транзакции валидируются на копии позиций до фиксации.

## Формальная проверка
Для каждой пары (страна c, сектор s) и транзакции t:
ΔNW(c,s,t) = ΔFA(c,s,t) + ΔRA(c,s,t).
Для каждой валюты v и инструмента j:
Σ_(c,s) FA(c,s,j,v) = 0.
Для периода p:
NW_close(c,s,p) − NW_open(c,s,p) = Σ_(t∈p) ΔNW(c,s,t).
Эти равенства сохраняются индукцией для допустимых транзакций. Они **не** устанавливают экономическую корректность семантики каждой операции и не заменяют национальные счета и платёжный баланс.

# AMFE — контекстная оценка научных методов и границы универсальности
Дата: 2026-11-10. Статус: методологический принцип-кандидат.

## Исходная позиция
Пользователь предлагает не предполагать существование универсального критерия качества научного метода. Уточнение: тезис «универсальности вообще не существует» сам является универсальным и потому логически проблематичен. Рабочая формулировка: **не постулировать единственный универсальный скалярный критерий качества методов, пригодный для всех задач, масштабов и условий**. Не исключать существование общих формальных принципов и локальных/специальных критериев.

## Два уровня
1. Общие требования научной процедуры: непротиворечивость формулировок, явные допущения, прослеживаемость, честное различение наблюдения и вывода, воспроизводимость там, где применима; их точная реализация зависит от типа исследования.
2. Контекстные критерии качества: прогноз, причинная идентификация, устойчивость, стоимость, научная ценность, масштаб, доступность данных.

## Формальная конструкция
Контекст c=(исследовательский вопрос, цели, данные, ограничения, горизонт, режим, допустимый риск).
Отношение m1 ≽_c m2 означает «m1 не хуже m2 в контексте c по объявленному правилу». Отношение может быть неполным: возможна несравнимость методов, и её нельзя скрывать произвольными весами. Различать неполноту отношения предпочтения, статистическую неопределённость и отсутствие данных. Рассмотреть доминирование Парето по нескольким измерениям и частичные порядки, но не предполагать их пригодность для любого типа метода.

## Проверяемые задачи
- Формализовать множество контекстов и допустимые критерии для каждого класса научных вопросов.
- Определить условия, при которых сравнение возможно, невозможно или зависит от явно объявленных ценностных весов.
- Разработать процедуру выбора из Парето-множества без фиктивной универсальной функции полезности.
- Отдельно проверить, существуют ли устойчивые общие требования научной корректности, и какова их область применимости.
- Не объявлять философскую позицию эмпирически доказанной.

## Рабочая формула
«Единство научной строгости не требует единственности критерия научного качества».

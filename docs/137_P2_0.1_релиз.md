# 137. Релиз P2 0.1: манифест состояния D1–D6

Версия 0.1 · 2026-11-14. Инструмент — [tools/p2_release.py](../tools/p2_release.py), тесты —
[tests/test_p2_release.py](../tests/test_p2_release.py), машиночитаемый манифест —
`build/p2_release/p2_release.json` (в git не коммитится, как и остальной `build/`).

**Статус:** `RESEARCH_RELEASE`. Это **не допуск**, не прогнозный продукт и не инвестиционная
рекомендация: допущенной модели нет, T1-кандидат остаётся `CANDIDATE`, режимный кандидат —
`SHADOW_TEST` с `conditional_data_class=true`.

## 1. Что входит в P2 0.1

| Область | Содержание |

| Статическое ядро | `tools/world_pipeline.py`: A=Z/x, ρ(A), Hawkins–Simon, x=(I−A)⁻¹y, страновое ядро, sparse-факторизация; валидации и балансы PASS на FIGARO и OECD |
| SFC | `src/amfe/world/sfc_io.py`: счета стран, S=I+CA, ΣCA=0, шаг потоков/запасов; PASS на FIGARO 2019 и OECD 2011 (невязки округления, docs/133) |
| Сценарии | **8 сценариев** (energy −5% и +50%, import +10%/+20%, FX −10%/−20% по DE/FR и DEU/USA) на **двух** датасетах; отчёты «страна × отрасль» JSON/MD, балансы сходятся (docs/131) |
| Динамика (D4) | GVAR на 53 странах × 30 лет; **отрицательный OOS**: лучше AR(1)/RW только в 4 из 32 ячеек (против 28), средняя ΔRMSE +0,02; честно зафиксировано, вне допуска (docs/128) |

мир, SFC и сценарии; динамика остаётся исследовательским треком с отрицательным результатом.

## 3. Сводка мира (как в манифесте)

- **FIGARO 2019** (`figaro_2019`): 50 стран (49 поимённых + `ROW`), 64 отрасли, 3200 секторов,
  Z 10,24 млн ячеек (sparse 5 146 560 ненулевых), `USD_mn`, SHA-256 `70789f08…`;
  покрытие 87,2771% ВВП + ROW 12,7229% = 100%, гейт ≥80% PASS.
- **OECD ICIO 2016** (2011): 71 экономика (63 поимённые + регионы + ROW), 34 отрасли,
  2414 секторов, SHA-256 `fc753c37…`; 12 лет 2000–2011 D1 PASS, покрытие мировой ДС 95,35–95,47%.
- **WIOD 2016**: 44 страны × 56 отраслей, 15 датасетов 2000–2014, покрытие 84,38–89,85%,
  идентичности PASS (max residual 0,0 после adjust-схемы v1.1).
- **Кандидаты:** T1 `ENSEMBLE_INVERSE_MSE` — `CANDIDATE` (C4 FAIL по RMSE, C6 0/12);
  `ENSEMBLE_REGIME_V4` — `SHADOW_TEST`, `status_label=SHADOW_TEST_CONDITIONAL_DATA_CLASS`,
  `conditional_data_class=true`, C6 не пройден (0/12, нужно 4 различных периода).
  **Допущенных моделей нет** (`admitted=false`).

## 4. Что НЕ входит в P2 0.1

1. **Допуск/ACTIVE.** T2/ACTIVE не входят: нет C6 (forward-журнал 11 строк, 0 разрешённых
   прогнозов), T1 — CANDIDATE, режимный кандидат — SHADOW_TEST.
2. **Микроуровень (фирмы), труд/домохозяйства как поведенческие блоки** — после D6, вне P2 0.1.
3. **Динамика как production-блок** — только research-трек D4 с отрицательным OOS.
4. **OECD release 2025** (60+×45, 1995–2022) — только ручная загрузка; в P2 0.1 OECD 2016.
5. **Цены/замещение/обратные связи в сценариях** — сравнительная статика; FX — pass-through
   в стоимость импортных затрат, без ценового замещения.
6. **Сырые сторонние данные** — не коммитятся; в манифесте только SHA-256, счётчики и агрегаты.
7. **Лицензионное заключение** — в docs/130, docs/121 зафиксированы условия источников
   (Eurostat re-use, OECD Terms, CC BY 4.0 для WIOD), но это не юридическая консультация.

## 5. Как воспроизвести

```powershell
# 1) данные (вне git): AMFE_MRIO_ROOT указывает на локальный MRIO-корень
$env:AMFE_MRIO_ROOT = "F:\Мировая экономика модель\data\mrio"

# 2) статический мир и сценарии (пример FIGARO; OECD — аналогично)
python tools/world_pipeline.py --dataset "$env:AMFE_MRIO_ROOT\figaro\figaro_2019\dataset.json" --build --solve
python tools/world_reports.py --root $env:AMFE_MRIO_ROOT --dataset figaro_2019 --out build/world
python tools/world_reports.py --root $env:AMFE_MRIO_ROOT --dataset oecd_icio/2011 --out build/world_oecd

# 3) релизный манифест (fail-closed; детерминизм кроме generated_at)
python tools/p2_release.py --data-root $env:AMFE_MRIO_ROOT
python tools/p2_release.py --generated-at 2026-11-14T20:40:00Z --date 2026-11-14

# 4) тесты
python -m unittest tests.test_p2_release -v      # 13 тестов
python -m unittest tests.test_world_pipeline tests.test_figaro_import
```

Манифест: `build/p2_release/p2_release.json` — 25,7 КБ, 32 входа с SHA-256, версия `0.1`,
`git_commit` (если git доступен), `criteria_summary`, `world`, `inputs`, `limitations`.
Инструмент падает (exit 2) при отсутствии обязательного артефакта или битом JSON; ничего не
пишет при ошибке. Поля `generated_at`/`date` — единственные, что меняются между прогонами.

## 6. Ограничения

1. **Research release.** P2 0.1 — воспроизводимый снимок состояния, а не допуск и не обещание
   точности; сценарии не являются прогнозами.
2. **Один релизный срез.** Манифест фиксирует состояние на дату; обновление — пересборкой.
3. **D4 отрицательный.** GVAR не лучше AR(1)/RW на агрегатах; это результат, а не провал, но
   динамика не готова к production.
4. **Данные на диске.** FIGARO/OECD/WIOD лежат вне git (`/data/mrio/` в `.gitignore`); для
   воспроизведения нужен локальный data root, иначе D1/D2/D3/D5 будут PARTIAL/FAIL (fail-closed).
5. **OECD report index может отсутствовать** (например, собран на другой машине): манифест
   помечает его как optional и снижает D2/D3/D5 до PARTIAL — это видно в `criteria_summary`.
6. **Числа покрытия зависят от World Bank GDP-винтажа** (кэш в манифестах источников).
7. **Не юридическое заключение:** условия лицензий зафиксированы, но требуют отдельной проверки
   перед публичным использованием данных.
8. **docs/135 и docs/136** присутствуют в релизе (включены в inputs с SHA-256); более ранняя сборка манифеста помечала их как
   `docs_context_missing` (необязательный контекст), обязательные документы перечислены в `inputs`.

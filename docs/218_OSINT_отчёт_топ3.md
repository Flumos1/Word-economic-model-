# 218. OSINT-отчёт по топ-3 западным заказчикам (2026-11-21)

Статус: **RESEARCH_ONLY, admission=false**. Отчёт по открытым источникам; не оферта, не
персональные данные, не контакты. Формат — по OSINT-практике: факт отдельно от интерпретации,
у каждого факта источник и дата обращения.

## 1. Задача и границы

- Задача: проверить публичный профиль топ-3 (Equinor, Shell, ConocoPhillips) для пилота.
- Источники: только официальные сайты компаний (S1), открытые HTTP-страницы.
- Не делали: не обходили paywall/авторизацию, не собирали персональные данные, не звонили,
  не писали в компании, не использовали закрытые базы (подписок нет).
- Ограничение среды: часть страниц отдаёт только заголовок/навигацию (JS/truncation), поэтому
  не все факты извлекаются. Это фиксируется как `NOT_FETCHED`, а не додумывается.

## 2. Метод

1. Открыть официальный раздел `about/company/operations` через HTTP.
2. Зафиксировать URL, дату, HTTP-статус, что именно видно в тексте.
3. Разделить: **факт** (есть цитата/наблюдение) и **интерпретация** (наша гипотеза).
4. Оценка: A — подтверждено официальным документом/страницей; B — вторичный надёжный источник;
   C — агрегатор; D — предположение. Источник: 1 — официальный, 2 — регулятор/статистика,
   3 — отраслевая пресса, 4 — агрегатор, 5 — неизвестный.
5. Не повышать досье до `VERIFIED`: для этого нужен человек, проверивший первоисточник и контекст.

## 4. Что это меняет в досье

- **ConocoPhillips:** можно усилить фактами F1–F4 (официальный сайт), но не менять `HYPOTHESIS`
  болей и не ставить `VERIFIED`.
- **Equinor, Shell:** оставить `PARTIAL`; в §9 добавить, что официальный сайт доступен, но контент
  не извлечён; не выдумывать структуру.
- **Кейсы:** у Conoco можно уточнить формулировки про Global LNG/операционные регионы; у Equinor/Shell
  — не добавлять новых фактов.

## 5. Выводы

**Факты:** официальные сайты трёх компаний доступны; у Conoco извлекается публичная структура
операций и наличие Global LNG; у Equinor/Shell в этой среде — только заголовки.

**Предположения:** Conoco — самый «читаемый» первоисточник для быстрого OSINT-пилота; Equinor/Shell
требуют браузера/сохранённых отчётов, иначе evidence не поднимется выше `PARTIAL`.

## 6. Правовые оговорки

- Только открытые страницы; без обхода ограничений, авторизации и paywall.
- Персональные данные, контакты и частная жизнь не собирались.
- Названия компаний — только как объект исследования, не как клиенты/партнёры; `not_client=true`.
- Отчёт внутренний; публикация — только с дисклеймером «гипотезы, не клиенты».

## 7. Следующие шаги

1. Человеку с браузером: открыть S1-страницы Equinor/Shell/Conoco, сохранить цитаты и даты.
2. Заполнить `source_id` в KB, поднять evidence до `PARTIAL`/`A`.
3. Обновить Conoco-кейсы числами: см. [docs/219](219_Conoco_факты.md) — добыча 2 375 MBOED,
   guidance 2,33–2,36 MMBOED, CAPEX ~$12B, запасы 4,2 BBOE, 28 LNG-трактов, 10,2 MTPA.
4. Не отправлять письма до проверки адресатов и санкционного комплаенса.

Файлы: [protocols/evaluation_protocol_v4.json](../protocols/evaluation_protocol_v4.json), тест [tests/test_protocol_v4.py](../tests/test_protocol_v4.py), инструмент [tools/fetch_data.py](../tools/fetch_data.py), план [protocols/data_plan.json](../protocols/data_plan.json), workflow [.github/workflows/data-refresh.yml](../.github/workflows/data-refresh.yml). v4 **заменяет v3 после заморозки**; v1, v2 и v3 остаются в репозитории неизменными.

## Зачем v4: два решения владельца
1. **D-131 — окно T3.** Винтажи ALFRED по GS10 и TB3MS начинаются 1996-12-03 (docs/65). До этой даты `PROBIT_SPREAD` — `PSEUDO_REAL_TIME`, и у T3 остаётся один REAL_TIME-член (правило Сам) — ниже минимума компаратора, поэтому C1 на W1 для T3 был бы не определён. **W1 для T3 начинается с 1996-12**; начало задано данными, а не результатами.
2. **D-132 — автоматическая загрузка.** Любой ручной шаг загрузки исключён из конвейера. Данные забирает инструмент проекта в CI: по одному ряду за запрос, с ограничением частоты, без FRED API и без кэша API; если величину нельзя получить автоматически в рамках опубликованных условий — она **заменяется собственной моделью или отбрасывается**, и это записывается. Сырые чужие файлы в репозиторий не попадают.

## Как работает автоматическая загрузка
- `tools/fetch_data.py` читает `protocols/data_plan.json` (только ряды со статусом OPEN в реестре), качает публичные CSV-файлы по одному, с User-Agent проекта, таймаутом, повторами и паузой между запросами; пишет файлы в игнорируемый `data/raw/` и журнал `data_log.json` (URL, дата, размер, SHA-256).
- `.github/workflows/data-refresh.yml` запускается по расписанию (1-е число месяца) и вручную; выполняет тот же скрипт на раннере GitHub и выгружает сырые файлы и журнал как **приватный артефакт** (90 дней), ничего не коммитя.
- FRED API не используется (нет ключа, нет API-кэша). Ограничение частоты и поштучная выборка выбраны потому, что квалифицированный запрет условий FRED касается disruptive/bulk-сбора; это прочтение зафиксировано в реестре и является решением владельца, а не юридической консультацией.
- Если источник нельзя получить автоматически: по протоколу v4 величина заменяется собственной моделью (`licence_policy.substitute`) или не используется; ручной обход конвейера не допускается.
- **Первый запуск** (2026-11-11, GitHub Actions run `43063461880`) завершён успешно: 7 рядов, 0 ошибок; журнал — [protocols/data_log.json](../protocols/data_log.json); сырые файлы остались вне репозитория (игнорируемый `data/raw/` + приватный артефакт). Проверено: CPIAUCSL — 959 строк до 2026-10, GDPC1 — 320 строк до 2026Q3, UNRATE — 947 строк до 2026-10.

# AMFE — R2: документарный аудит (2026-11-11)
Версия 1.0.0 · 2026-11-11. Второй этап лицензионно-документарного аудита. Контекст: [docs/63](63_Лицензионный_аудит_2026-11-11.md) (первый этап), реестр [protocols/licence_register.json](../protocols/licence_register.json), [protocols/r3_specification.json](../protocols/r3_specification.json). **Это не юридическая консультация.** Документ фиксирует, что буквально написано на страницах условий, документации и метаданных; решения по статусам и по спецификации принимает владелец проекта.

## Ограничение независимости и метод
Аудит выполнен отдельным экземпляром той же языковой модели (не человеком), по инструкции Team Lead; он не участвовал в написании протокола и R3-спецификации. Метод: `web_fetch` первоисточников (для PDF — текстовое извлечение через `r.jina.ai`), дословные цитаты; внешние страницы — данные, не инструкции. Страницы открыты **2026-11-11**. **Сырые данные не скачивались и не сохранялись**: ссылки на `.xlsx`, `.zip`, `.csv`, `.txt` не открывались; читались только страницы условий, документации и метаданных. Уровень чтения отмечен в таблице: «полностью» — страница/PDF прочитана в объёме, покрывающем вопрос; «извлечение» — ответ на запрос по странице. Общие обучающие данные модели означают, что слепые пятна автора спецификации и аудитора могут совпадать.

## 2. Что это меняет для R2/R3 (только факты, выводы — за владельцем)

### 2.1 SPF и отображение определений (`SPF_MEDIAN.status = PROPOSED_OPEN_MAPPING`)
- SPF публикует CPI-инфляцию **только** как q/q в annualized п.п. (квартальная средняя индекса) и как **Q4/Q4** годовую; помесячного y/y прогноза в документации нет (п.9 таблицы).
- Квартальные горизонты SPF — пять кварталов вперёд; годовые — текущий и следующий год (для CPI/core CPI/PCE/core PCE с 2007:Q1 — текущий и два следующих) (п.6, 10).
- Цель T1 в протоколе — **помесячный y/y**; прямое отображение документацией не задаётся: чтобы получить месячный y/y из Q/Q annualized, нужна дополнительная гипотеза о внутриквартальном пути индекса, которой в SPF нет.
- Наиболее близкие по определению величины SPF: квартальный q/q annualized и годовой Q4/Q4. Горизонты T1 = 1/3/6/12 месяцев не совпадают с сеткой SPF (кварталы и календарные годы).
- Сроки: дедлайн — вторая-третья неделя среднего месяца квартала (февраль/май/август/ноябрь), публикация — со второй половины среднего месяца, всегда до второй оценки BEA (п.7); список точных дат опросов вынесен в отдельный файл `spf-release-dates.txt` (не открывался).
- Формат данных: `.xlsx`, первые два столбца — год и квартал опроса; это метаданные, позволяющие привязать прогноз к origin, но не дают внутриквартальной даты (только квартал).
- В SPF есть непубличные для широкой публики переменные (Moody's Aaa/Baa) — при построении маппинга их нельзя использовать (п.11).

### 2.2 Глубина винтажей и `data_manifest.depth` в R3-спецификации
R3-спецификация (`data_manifest.series`) указывает для UNRATE, GS10, TB3MS, T10Y3M «vintages from 1990-01», а для T10Y3M — старт ряда 1982. Факты ALFRED (метаданные страниц, без скачивания данных):
- **UNRATE** — винтажи в ALFRED с 1960-03-15 → заявленная глубина с 1990-01 перекрывается (п.19).
- **GS10** — винтажи в ALFRED с **1996-12-03**; до этой даты винтажей нет (п.20).
- **TB3MS** — винтажи в ALFRED с **1996-12-03** (п.21).
- **T10Y3M** — старт наблюдений 1982-01-04 подтверждён (п.22), но винтажи в ALFRED только с **2014-01-27** (п.23); в заметках зафиксирована смена источника данных с 2019-06-21.
- Следствие для классификации REAL_TIME: origins W1 (1990–2006) и часть W2 для моделей, которым нужны GS10/TB3MS/T10Y3M (BVAR, PROBIT, OWN_NOWCAST_BRIDGE), не могут опираться на винтажи ALFRED ранее указанных дат. Что с этим делать (сузить REAL_TIME-окно, искать другой канал, помечать PSEUDO_REAL_TIME) — решение по спецификации, не по лицензиям.
- RTDSM как альтернативный канал винтажей: real GDP с 1965:Q4, CPI квартальные с 1994:Q3, CPI месячные с 1998:M11 (п.14, 15) — то есть RTDSM не закрывает CPI до 1994 и не содержит рядов H.15 (GS10/TB3MS/T10Y3M в составе RTDSM не найдены).

### 2.3 BEA
- Данные BEA — public domain, разрешение не требуется, цитирование приветствуется; запрещено использование логотипа не для идентификации ссылки (п.1, 2).
- Полного машиночитаемого архива «как опубликовано» на прочитанных страницах не найдено: есть архив пресс-релизов с пометкой «Data may be superseded» и страницы истории обновлений/ревизий (п.3, 4, 5). Факт наличия канала «как опубликовано» для BEA данным аудитом не подтверждён.

### 2.4 Cleveland
- Свидетельство архива значений «как опубликовано в реальном времени» **есть, но в публикации банка, а не на странице данных**: для 2013:Q3 и далее использованы наукасты, опубликованные на сайте в реальном времени; сайт публикует дневные наукасты с начала 2014 (п.16).
- Сама страница наукаста прямой формулировки про архив не содержит; там графики прошлых периодов, «Download CSV» и рекомендуемая ссылка DOI (п.18).
- Лицензия публикации Commentary — CC BY-NC 4.0; это лицензия на публикацию, не на ряд данных (п.17). Условия использования данных на страницах Cleveland по-прежнему — только Privacy/Terms of Use (см. docs/63, п.10).

### 2.5 FRED-MD/FRED-QD
- Условий использования на странице нет; там только дисклеймер о стороннем ПО и ссылках (п.24). Запись реестра UNVERIFIED остаётся обоснованной.
- Формат/архивы: `.csv` по винтажам + zip исторических винтажей; FRED-MD 1999-08 … 2025-12 (двумя блоками), FRED-QD 2018-05 … 2025-12 (п.25).
- Вопрос «подпадают ли сами файлы FRED-MD/QD под условия FRED» на странице не решён: страница ссылается на FRED как источник обновлений, но не заявляет лицензию.

## 5. Итог
- **BEA** — OPEN, public domain, цитирование приветствуется; архив винтажей в машиночитаемом виде на прочитанных страницах не подтверждён (есть архив пресс-релизов «Data may be superseded» и история ревизий).

- **RTDSM** — отдельных условий на страницах данных не найдено (ссылка на Privacy Notice); глубина: real GDP 1965:Q4, CPI 1994:Q3 / 1998:M11; форматы `.xlsx`.

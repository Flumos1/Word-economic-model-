## Инструмент `tools/check_terms.py`
Назначение: ловить изменение текста условий без уведомления. Два режима:

- `python tools/check_terms.py --offline` (по умолчанию) — без сети: сверяет `terms_sha256`/`terms_retrieved_at` реестра с выдержками условий в [docs/90](90_Условия_источников_хеши.md) (FRED, Philadelphia SPF, Philadelphia RTDSM, NBER) и в [docs/97](97_Лицензии_ряды_и_terms.md) (BLS, BEA); пересчитывает `terms-passages-v1` и сообщает OK / MISMATCH / MISSING.
- `python tools/check_terms.py --online` — для CI: скачивает каждый `terms_url` из реестра (urllib, свой User-Agent, таймаут/ретраи), нормализует текст страницы, проверяет, что все нормализованные выдержки присутствуют на странице, и печатает sha256 скачанного текста для аудита. **Ограничение:** хеш — по выдержкам, а не по байтам HTML (текстовое извлечение нестабильно к разметке), поэтому проверяется наличие выдержек, а не байтовое совпадение.
- `--source ID` — только один источник; `--json` — машиночитаемый отчёт; код возврата 0 при успехе и 1 при расхождении/ошибке.

Офлайн-режим покрыт `tests/test_check_terms.py`; онлайн-режим в этой песочнице не запускался (сеть из скриптов недоступна) — он предназначен для CI и проверен на подменённом `fetch_text`.

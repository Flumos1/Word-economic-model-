# AMFE — NF-SIM: исследование шумового порога C1 (2026-11-11)
Версия 1.0.0 · 2026-11-11. Контекст: [протокол v4](66_Протокол_оценки_v4_изменения.md) (`admission.threshold_rule.noise_floor_study`), [R3-спецификация](../protocols/r3_specification.json). Таблица: [protocols/nf_sim_thresholds.json](../protocols/nf_sim_thresholds.json), SHA-256 `f057e2a5…c614`; калибровка: [protocols/nf_sim_config.json](../protocols/nf_sim_config.json); код: [tools/nf_sim.py](../tools/nf_sim.py), [tools/nf_sim_calibrate.py](../tools/nf_sim_calibrate.py); тест: [tests/test_nf_sim.py](../tests/test_nf_sim.py). **Таблица заморожена до первой оценки кандидатов** (D-135).

## Зачем
C1 сравнивает кандидата с основным компаратором по относительной потере. Даже у двух статистически эквивалентных методов относительная потеря не равна ровно 1 из-за шума оценивания. NF-SIM оценивает **q05 — 5-й процентиль распределения относительной потери двух эквивалентных методов** — и задаёт порог C1 = min(0,97; q05), отдельно для каждой (цель, горизонт, потеря, окно).

## Дизайн (реализован в tools/nf_sim.py)
- **Калибровка** ([tools/nf_sim_calibrate.py](../tools/nf_sim_calibrate.py)) по фактическим рядам из локального `data/raw` (в git не попадают): AR(1) для инфляции г/г (месячные, 1960–2019) и роста ВВП (квартальные, 1960–2019); двухрежимная марковская цепь для рецессий по `USREC` (p_ER = 0,0128, p_RE = 0,0860, доля рецессий ≈ 12,9 %). Конфигурация закоммичена: [protocols/nf_sim_config.json](../protocols/nf_sim_config.json) (только параметры, не данные).
- **Эквивалентные методы** различаются только шумом оценивания: окна оценки 156 и 180 месяцев для T1, 52 и 60 кварталов для T2, 180 и 240 месяцев для T3 (базовое окно протокола — 180/60/240).
- **Длина выборки** — эффективная REAL_TIME-длина каждого окна: число периодов минус h и перекрытие h−1 (для W1/W2 и каждого горизонта; от 45 до 203 наблюдений).
- **Потери** — по протоколу: RMSE (точка), CRPS = удвоенная средняя пинбол-потеря по 19 квантилям (плотность), Brier и лог-оценка (событие).
- **Вариант комбинации**: основной компаратор — комбинация; в симуляции компаратор заменяется равновесной комбинацией двух эквивалентных методов, и берётся более строгий из двух порогов.
- 10 000 репликаций, детерминированный seed 20261111; повторный запуск даёт ту же таблицу (проверяется тестом по хешу).

## Результаты: 44 комбинации (2 цели × плотностные/точечные, T3 отдельно)
| Цель | Комбинаций | min q05 | среднее | max q05 |
|---|---|---|---|---|
| T1_CPI_YOY | 16 | 0.9452 | 0.9647 | 0.9700 |
| T2_GDP_GROWTH | 16 | 0.9700 | 0.9700 | 0.9700 |
| T3_RECESSION | 12 | 0.7055 | 0.7871 | 0.8501 |

- **T1 (инфляция):** q05 0,945–0,993; после правила min(0,97) почти все пороги = 0,97, на длинных горизонтах (12 мес.) — 0,95–0,96.
- **T2 (ВВП):** q05 0,98–0,984 → порог 0,97 на всех горизонтах.
- **T3 (рецессия):** q05 заметно ниже — 0,71–0,85 (Brier) и 0,80–0,85 (лог-оценка). Это не ошибка: редкие события дают большую дисперсию оценок вероятности, поэтому шумовой пол выше, а порог C1 строже. С учётом потолка LIMITED_DEPLOYMENT для T3 это ожидаемое следствие, а не артефакт.
- Комбинационный вариант везде даёт q05 **выше**, чем одиночный (комбинация меньше шумит), поэтому «более строгий из двух» — это q05 одиночного сравнения; так и записано в таблице.

## Как это встроено в допуск
Для каждой пары (цель, горизонт, потеря) C1 использует порог из таблицы по окну W1/W2; кандидат допускается только если относительная потеря ≤ порога на W1 и W2. Порог **вычислен до любых результатов** и заморожен: изменение — только новой версией протокола (D-100) или новой версией NF-SIM через мета-ворота.

## Ограничения
- DGP — AR(1)/марковская цепь, калиброванные по фактическим рядам; это шумовой пол, а не модель экономики. В R3-спецификации зарезервированы и другие DGP (случайное блуждание, блочный бутстреп ошибок) — они не входят в эту замороженную таблицу.
- NF-SIM не использует винтажные данные напрямую — только эффективные длины (они зафиксированы по воротам R2 и окнам протокола).
- Таблица не учитывает выбор модели исследователем между репликации — это задача C1–C6 и журнала будущих прогнозов.
- T3-пороги строгие из-за малого числа событий; при 12 разрешённых прогнозах C6 остаётся узким местом.

# 214. 100 западных кейсов: каталог гипотез, цены и правила замены

Дата: 2026-11-21. Роль `dense-vintages` (продукты/упаковка). Статус: **RESEARCH_ONLY,
admission=false, causal_claim=false**. Это каталог гипотез для западных корпораций, а не КП:
**ни один кейс не является клиентским, ни один не согласован, ни один не отправлен**;
`not_client=true` у всех ста.

## 0. Короткий вывод

1. Собрано **100 кейсов на 50 компаний** (по 2 кейса: один — про цену/бюджет или газ, второй —
   про TCO закупок, геополитику или API). Сегменты: major, upstream, lng, services, trading,
   chemicals, utilities, industrials, pipelines.
2. Каждый кейс — **гипотеза**: профиль роли, боль, вопрос и набор наших модулей. Ни выручки, ни
   штата, ни контактов, ни утверждений о финансовых показателях компании внутри нет.
3. Числа в вопросах взяты из существующих модулей и документов ([docs/186](186_Ормуз_нефть_США_последствия.md),
   [docs/188](188_Газ_LNG.md), [docs/190](190_Клиентский_пакет_Ормуз_США.md)), а не придуманы;
   где внешних данных не забирали — стоит `NOT_FETCHED`.
4. `tools/case_catalog.py` валидирует пакет fail-closed и собирает `catalog.md`, `catalog.pdf`,
   **англоязычные** `catalog_en.md`/`catalog_en.pdf` и `manifest.json` с SHA-256.
5. Цены — только USD и только из пяти объявленных полос; срок обязан соответствовать полосе.

## 2. Как использовать (гипотезы) и что является гипотезой

1. **Профиль компании, боль, вопрос.** Мы не утверждаем, что у компании есть эта боль; это
   гипотеза для проверки на discovery.
2. **Решение на discovery.** Сначала 20–30 минут, потом решаем, нужен ли пилот.
3. **Цена — это полоса, а не оферта.** Итоговая цена зависит от объёма, данных и срока;
   фиксируется в `price_note`.
4. **Клиентских данных нет.** Все кейсы — `not_client=true`; ни один не отправлен.
5. **Никаких контактов.** В кейсах нет ФИО, email, телефонов; контактный канал — почта
   `flumos@gmail.com`, и только после решения человека.

### 2.1 Чек-лист перед использованием

- [ ] проверить, что кейс не выглядит как согласованный с компанией;
- [ ] не отправлять без проверки адресата и NDA-рамки;
- [ ] сохранить `RESEARCH_ONLY`, `admission=false`, `not_client=true` в письме;
- [ ] не обещать цифры/сроки без discovery;
- [ ] `python tools/case_catalog.py --check` → `OK`;
- [ ] `python -m unittest tests.test_western_cases` → зелёный.

## 5. Как пересобрать

```powershell
python tools/case_catalog.py                 # RU+EN MD/PDF + manifest
python tools/case_catalog.py --no-pdf        # без PDF (быстро)
python tools/case_catalog.py --check         # SHA, цены, покрытие, правила
python tools/case_catalog.py --json          # сводка в stdout
python -m unittest tests.test_western_cases  # 26+ тестов
```

Править `cases.json`, затем пересобрать. `catalog.md` байт-детерминирован; PDF — нет
(метаданные LibreOffice), manifest пересобирается вместе с PDF.

## 7. Что нельзя

1. **Выдавать гипотезу за факт.** Если клиент спросит «откуда вы знаете?» — это гипотеза,
   проверяемая на discovery.
2. **Называть компанию клиентом.** `not_client=true`; никаких логотипов, отзывов, «мы работали».
3. **Обещать точность, вероятность, замену Bloomberg/WoodMac/Platts, экономию X %.**
4. **Публиковать как КП** — только как исследовательский каталог гипотез с дисклеймером.
5. **Отправлять без проверки адресата/NDA/санкционного комплаенса.**

## 8. Ограничения

- 100 кейсов — гипотезы; ни один не проверен на компании.
- Профили без выручки, штата, контактов; evidence — `HYPOTHESIS`/`NOT_FETCHED`.
- Числа в вопросах (Brent 168,9; дизель 6,62 → 8,04; JKM +24,0%; 45 bcm/г) — из наших
  сценариев, не прогноз и не факт рынка.
- PDF не байт-детерминирован; `cases.json`, `catalog.md` — детерминированы.
- Контактный канал — только почта; отправка человеком, после проверки.

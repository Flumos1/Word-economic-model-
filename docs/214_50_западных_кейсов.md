admission=false, causal_claim=false**. Это каталог гипотез для западных корпораций, а не КП:
**ни один кейс не является клиентским, ни один не согласован, ни один не отправлен**;

## 2. Как использовать (гипотезы) и что является гипотезой

1. **Профиль компании, боль, вопрос.** Мы не утверждаем, что у компании есть эта боль; это
   гипотеза для проверки на discovery.
2. **Решение на discovery.** Сначала 20–30 минут, потом решаем, нужен ли пилот.
3. **Цена — это полоса, а не оферта.** Итоговая цена зависит от объёма, данных и срока;
   фиксируется в `price_note`.
4. **Клиентских данных нет.** Все кейсы — `not_client=true`; ни один не отправлен.
5. **Никаких контактов.** В кейсах нет ФИО, email, телефонов; контактный канал — почта
   `flumos@gmail.com`, и только после решения человека.

### 2.1 Чек-лист перед использованием

- [ ] проверить, что кейс не выглядит как согласованный с компанией;
- [ ] не отправлять без проверки адресата и NDA-рамки;
- [ ] сохранить `RESEARCH_ONLY`, `admission=false`, `not_client=true` в письме;
- [ ] не обещать цифры/сроки без discovery;
- [ ] `python tools/case_catalog.py --check` → `OK`;
- [ ] `python -m unittest tests.test_western_cases` → зелёный.


## 7. Что нельзя

1. **Выдавать гипотезу за факт.** Если клиент спросит «откуда вы знаете?» — это гипотеза,
   проверяемая на discovery; числа — только с `source_id`.
2. **Называть компанию клиентом.** `not_client=true`; никаких логотипов, отзывов, «мы работали».
3. **Обещать точность, вероятность, замену Bloomberg/WoodMac/Platts, экономию X %.**
4. **Публиковать как КП** — только как исследовательский каталог гипотез с дисклеймером.
5. **Отправлять без проверки адресата/NDA/санкционного комплаенса.**

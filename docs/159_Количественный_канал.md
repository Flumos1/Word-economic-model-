## 1. Короткий ответ

> При центральном pass-through 0,6 ценовой шок Ормуза (Brent +125,1%) даёт **−2,23% выпуска**
> (FIGARO 2019) и **−2,51%** (OECD ICIO 2025) в **reduced-form** количественном канале:
> финальный спрос −1,11% / −1,17%, промежуточный (отдельная reduced-form реакция) −1,11% / −1,35%.
> Это **не прогноз падения выпуска** и не равновесие: модель линейная, эластичности — допущения,
> каналы считаются раздельно, а большие шоки выходят за пределы малого (линеаризация). Ценность
> результата — **порядок величины и проверяемая арифметика**, а не «оценка рецессии».

Ценовой этап переиспользован из моста **без изменений** (тот же `CostShock`, та же `A`, тот же
решатель): агрегатный Δp при 0,6 — 5,917% (FIGARO) и 6,393% (OECD), как в docs/152. Количественный
этап добавляет к этому две явные вещи: (а) функцию спроса `ΔQ/Q = ε(m)·Δp` с объявленными
эластичностями и (б) спросовую модель Леонтьева `Δx = (I − A)⁻¹Δd`.

## 2. Архитектура и разделение каналов

```
oil module (docs/147)  →  CostShock (pass-through)  →  Δp = (I − Aᵀ)⁻¹c     [price stage, docs/152]
                                                                │
        ┌───────────────────────────────────────────────────────┘
        ▼
demand.demand_response(Δp, base, groups)   ΔQ_i/Q_i = ε_i(m)·Δp_i,  ε(m)=ε_short+(ε_long−ε_short)·m/ramp
        │  final demand: base = y (конечный спрос)     → Δd_final
        │  intermediate: base = z (промежуточное использование) → Δd_inter (отдельная reduced form)
        ▼
Δx = (I − A)⁻¹ Δd        A = Z / x          [demand-driven Leontief output model]
        │
        ▼
три отдельных блока: final_demand · intermediate_input · combined; и отдельно — старый
сравнительно-статический quantity-proxy (energy_plus50/energy_minus5), НЕ смешивается
```

Жёсткие правила, закреплённые в коде и тестах:

1. **Ценовой канал не пересчитывается заново** — `price_stage()` вызывает те же функции
   `tools/market_bridge.py` (read-only), а расхождение с `bridge_report.json` проверяется.
2. **Три канала не смешиваются**: final, intermediate и combined отдаются отдельными полями и
   отдельными метриками; combined — их сумма в `Δd`, не «лучшая оценка».
3. **Старый quantity-proxy (energy_plus50) — другая механика** (сравнительная статика по конечному
   спросу энергетических отраслей), приводится только для контекста в отдельном блоке
   `legacy_quantity_proxy` и никогда не складывается с эластичностным каналом.
4. **Нет точечного прогноза**: отчёт содержит `no_point_forecast: true`, статус `RESEARCH_ONLY`,
   `admission: false`; это не временной прогноз, а сравнительно-статическая оценка.

## 3. Функция спроса (`amfe.markets.demand`)

Формула: `ΔQ_i/Q_i = ε_i(m)·Δp_i`, где `m` — месяц, `ε_i(m) = ε_short + (ε_long − ε_short)·min(m/ramp, 1)`.
Эластичности — **допущения порядка величины** (`source_class="assumption"`), не оценки по данным:

| Группа издержек | Конечный спрос: short / long | Промежуточный спрос: short / long |
|---|---|---|
| energy | −0,15 / −0,55 | −0,07 / −0,25 |
| transport | −0,10 / −0,40 | −0,05 / −0,20 |
| manufacturing | −0,05 / −0,20 | −0,03 / −0,10 |
| services | −0,03 / −0,12 | −0,02 / −0,06 |

Границы и защита (fail-closed): эластичность вне `[−2,0; 0,0]` — отказ; относительное изменение
спроса одного шока больше 0,5 — отказ; неизвестная группа/классификация — отказ; нефинитные цены,
отрицательный базовый объём, отрицательный конечный спрос — отказ (маленькие отрицательные
`y`-реконсиляции канонической схемы тоже отвергаются: для них нужна отдельная конвенция).
Классификация отраслей повторяет правила моста (`CPA_B/C19/D35` и т.д. для FIGARO; `B05…B09/C19/D`
для OECD 2025) и дублируется в `src`, чтобы `src` не импортировал `tools`; тесты сверяют обе
классификации.

## 6. Ограничения

1. **Reduced-form, не поведенческая модель**: нет функции полезности, замещения между товарами,
   дохода/богатства, ожиданий и предложения. Числа не являются «эффектом шока на экономику».
2. **Эластичности — допущения**, не оценки: §4.3 показывает, что они и определяют масштаб.
3. **Линеаризация первого порядка**: шок Brent +125% — большой; ошибка растёт с шоком, поэтому
   результат — порядок величины, а не точная оценка.
4. **Леонтьев output effect спросовый**: `Δx = (I − A)⁻¹Δd` не является равновесием, не учитывает
   предложение, цены, ожидания и обратные связи; это «сколько выпуска потребовалось бы», а не
   «сколько выпуска будет».
5. **Промежуточный канал — отдельная reduced form**, а не стандартная модель промежуточного спроса;
   combined — сценарий, а не прогноз.
6. **Старый energy_plus50 — другая механика**, с этим каналом не сравнивается напрямую.
7. **MRIO сторонние**: в git не коммитятся, в отчёте только SHA-256, счётчики и агрегаты;
   нулевые секторы исключены из модели, что меняет базу на 1,6–1,9%.
8. **Один шок и два мира (2019)**: нет исторической валидации количественного канала; прогнать
   против фактов нельзя без PIT-рядов и модели замещения.

## 7. Воспроизведение

```powershell
python tools/quantity_bridge.py                 # оба мира, отчёт в build/quantity_bridge/
python tools/quantity_bridge.py --dataset figaro --pass-through 0.6 --horizon 6
python tools/quantity_bridge.py --elasticity-scales 0.5,1,1.5
python tests/test_quantity_channel.py           # 25 тестов
```

Коды возврата: `0` — отчёт собран; `2` — fail-closed (нет датасета и нет синтетического режима,
непродуктивная `A`, не сошёлся решатель, невалидные входы). Тесты покрывают: формулу эластичности и
ramp, монотонность/детерминизм, границы (отказ вне `[−2;0]`, неизвестная группа, отрицательный
объём, нефинитные цены, слишком большой шок, агрегатный предел), аналитическое решение Леонтьева
2×2 и тождество `(I−A)Δx = Δd`, структуру отчёта и разделение каналов, равенство ценового этапа
математике ценового моста, `pass-through 0 → 0`, монотонность по pass-through, детерминизм,
`BLOCKED_DATA` вместо падения, CLI.

# 147. Рынки: каркас и нефтяной модуль (Ормуз)

Дата: 2026-11-16. Автор: трек B волны 21 (исполнитель: pit-reconstructor). Статус:
**RESEARCH-ПРОТОТИП, RESEARCH_ONLY** — это не прогноз, не допуск, не инвестиционная рекомендация
и не сигнал к торговле. Основание: [docs/144](144_Товарные_модули_архитектура.md) (каркас рынков),
[docs/145](145_AMFE_2.0_план.md) (волна 21, трек B), [docs/121](121_Данные_MRIO.md) (лицензионная
политика), [docs/129](129_Схема_v1.1_и_WIOD.md) (MRIO-слой для моста издержек).

> **Короткий ответ.** Сделан общий контракт рыночного модуля и детерминированный движок
> баланса supply/demand/trade/stocks/price; первый модуль — Brent при закрытии Ормуза на 6 месяцев.
> Результат — **диапазон, не точка**: пик Brent **139,0–268,5 USD/bbl** (центрально 168,9),
> среднее за 6 месяцев **115,9–165,3** (центрально 130,1). Все входы — явные `assumption` с
> подсказкой «чем заменить»; ни одно число не выдаётся за наблюдаемое.

## 1. Архитектура

```
src/amfe/markets/
  contract.py  MarketModule (паспорт, scenarios, run, describe), Assumption (source_class:
               observed/derived/assumption), Scenario, MarketResult (path+range+sensitivity+checks,
               RESEARCH_ONLY), CostShock, registry (register/get_module/modules_document)
  engine.py    MarketCalibration (единицы mb/d, mb, USD/bbl; эластичности; запасы; risk premium),
               Shock (потеря/обход/SPR по месяцам), simulate() — детерминированный месячный
               баланс с бисекцией цены, MarketPath (checks, rows, summary), ramp/flat,
               run_variants(), price_range()
  oil.py       OilModule: сценарии «Ормуз закрыт 3/6 месяцев», «6 месяцев без SPR»;
               ASSUMPTION_SPECS (17 допущений + replace-with), SENSITIVITY_VARIANTS,
               prepare_cost_shock() — хук в MRIO
```

Идентичность месяца (проверяется в `MarketPath.checks`):

```
demand(price) + commercial_stock_draw(price) = supply_available
supply_available = baseline_supply − lost_supply + bypass + supply_response + strategic_release
```

Цена находится бисекцией по монотонному остатку; эластичность спроса **нарастает** от
краткосрочной к долгосрочной (рационирование/замещение накапливаются), затем добавляется risk
premium. Запасы: mb; потоки: mb/d; шаг — месяц (30,4375 дней для пересчёта запасов). Движок
fail-closed: несовместимые единицы, отрицательные запасы, неверный знак/порядок эластичностей,
план SPR больше запаса, неизвестный сценарий/параметр — исключение, а не «примерное число».
Детерминизм: нет времени/случайности, есть SHA-256 дайджест результата.

## 3. Сценарий «Ормуз закрыт 6 месяцев» — числа

| Месяц | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| Brent (центрально), USD/bbl | **168,86** | 139,86 | 123,48 | 119,78 | 116,13 | 112,47 |
| Доступное предложение, mb/d | 85,65 | 87,30 | 88,95 | 88,13 | 87,70 | 87,70 |

- **Пик**: 168,86 (месяц 1); **среднее** 130,10; **минимум** 112,47.
- **Диапазон пика**: **139,04–268,52** (центрально 168,86), разброс 76,7 %.
- **Диапазон среднего**: **115,86–165,30** (центрально 130,10).
- Использовано SPR: 150 mb (весь объявленный запас, ~3,3 месяца при 1,5 mb/d); коммерческий
  запас не израсходован (цена закрывает баланс до лимита — это раскрывается, а не скрывается).
- Дефицита «физически не поставлено» в центральном сценарии 0: баланс закрывается ценой и SPR.

**Чувствительность (влияние на пик):**

| Вариант | Пик, USD/bbl | Δ к центральному |
|---|---|---|
| эластичность более высокая (−0,35/−0,75) | 139,04 | −17,7 % |
| risk premium 0 | 156,86 | −7,1 % |
| обход выше (6,0 mb/d) | 164,54 | −2,6 % |
| закрытие 9 месяцев | 168,86 | 0 % (пик в 1-м месяце), но среднее 124,2 |
| отклик предложения ниже (0,5) | 169,77 | +0,5 % |
| обход ниже (2,5 mb/d) | 173,08 | +2,5 % |
| risk premium 25 | 181,86 | +7,7 % |
| эластичность ниже (−0,15/−0,40) | **268,52** | **+59,0 %** |

Сценарии модуля: `hormuz_closed_6m` (центральный, выше), `hormuz_closed_3m` (пик тот же 168,86,
но среднее 111,81 — восстановление быстрее), `hormuz_closed_6m_no_spr` (пик 180,34, диапазон
145,62–300,59).

## 4. Мост в MRIO (без правок world-ядра)

`module.prepare_cost_shock(result, pass_through=0.6, sector_shares=...)` возвращает `CostShock`:
`brent_delta_usd = 93,86`, `brent_delta_pct = 125,1 %`, множители издержек по универсальным
корзинам при pass-through 0,6: `energy 1,2253`, `transport 1,0901`, `manufacturing 1,0300`,
`services 1,0150`, `default 1,0225`. Корзины → отрасли MRIO сопоставляет вызывающая сторона
(например, energy → добыча/энергетика, transport → сухопутный/водный транспорт); схема
`amfe.markets.cost_shock.v1`, статус `RESEARCH_ONLY`, в допущениях явно помечено, что
pass-through — мостовое допущение, а не свойство рынка.

## 5. Как запускать

```python
from amfe.markets import oil, get_module, modules_document
module = get_module("oil.brent")
result = module.run("hormuz_closed_6m")          # MarketResult
result.summary["brent_range_usd_per_bbl"]        # {'low': 139.04, 'central': 168.86, 'high': 268.52}
cost = module.prepare_cost_shock(result)         # CostShock для MRIO
result.as_dict()                                 # агрегаты + допущения + чувствительность + checks
modules_document()                               # паспорта всех модулей
```

## 6. Ограничения (важно)

1. **Это не прогноз.** Нет калибровки на исторических эпизодах, нет OOS-валидации, нет оценки
   ошибки — поэтому нет и статуса допуска. Диапазон — по объявленным сценариям чувствительности,
   а не доверительный интервал.
2. **Параметры — допущения**, а не данные: 17 входов помечены `source_class="assumption"`;
   `replace_with` в `result.meta` указывает, чем заменить каждый. До замены числа нельзя
   использовать вне исследовательского контура.
3. **Эффективная эластичность** (−0,25/−0,55) включает неценовое рационирование; чистая ценовая
   эластичность дала бы арифметически >500 USD/bbl — это раскрыто и осознанно не используется.
4. **SPR/запасы** — объявленные планы, не оптимизация; коммерческий запас в центральном сценарии
   не расходуется (цена закрывает баланс).
5. **Нет торговли/маршрутов как отдельных объектов**: bypass и supply response входят в
   предложение; отдельный модуль маршрутов (фрахт) — следующий шаг архитектуры docs/144.
6. **Нет динамики инвестиций/добычи** (цена не влияет на будущее предложение) и нет обратной
   связи с макро — только односторонний мост издержек в MRIO.
7. **Один товар**: каркас общий, но проверен на нефти; агро/металлы — конфигурация + данные
   (docs/144), не в этой волне.

Метрики: ошибка пика и времени, ошибка среднего за 1/3/6 месяцев, попадание факта в объявленный
диапазон. Только после этого — калибровка эластичностей и pass-through; до тех пор статус
`RESEARCH_ONLY` остаётся.

# 216. OSINT-план market intelligence (без подписок)

Дата: 2026-11-21. Режим сети: **`OSINT_ONLY`**. Подписок и платных баз нет; закрытые базы не
используются. Это план lawful OSINT, а не доступ к чужим системам: только открытые публикации,
отчётность, регуляторные документы и новости; без обхода paywall/авторизации, без персональных
данных, без подкупа. `RESEARCH_ONLY`, `admission=false`.

## 1. Что разрешено

| Класс | Примеры | Как использовать |
|---|---|---|
| S1 — первоисточник | годовой отчёт, 10-K/20-F, пресс-релиз, регулятор | цитата + дата + ссылка; evidence A |
| S2 — официальная статистика | EIA, IEA (public), World Bank, OECD, Eurostat, SEC EDGAR | агрегаты/факты со ссылкой; evidence A/B |
| S3 — отраслевая пресса/аналитика | Reuters, FT, Argus/Platts public summaries | только как контекст, не как факт; evidence B |
| S4 — агрегаторы/энциклопедии | Wikipedia, базы компаний | стартовая навигация; evidence C, проверять |
| S5 — закрытые/платные | Bloomberg, WoodMac, S&P, ICE, Rystad | **не используются без подписки**; NOT_FETCHED |

## 2. Что запрещено (red lines)

- обход paywall, авторизации, robots/terms, лимитов;
- взлом, парсинг закрытых кабинетов, использование чужих ключей;
- персональные данные, телефоны, email, ФИО;
- подкуп, введение в заблуждение, выдача гипотезы за факт;
- санкционные нарушения и работа с подсанкционными лицами без комплаенса;
- публикация названий компаний как «клиентов» (только `not_client=true`, гипотезы).

## 3. 30-дневный план

| Неделя | Что делаем | Результат |
|---|---|---|
| 1 | 10 компаний: профиль, сегмент, 3 боли-гипотезы, buying center (роли) | досье `PARTIAL`/`HYPOTHESIS`, source log |
| 2 | 10 компаний: триггеры (отчётность, CAPEX, санкции, энергопереход) | 20 досье, приоритет топ-5 |
| 3 | Топ-5: первичные источники (годовые отчёты/сайты) → `PARTIAL` | evidence A/B, цитаты и даты |
| 4 | 50 кейсов: source plan, уточнение болей, English summary | обновлённые кейсы + KB merge |

Цель: **20 досье**, 5 с evidence A/B, 0 контактов, 0 отправленных писем.

## 4. Source plan для одного аккаунта

1. Официальный сайт: investor relations, annual report, strategy, CAPEX, projects.
2. Регулятор: SEC EDGAR (10-K/20-F), национальные реестры.
3. Статистика: EIA/IEA/World Bank/OECD — только если нужен рыночный контекст.
4. Пресса: 1–2 материала для триггеров, помечать как B/C.
5. Запись в KB: `source_id`, URL, дата, цитата, evidence, `review_due`.
6. Если источник закрыт — `NOT_FETCHED`, не выдумывать.

## 5. Роли и ворота

- **director** — выбирает 20 аккаунтов и вопросы;
- **osint-scout** — собирает S1–S4, ведёт source log;
- **segment roles** — формулируют боли/use cases;
- **evidence-qa** — проверяет цитаты, ставит A/B/C, запрещает VERIFIED без S1;
- **case-writer** — упаковывает в кейс;
- **kb-librarian** — merge/index, freshness.

## 6. Как пополнять базу знаний

```powershell
python tools/market_intel.py --mode osint --check
python tools/kb.py add --file knowledge_base/inbox/<role>.json
python tools/kb.py merge
python tools/kb.py index
python tools/kb.py --check
```

Правило: **нет ссылки/даты — нет записи**; `HYPOTHESIS` не становится `VERIFIED` без S1.

## 7. Ограничения текущей среды

- веб-поиск/сеть недоступны; URL/условия не проверены (`url_checked=false`);
- поэтому в KB нет `VERIFIED`, только `HYPOTHESIS`/`NOT_FETCHED`;
- нужен человек с доступом к сети/первоисточникам для подъёма evidence;
- публикация каталога — только как гипотезы, `not_client=true`.

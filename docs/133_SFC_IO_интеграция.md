# 133. SFC ↔ IO интеграция: счета стран, S = I + CA и шаг потоки–запасы

Дата: 2026-11-14. Статус: **реализовано и проверено на реальных данных FIGARO 2019; это
бухгалтерский блок, а не поведенческая модель.** Файлы:
[src/amfe/world/sfc_io.py](../src/amfe/world/sfc_io.py),
[tests/test_sfc_io.py](../tests/test_sfc_io.py), минимальные правки
[tools/world_pipeline.py](../tools/world_pipeline.py) (`--sfc`). Данные читаются из
`data/mrio/figaro/figaro_2019/dataset.json` только на чтение, не коммитятся.

## 1. Метод

Из снимка MRIO (канонический `MRIODataset`, `WorldTable` пайплайна или обычный mapping с
`countries/industries/Z|Z_sparse/y/x/va` и знаковыми `fda/vaa`) строится страновой блок:

```
GDP_c      = Σ_{i в блоке c} (va_i + vaa_i)                    (доходы)
FD_c       = Σ_{i в блоке c} (y_i + fda_i)                     (конечный спрос на продукцию c)
EX_int,c   = Σ_{j != c} Z[блок c, блок j]                      (промежуточный экспорт)
IM_int,c   = Σ_{j != c} Z[блок j, блок c]                      (промежуточный импорт)
CA_c       = EX_int,c − IM_int,c  ==  GDP_c − FD_c             (счёт текущих операций, две сверки)
A_c        = FD_c                                              (конвенция поглощения, см. §4)
C_c, I_c   — по доле инвестиций в поглощении (иначе не идентифицированы)
S_c        = GDP_c − C_c,     I_c = A_c − C_c
S_c        = I_c + CA_c                                       (тождество)
```

**Ключевой инвариант.** `CA_c` вычисляется двумя независимыми способами — из промежуточной
торговли (`EX_int − IM_int`) и из доходов/расходов (`GDP − FD`); при корректной таблице они
совпадают в пределах допуска таблицы, иначе `SFCIOError` (fail-closed). Это проверка согласованности
IO-таблицы без каких-либо поведенческих предпосылок.

**Тождество S = I + CA** выполняется при **любом** разбиении поглощения на потребление и
инвестиции: `S − I = GDP − A = CA`. Поэтому доля инвестиций (`investment_share`, по умолчанию 0 —
всё поглощение трактуется как потребление) влияет только на величины `S` и `I`, но не на
тождество; это явно проверяется тестом.

**Шаг периода (потоки–запасы).** Состояние — чистая внешняя позиция (NFA) страны. Транзакции
периода — счета текущих операций; финансирование дефицитов распределяется между странами с
профицитом пропорционально их профицитам (детерминированное правило, даёт неотрицательные
двусторонние потоки и `row − column = CA_c`). Шаг:

```
closing_c = opening_c + CA_c + revaluation_c ,   Σ_c opening = Σ_c CA = Σ_c revaluation = 0
```

Шаг собирается через `amfe.world.sfc_core.SFCFrame`, поэтому проверяются все SFC-инварианты: закрывающие =
открывающие + транзакции + переоценка поэлементно, суммы строк = суммы столбцов, мировой чистый капитал
= 0, межстрановые позиции погашаются, согласование чистой стоимости. Переоценка — единственная
знаковая фаза и обязана суммироваться в ноль (замкнутый мир); иначе отказ.

## 2. Что реализовано / что нет

Реализовано: агрегация IO до стран, две сверки `CA`, счета `C/I/S`, `S = I + CA`, NFA-шаг с
открывающими/транзакциями/переоценкой/закрывающими, SFC-валидация, компактный отчёт
`sfc_section()` (агрегаты, топ-профициты/дефициты, проверки, допущения), флаг `--sfc` в пайплайне
(без флага отчёт **не меняется** — обратная совместимость проверена тестом).

Не реализовано (сознательно): поведенческие функции (потребление, инвестиции, импорт), цены,
валютные курсы, процентные ставки, финансовые инструменты и запасы кроме NFA, разбивка конечного
спроса по назначению, согласование с финансовыми счетами FIGARO (их нет в датасете), динамика
NFA за пределами одного шага.

## 4. Допущения (почему именно так)

1. **Поглощение A_c = FD_c.** В датасете конечный спрос хранится по блоку страны-производителя;
   назначение (кто потребляет) не идентифицируется. Конвенция «конечный спрос продукции c
   поглощается в c» делает счета внутренне согласованными; при ней `CA` — это баланс
   **промежуточной** торговли, а не полный счёт текущих операций (торговля конечными товарами
   отсутствует в таблице). Это главное ограничение, а не свойство модели.
2. **Разбиение C/I не идентифицировано** (нет компонент конечного спроса). `S = I + CA` верно для
   любой доли; по умолчанию `I = 0`, `S = CA`.
3. **NFA — единственный запас.** Открывающие позиции по умолчанию нулевые; переоценка задаётся
   извне и должна суммироваться в ноль.
4. Финансирование дефицитов — пропорционально профицитам (детерминированное правило, не
   поведение).

## 5. Ограничения

* Данные — один год (2019); динамика NFA за пределами шага не строится, сравнивать эпохи нельзя.
* `CA` не включает конечные товары/услуги, доходы от факторов и трансферты: это IO-баланс
  промежуточных потоков; знаки и величины нельзя читать как официальный счёт текущих операций.
* ROW — отдельный блок; его профицит/дефицит (+163 033.43) остаётся в отчёте как есть.
* Нет цен, курсов, процентных ставок и финансовых инструментов; SFC-слой — только учётная схема.
* Нет point-in-time/винтажей: пересмотры FIGARO не моделируются.
* Отчёт пайплайна остаётся агрегатным: в `--sfc`-блоке нет сырых матриц, только агрегаты,
  проверки и допущения (при `include_countries=True` — страновые агрегаты).
* 12 тестов проверяют синтетику, разряженный/плотный формат, объект `WorldTable`, знаковые `fda/vaa`,
  тождества, шаг с переоценкой, fail-closed, детерминизм и флаг `--sfc`; реальный FIGARO в тестах не
  загружается (медленно), он проверен этим прогоном.

## 6. Воспроизведение

```
python tools/world_pipeline.py --synthetic --countries 6 --industries 4 --no-p2-gate --sfc
python tools/world_pipeline.py --dataset figaro --build --solve --sfc     # реальные данные
python tests/test_sfc_io.py                                               # 12 тестов

python - <<'PY'  # прямой вызов на реальном FIGARO
import json, sys; sys.path.insert(0, "src")
from amfe.world.sfc_io import sfc_section
doc = json.load(open("data/mrio/figaro/figaro_2019/dataset.json", encoding="utf-8"))
print(json.dumps(sfc_section(doc, investment_share=0.2, include_countries=True)["totals"]))
PY
```

`--sfc` добавляет в `world_pipeline_report.json` блок `sfc` (модуль, метод, страны, единицы,
итоги, топ-профициты/дефициты, проверки, допущения, `pass`); без флага блок не появляется —
отчёт байт-в-байт соответствует прежнему поведению (проверяется тестом).

## 5. Методика (формулы и правила)

- Доли: `s_t = X_t / GDPC1_t` по кварталам окна; параметр = среднее `s_t`, неопределённость = stdev,
  диапазон = min/max. Ряды разных частот приводятся к кварталам средним значением месяцев
  (для уровней, публикуемых как годовые ставки/уровни, среднее сохраняет смысл; квартальные ряды
  имеют одну наблюдённую точку на квартал). Пропуски FRED (`.`) отбрасываются, не заменяются нулём.
- NAIRU-прокси: `mean(UNRATE[2015-01..2019-12])` — окно устойчивого роста и низкой инфляции.
- Тренд производительности: OLS `ln(GDPC1/PAYEMS)` по кварталам baseline, наклон × 4 →
  `exp(4·slope) − 1` в %/год.
- Детерминизм: отчёт содержит `content_sha256` по параметрам/агрегатам/V2-проверкам/источникам
  (без `generated_at`) и SHA-256 каждого входного файла; тест `test_determinism` запускает калибровку
  дважды и сравнивает отчёты.
- Воспроизведение: `python tools/calibrate_core.py` на `data/raw` (git-ignored), куда распакован
  приватный артефакт `amfe-data-<run>` из `data-refresh`. Сырые ряды не публикуются; в отчёте только
  агрегаты, окна, источники, хеши и ограничения.

## 7. Ограничения

1. **Только US**; мировой контур требует страновых блоков и консистентной кросс-страновой
   классификации (V2_world_aggregation = NOT_APPLICABLE).
2. **Latest tape, не point-in-time**: калибровка использует последние файлы, а не винтажи; для
   REAL_TIME-версии стартовых значений нужно повторить калибровку на ALFRED-винтажах (данные для
   этого уже собираются: 18 рядов с плотным планом).
3. **Нет структурной идентификации**: доли расходов — тождественные агрегаты, NAIRU-прокси —
   среднее по окну, тренд производительности — OLS на выпуске на занятого; поведенческие
   параметры (эластичности, факторные доли, TFP) не оцениваются.
4. **Номинальный слой отсутствует**: нет номинального ВВП/дефлятора-как-ряда, нет процентных
   платежей/долга — фискальный и денежный блоки (11/12 docs/38) калибруются позже.
5. **Историческая неоднородность**: доли меняются структурно (гос. доля 25.9% → 16.6% ВВП), поэтому
   одно число — только стартовое значение; окна и разброс сохранены в отчёте, чтобы это не
   потерялось.
6. **Глубина винтажей новых рядов** различается (A191RL — с 2014, RSAFS — с 2001): для OOS-оценок
   мира это ограничит доступные точки; плановые даты до первого винтажа логируются как несопоставленные.
7. `data/raw` не коммитится; отчёт калибровки воспроизводим только при наличии артефакта
   `data-refresh` (процедура в §5).

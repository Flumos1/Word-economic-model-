## 2. Формулы

### 2.1 Правило ставки с инерцией

```
i_rule,t = r* + pi_t + phi_pi*(pi_t - pi*) + phi_y*y_t
i_t      = clip(rho*i_{t-1} + (1-rho)*(i_rule,t + shock_t), lower, upper)
```

Базовые значения: `r*=0,5`, `pi*=2,0`, `phi_pi=1,5`, `phi_y=0,5`, `rho=0,8`, границы `[0; 20]`.
При `pi=pi*`, `y=0` фиксированная точка `i = r* + pi* = 2,5`; шок ставки входит **внутрь**
сглаживания, поэтому постоянный шок +1 п.п. не «умножается» на `1/(1−rho)`, а сходится к +1 п.п.
до обратной связи через инфляцию и разрыв.

### 2.2 Передача в инфляцию и выпуск (редуцированная форма)

```
r_t  = (i_t - pi_t)/100
y_t  = y*_t + m_f*deficit_shock_t + gap_effect_t - beta*(r_t - r*_t)*100
pi_t = pi*_t + inflation_shock_t + gamma*(y_{t-1} - y*_{t-1})
g_t  = potential_growth + (y_t - y_{t-1})/100
```

`beta=0,5` п.п. разрыва на 1 п.п. реальной ставки, `gamma=0,25`, `m_f=0,5` — **допущения**
(A2–A4), не оценки. Лаг один: инфляция реагирует на прошлый разрыв, ставка — на текущую инфляцию
и прошлый разрыв.

### 2.3 Баланс ЦБ и ликвидность

```
assets      = bonds + fx_reserves + loans
liabilities = currency + reserves
equity      = assets - liabilities              (тождество, проверяется)
liquidity   = currency + reserves               (денежная база)
QE: bonds += X; reserves += X                   (тождество сохраняется)
```

Базовая калибровка — доли ВВП: облигации 0,30, FX 0,05, кредиты 0,02, наличные 0,10, резервы 0,27,
капитал 0,00; активы 0,37 ВВП, ликвидность 0,37 ВВП. QE-иллюстрация: покупка 5% ВВП увеличивает
облигации и резервы на 5 п.п. ВВП, ликвидность — на 5 п.п. ВВП, капитал не меняется. QE **не**
передаётся в доходности и цены (A8).

### 2.4 Долг и дефицит (r−g)

```
interest_t = r_t*b_t
D_t        = r_t*b_t - pb_t                     (общий дефицит, доля ВВП)
b_{t+1}    = (1+r_t)/(1+g_t)*b_t - pb_t         (тождество)
snowball_t = (r_t - g_t)/(1+g_t)*b_t
pb*_t      = (r_t - g_t)/(1+g_t)*b_t            (стабилизирующий первичный баланс)
```

`r`, `g`, `pb`, `b` — десятичные доли ВВП; `r−g<0` — долг снижается при `pb=0`, `r−g>0` —
растёт. Реализация сверена с [`dynamics/debt.py`](../src/amfe/dynamics/debt.py): путь совпадает
до 12 знаков (тест `test_debt_path_matches_the_project_identity`).

### 2.5 Связь с T1/T3

* **T1** (CPI г/г): `inflation_path_from_t1({"h1":…,"h2":…})` даёт `pi*_t`; горизонты должны быть
  непрерывными с `h1`, недостающие — продлеваются последним значением. Это адаптер, а не оценка T1.
  В CLI: `--t1 t1.json` (нет файла — код 2, битый JSON — код 1).
* **T3** (вероятность рецессии): `gap = -scale*max(0,(p-threshold)/(1-threshold))`,
  `scale=2,0` п.п., `threshold=0,35`. Связь линейна и является допущением A7; вероятность 0,35 и
  ниже даёт нулевой разрыв, 1,0 — минус 2 п.п. В CLI: `--t3 0.8`.

### 2.6 SFC-связь

```
S = I + CA                                  (P2 0.2, docs/146 §4)
S = S_private + S_government
S_government = -D                           (чистое кредитование государства)
residual = S_private + S_government - I - CA = 0
```

В отчёте `S_private` — **остаток** `S + D`, а не поведенческая функция; это подчёркнуто в
`sfc.note` и в ограничениях.

Пояснения к числам:

* **Ставка +100 б.п.** Шок держится 1 п.п. выше правила. Наблюдаемая ставка к концу горизонта
  +0,60 п.п. (максимум — 12-й период): инфляция падает до 1,91% (−0,09 п.п.), разрыв −0,35 п.п.,
  долг на 3,63 п.п. ВВП выше базы. Разница между «+1,00 в правиле» и «+0,60 наблюдаемых» —
  endogenous feedback: падение инфляции и разрыва снижает и саму ставку. Это не ошибка счёта, а
  свойство сценария; в отчёте есть и `rule_rate_pp`, и `delta_policy_rate_pp` по периодам.
* **Дефицит +2% ВВП.** Первичный баланс ниже базы на 2 п.п.; к концу дефицит +2,55 п.п. из-за
  процентной нагрузки, долг +25,41 п.п. ВВП за 12 лет, разрыв +0,70 п.п., инфляция +0,18 п.п.,
  ставка +0,77 п.п. `r−g` в начале −2,0%: даже при отрицательном `r−g` постоянный первичный
  дефицит 2% ВВП доминирует.
* **Тарифы/инфляционный шок +1,5 п.п.** Импульс 1,5 п.п. с затуханием 0,5: пик инфляции +1,50 в
  1-м периоде, к концу — почти ноль (−0,01). Ставка реагирует с пиком +0,97 п.п. во 2-м периоде,
  разрыв — минимум −0,40 п.п. в 3-м. Долг +1,26 п.п. ВВП. Это **не** оценка тарифов (блок 16), а
  проверка передачи шока при допущениях A2–A3.
* **Баланс ЦБ:** активы 37,0, ликвидность 37,0 (37% ВВП), капитал 0; QE 5% ВВП → облигации и
  резервы +5 п.п. ВВП, ликвидность +5 п.п. ВВП, тождество PASS.
* **SFC:** `S=20% = I=21% + CA=−1%`, остаток 0; чистое кредитование государства `=−D`; частные
  сбережения как остаток `S+D`. Максимальный остаток всех тождеств — **1,73e−16**.

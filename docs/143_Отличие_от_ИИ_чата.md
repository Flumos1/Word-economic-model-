# 143. Чем результат AMFE отличается от простого запроса к ИИ-чату

Дата: 2026-11-15. Вопрос клиента: «Если мы построим сценарий Ормуза и получим цену дизеля — чем это
лучше, чем просто спросить ChatGPT/Claude?» Короткий ответ: **не «магической точностью», а
проверяемостью, управляемостью и встроенностью в решение.** Пока нефтяной модуль не
валидирован, мы не заявляем, что наш точечный прогноз точнее — мы заявляем, что его можно
проверить, повторить, оспорить и пересчитать под клиента.

## 1. Одна и та же задача: два разных продукта

Запрос: «Сколько будет стоить дизель в США через полгода, если Ормуз перекрыт на полгода?»

| | ИИ-чат | AMFE-сценарий |
|---|---|---|
| Что на выходе | связный текст с числом | числа + диапазоны + таблицы + файлы (PDF/Excel/JSON) |
| Откуда число | «из головы» модели, без источника | из явных допущений и расчёта; источник и дата у каждого входа |
| Допущения | скрыты, меняются от запроса к запросу | перечислены, версионированы, можно заменить |
| Повторяемость | другой запуск — другой ответ | SHA-256, код, версии данных, команда пересборки |
| Неопределённость | одна цифра «уверенным тоном» | сценарии + чувствительность + границы |
| Проверка | нельзя проверить, кроме «звучит логично» | можно пересчитать, сверить с балансами, оспорить |
| Согласованность | может противоречить сам себе | жёсткие тождества: Z, y, x, SFC, суммы |
| Кастомизация | общие рассуждения | параметры клиента: длительность, SPR, эластичности, страны, отрасли |
| Обновление |knowledge cutoff, без новых данных | новые данные/винтажи, новая версия модели |
| Аудит/ответственность | нет audit trail | methodology appendix, журнал версий, ограничения |
| Цена | ~$0–20/мес | пилот $6–30 тыс. |

## 2. Что именно покупает клиент

Не «ответ», а **процесс принятия решения**:

1. **Сценарии, а не одна цифра.** «Если перекрытие 3 месяца и SPR 2 млн барр./сут — $5,5–6,0.
   Если 6 месяцев и SPR 1 млн — $6,5–7,5. Если добавляется tanker-риск — $8+».
2. **Чувствительность.** Клиент видит, какой параметр двигает цену сильнее всего, и может
   поспорить с допущением, а не со всем ответом.
3. **Воспроизводимость.** Через месяц можно пересчитать с новыми данными и объяснить, почему
   цифра изменилась.
4. **Защита решения.** Перед советом директоров/регулятором можно показать методологию, источники,
   версии, ограничения — а не «так сказала нейросеть».
5. **Интеграция.** Числа уходят в Excel/JSON/API клиента, а не остаются в чате.

## 3. Где ИИ-чат действительно хорош

- Быстрая гипотеза, брейншторм, черновик списка факторов.
- Объяснение «на пальцах» для неспециалиста.
- Перевод, суммаризация, генерация текста отчёта.
- Дешёвый первый экран: «стоит ли вообще копать».

Поэтому правильная архитектура — **не «AMFE вместо ИИ», а ИИ как интерфейс, AMFE как счётная
машина»**: чат понимает вопрос и объясняет результат, но **числа берёт только из движка**.

## 4. Гибридная схема (то, что стоит продавать)

```
вопрос клиента
   → ИИ-интерфейс: уточняет сценарий, выбирает шаблон, вызывает инструменты
   → AMFE-движок: данные → балансы → сценарий → цена/эффекты → проверки
   → ИИ-слой: объясняет, но НЕ придумывает числа (только из ответа движка)
   → клиентский пакет: PDF/Excel/JSON/dashboard + SHA-256 + ограничения
```

Правила безопасности:
- ИИ не имеет права называть число, которого нет в ответе движка;
- каждое число сопровождается источником/допущением;
- при отсутствии данных — «нет данных», а не правдоподобная догадка;
- все расчёты воспроизводимы и логируются.

## 5. Честно о точности

- ИИ-чат может дать **правдоподобный** ответ; AMFE без валидированного нефтяного модуля — тоже
  всего лишь **структурированную оценку**. Мы не утверждаем, что она точнее.
- Преимущество появляется, когда модуль **бэктестирован** на 1990/2019/2022 и откалиброван:
  тогда можно говорить об ошибках, а не о «мнении».
- До этого наш продукт — **auditable scenario analysis**: не «прогноз», а «расчёт при допущениях».
  Это честная и продаваемая ценность: клиент покупает не иллюзию точности, а управляемость.

## 6. Когда достаточно ИИ-чата

- низкая цена ошибки, разовое любопытство, нет требований к аудиту;
- нужен текст/идея, а не числа;
- нет бюджета на данные и валидацию.

## 7. Когда нужен AMFE

- на кону деньги/репутация (закупки, портфель, тарифы, бюджет);
- решение повторяется (ежемесячно/ежеквартально) и должно обновляться;
- нужны числа в их моделях (Excel/API);
- нужна защита перед советом/регулятором/аудитором;
- сценарий нестандартный (Ормуз, санкции, FX, энергошок) и требует явных допущений.

## 8. Как это влияет на цену

| Продукт | Что покупает клиент | Цена |
|---|---|---|
| ИИ-чат | черновик мысли | ~$0–20/мес |
| AMFE: быстрая записка | диапазон + допущения + брифинг | $6–10 тыс. |
| AMFE: полный сценарий | пакет файлов + чувствительность + макро-эффекты | $18–30 тыс. |
| AMFE: нефтяной модуль | модель + бэктест + интеграция | $35–60 тыс. |
| AMFE: подписка | регулярные обновления + поддержка | $20–100 тыс./год |

## 9. Итог одной фразой

**ИИ-чат даёт правдоподобный ответ; AMFE даёт проверяемый расчёт, который можно защитить, обновить
и встроить в решение.** Пока нет валидации — мы продаём именно проверяемость, а не превосходство
в точности.

## Решение владельца (2026-11-11)
**Ни у кого разрешений не запрашиваем. Работаем только с открытой информацией, а всё недостающее заменяем собственными моделями.** Запрос в Atlanta Fed не отправляется. Это отражено в v3: `meta_gate.owner_decisions`, `licence_policy.no_permissions`, `licence_policy.substitute`.

## Зачем v3
1. **Лицензия.** В v2 основной компаратор для ВВП на горизонте 0 включал GDPNow и наукаст NY Fed. Раз разрешений не будет, **GDPNow не используется нигде**; его замена — собственный наукаст `OWN_NOWCAST_BRIDGE` из открытых данных.
2. **Замечания проверки v2** ([docs/58](58_Независимая_проверка_протокола_v2.md), R-01…R-17).
3. **Замечания проверки v3** ([docs/61](61_Независимая_проверка_протокола_v3.md)): 4 блокирующих и **13 неблокирующих** замечаний (V3-01…V3-17).
4. **Сверка правок** ([docs/62](62_Сверка_правок_протокола_v3.md)): редакция 0.2 закрыла 4/4 блокирующих и 10/13 неблокирующих; найдено новое блокирующее противоречие **Б-1** (правило разрешения T3) и семь неблокирующих замечаний **Н-1…Н-7**. Все они исправлены в редакции 0.3 (раздел «Что исправлено в 0.3»).
5. **Лицензионный аудит** ([docs/63](63_Лицензионный_аудит_2026-11-11.md)): реестр сверен с первоисточниками заново, цитаты и известные неопределённости записаны в реестр; часть условий остаётся непроверенной (BEA, SPF-документация, архивы Cleveland/NY Fed, дата старта T10Y3M).

## Шесть подтверждённых пунктов (2026-11-11)
1. **Окно T3 — 240 месяцев** (вместо 180), окна чувствительности 180 и 360.
2. **Ужесточающие прочтения R-05, R-06, R-08, R-09:** критерии выполняются для каждой применимой функции потерь; C2 — тест с поправкой Romano–Wolf; определение инструмента в C4.
3. **Канал данных и правило лицензий:** ручная загрузка файлов версий из ALFRED, ничего не коммитится, без обучения моделей на содержимом FRED; минимальное число членов компаратора — 2; источник с непроверенными условиями нигде не используется.
4. **Philadelphia Fed (SPF, RTDSM) и Cleveland Fed — открыты для некоммерческого исследования.** Проверяющий предложил более осторожное прочтение (RESTRICTED); я прочёл их условия как разрешающие исследование без запроса (docs/63 §2.11 — Philadelphia и §2.7 — Cleveland, §4: текст буквально называет research у Philadelphia и «noncommercial» у Cleveland). Обратное решение уберёт SPF из компаратора и RTDSM из источников винтажей.
5. **Ковидные цели вне W2:** начала, цели которых лежат в 2020-03…2021-02, выводятся из W2 и отчитываются отдельно.
6. **Репозиторий остаётся приватным.** Если он станет публичным, все записи реестра перепроверяются.

## Известные ограничения
- Лицензии проверены по страницам сайтов 11.11.2026 (уровни «целиком» или «извлечение» указаны в реестре); это не юридическая консультация. Условия меняются без уведомления; на R2 сохраняются хеши текстов условий.
- Для ВВП на горизонте 0 собственный наукаст есть только с тех начал, где его входы доступны в реальном времени; до 1999 года такого члена нет, поэтому планка допуска на этом горизонте может быть ниже, чем с лучшим публичным наукастом (оговорка обязательна в каждом отчёте).
- Условия документации SPF, страниц файлов данных Philadelphia Fed и Real-Time Data Set, условия BEA, архив реального времени Cleveland и пригодность «values-only» архива NY Fed не проверены — это задачи R2 (docs/63 §3).
- Условия BLS прочитаны (public domain, citation requested), но доступность винтажей BLS как канала ещё не проверена.
- `comparator_minimum` выполняется на текущем реестре (T1 — 5, T2 — 5, T3 — 2 OPEN-члена); при смене статуса Philadelphia/Cleveland состав изменится по правилу реестра, и пара может вернуться в CANDIDATE.
- Для T3 прогноз разрешается не раньше, чем хронология NBER покроет интервал (обычно позже `origin + h`); неразрешённые прогнозы не входят в C6, поэтому журнал T3 набирает 12 исходов медленнее — это указывается в каждом отчёте по T3.

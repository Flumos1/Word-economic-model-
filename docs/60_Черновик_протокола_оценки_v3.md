# AMFE — черновик протокола оценки v3 (статус DRAFT)
Версия 0.2 · 2026-11-11. Файлы: [protocols/evaluation_protocol_v3.json](../protocols/evaluation_protocol_v3.json), [protocols/licence_register.json](../protocols/licence_register.json), тест [tests/test_protocol_v3.py](../tests/test_protocol_v3.py). Заменяет [v2](57_Черновик_протокола_оценки_v2.md) для всех новых оценок. v2 и v1 **остаются в репозитории нетронутыми** и заморожены; v3 ссылается на хеш v2.

## Решение владельца (2026-11-11)
**Ни у кого разрешений не запрашиваем. Работаем только с открытой информацией, а всё недостающее приближаем собственными моделями.** Запрос в Atlanta Fed не отправляется. Это отражено в v3: `meta_gate.owner_decisions`, `licence_policy.no_permissions`, `licence_policy.approximation`.

## Зачем v3
1. **Лицензия.** В v2 основной компаратор для ВВП на горизонте 0 включал GDPNow и наукаст NY Fed. Раз разрешений не будет, **GDPNow не используется нигде**; его замена — собственный наукаст `OWN_NOWCAST_BRIDGE` из открытых данных.
2. **Замечания проверки v2** ([docs/58](58_Независимая_проверка_протокола_v2.md), R-01…R-17).
3. **Замечания проверки v3** ([docs/61](61_Независимая_проверка_протокола_v3.md)): 4 блокирующих и 11 неблокирующих (V3-01…V3-15). Все блокирующие и неблокирующие учтены в этой редакции.

## Статус и что нужно для принятия
- Стадия meta-gate D-100: независимая проверка v3 нашла блокирующие замечания; **редакция 0.2 исправляет их, исправления должен сверить проверяющий.** Утверждения и заморозки нет. Решение D-128 в журнал **не внесено**.
- **Нужно ваше подтверждение** (поле `meta_gate.owner_confirmation_needed`) — шесть пунктов, ниже.

## Как исправлены блокирующие замечания
| № | Что было | Что сделано |
|---|---|---|
| V3-01 | Для ВВП и рецессии компаратор пуст, для инфляции — одна модель; правила на этот случай нет | Правило `comparator_minimum`: не менее 2 членов на потерю, иначе пара остаётся CANDIDATE и допуску не подлежит; источники указаны **по целям**. После пересмотра реестра на сегодня у каждой цели есть не менее двух членов |
| V3-02 | Реестр лицензий лежит в замороженном файле, а менять его нужно | Реестр вынесен в **отдельный журнал** `protocols/licence_register.json` с датированными записями; новая запись действует только для кандидатов, оцениваемых после неё; состав компаратора хешируется по дате |
| V3-03 | Реестр по группам, без «намеченного использования» | Реестр по **рядам и источникам**; определено намеченное использование: некоммерческое исследование, публикуются только производные статистики, без сырых данных |
| V3-04 | Условия FRED/ALFRED запрещают сбор роботом, хранение через API и обучение моделей на их содержимом; «без разрешений» закрывает простой выход | `licence_policy.data_channel`: файлы версий основных рядов скачиваются **вручную**, по одному на ряд, без робота и без кэша API, в репозиторий не попадают; обучение моделей на содержимом FRED запрещено; запасной канал — первичные источники (BLS, BEA, Минфин, ФРС), условия которых ещё не читали |

Неблокирующие V3-05…V3-15 внесены в ту же редакцию (определения C4 и C5, исход «неопределённо», разрешение прогнозов по рецессии, классы реального времени, окна по началам и целям с исключением ковидных целей из W2, распределения базовых моделей и смесь вместо усреднения квантилей, формула CRPS и обрезка логарифмической оценки, окна чувствительности для рецессии и калибровка вместо охвата).

## Шесть пунктов, которые решаете вы
1. **Окно T3 — 240 месяцев** (вместо 180), окна чувствительности 180 и 360.
2. **Ужесточающие прочтения R-05, R-06, R-08, R-09:** критерии выполняются для каждой применимой функции потерь; C2 — тест с поправкой Romano–Wolf; определение инструмента в C4.
3. **Канал данных и правило лицензий:** ручная загрузка файлов версий из ALFRED, ничего не коммитится, без обучения моделей на содержимом FRED; минимальное число членов компаратора — 2; источник с непроверенными условиями нигде не используется.
4. **Philadelphia Fed (SPF, RTDSM) и Cleveland Fed — открыты для некоммерческого исследования.** Проверяющий предложил более осторожное прочтение (RESTRICTED); я прочёл их условия как разрешающие исследование без запроса. Обратное решение уберёт SPF из компаратора.
5. **Ковидные цели вне W2:** начала, цели которых лежат в 2020-03…2021-02, выводятся из окна W2 и отчитываются отдельно.
6. **Репозиторий остаётся приватным.** Если он станет публичным, все записи реестра перепроверяются.

## Известные ограничения
- Лицензии проверены по страницам сайтов 11.11.2026 (уровни «целиком» или «извлечение» указаны в реестре); это не юридическая консультация. Условия меняются без уведомления.
- Для ВВП на горизонте 0 собственный наукаст есть только с тех начал, где его входы доступны в реальном времени; до 1999 года такого члена нет.
- Условия документации SPF и страниц файлов Philadelphia Fed не читались; их нужно перечитать до первой загрузки (R2).
- Условия BLS и BEA не читались.

# AMFE — черновик протокола оценки v3 (статус DRAFT)
Версия 0.1 · 2026-11-11. Файл: [protocols/evaluation_protocol_v3.json](../protocols/evaluation_protocol_v3.json), тест: [tests/test_protocol_v3.py](../tests/test_protocol_v3.py). Заменяет [v2](57_Черновик_протокола_оценки_v2.md) для всех новых оценок. v2 и v1 **остаются в репозитории нетронутыми** и заморожены; v3 ссылается на хеш v2.

## Зачем v3
1. **Лицензия.** В v2 основной компаратор для ВВП на горизонте 0 включал GDPNow и наукаст ФРБ Нью-Йорка. Архив GDPNow разрешён «для личного и учебного использования», публикация и производные работы требуют письменного разрешения. Компаратор, который нельзя пересчитать другим людям, ориентиром не является.
2. **Замечания проверки v2.** Независимая проверка ([docs/58](58_Независимая_проверка_протокола_v2.md)) дала 17 неблокирующих замечаний R-01…R-17. Все они закрыты в одной версии, пока по v2 нет ни одного результата и пересчёт пуст.

## Статус и что нужно для принятия
- Стадия meta-gate D-100: PROPOSE пройдена. **Независимая проверка и утверждение не выполнены.** Проверять должна не та сессия, что писала черновик.
- Решение D-128 в журнал **не внесено**.
- **Нужно ваше подтверждение трёх пунктов** (поле `meta_gate.owner_confirmation_needed`):
  1. окно оценивания для T3 — **240 месяцев вместо 180** (в v2 одна-две рецессии в окне не позволяют оценить пробит; единственное изменение числового параметра);
  2. ужесточающие прочтения R-05, R-06, R-08, R-09 (критерии должны выполняться для каждой применимой функции потерь; C2 — тест с поправкой Romano–Wolf; определение инструмента в C4);
  3. правило «источник с непроверенной лицензией в основной компаратор не входит».

## Важное следствие: компараторы для ВВП и рецессии пока пусты
Из ряда ALFRED проверена лицензия только у `CPIAUCSL` («public domain, citation requested»). Лицензии остальных рядов (ВВП, USREC, кривая доходности, базовый CPI), FRED-MD/QD, SPF и Cleveland Fed **не проверены**. По новому правилу источник без подтверждённого статуса OPEN в компаратор не входит, так что до этапа R2 основной компаратор определён только для T1 (по `CPIAUCSL`). Это не ошибка черновика, а прямое следствие правила; проверка лицензий рядов — обязательная задача R2.

## Известные ограничения черновика
- Лицензии проверены по страницам сайтов 11.11.2026; это не юридическая консультация.
- Окно T3 в 240 месяцев в 1990–2006 годах требует данных с 1970-х; для рецессий 1970-х и 1980-х полноценных реальных версий может не хватить (проверка R2).
- Правило «UNVERIFIED исключается» консервативно; если часть источников окажется OPEN, состав компаратора вырастет без смены версии протокола.

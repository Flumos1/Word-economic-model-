## Что означает «закрыто»
Закрыта **спецификация**: что прогнозируем, на чём сравниваем и по каким критериям допускаем модель. Не закрыто и не выполнено: сбор данных, базовые модели, бэктест, журнал будущих прогнозов. Пороги в C1–C6 — **начальные рабочие значения**, выбранные из практики литературы, а не доказанные оптимумы. Менять их можно только новой версией протокола (v2) через meta-gate D-100; результаты v1 сохраняют свой вердикт.

**Заморозка не абсолютна.** Тест и хеш защищают от случайной правки, но любой может изменить файл, тест и хеш одним коммитом. Для реальной неизменяемости нужна подписанная метка git `protocol-v1` на коммите с протоколом; без неё это договорённость, подтверждаемая историей репозитория.

## D-121 · Q-001 — что прогнозируем первым
Объект — США. Три цели, каждая со своими горизонтами:

| Цель | Определение | Горизонты |
|---|---|---|
| T1 инфляция | рост CPI г/г: общий и базовый индексы отдельно | 1, 3, 6, 12 месяцев |
| T2 рост ВВП | 400·ln(ВВП_q/ВВП_(q−1)), реальный, кв/кв в годовом выражении | 0 (наукаст), 1, 2, 4 квартала |
| T3 рецессия | вероятность хотя бы одного месяца рецессии NBER в (t, t+h] | 3, 6, 12 месяцев |

Горизонты 1/3/6/12 месяцев из ТЗ для ВВП соответствуют 0/1/2/4 кварталам. Для наукаста (горизонт 0) начала прогноза в 1-м, 2-м и 3-м месяце квартала считаются отдельно.
**Ограничение T3:** послевоенных рецессий около восьми, поэтому мощность любого статистического теста низкая. Потолок для T3 — статус LIMITED_DEPLOYMENT, до ACTIVE по одним оценкам не доходит.
Остаётся вне первой очереди (Q-020): курсы валют, BTC, золото. Курсы валют на горизонте до года труднее случайного блуждания (Meese & Rogoff 1983).

## D-122 · Q-002 — источники прогнозов
**«20 источников» перестаёт быть требованием.** Важна не численность, а то, что у источника есть дата публикации каждого прогноза и накопленный архив. Правило допуска источника: (1) метка времени публикации у каждого прогноза; (2) архив доступен или накапливается с сегодняшнего дня; (3) лицензия разрешает хранение. Доступность архивов — уровень **U**: подтверждается тестом в R2, а не принимается на веру.

| Уровень | Источники | Тип | Решение |
|---|---|---|---|
| A, использовать в R2 | Philadelphia Fed SPF | прогноз | основной внешний ориентир |
| | FOMC SEP; Greenbook/Tealbook (публикуется с задержкой около 5 лет) | прогноз | только для исторического окна |
| | CBO, IMF WEO, OECD Economic Outlook | прогноз | годовые и полугодовые винтажи |
| | Atlanta Fed GDPNow, NY Fed Staff Nowcast, Cleveland Fed inflation nowcast | наукаст | горизонт 0 для ВВП и инфляция |
| | Университет Мичигана (ожидания инфляции), Dallas Fed WEI | индикатор | не прогноз; как признаки |
| | ECB SPF | прогноз (еврозона) | после США |
| B, только при лицензии и архиве | Consensus Economics, Blue Chip, EIU, Bloomberg survey, ECRI, Gavekal | прогноз / аналитика | платные либо без открытого архива |
| C, вне количественного ансамбля | Caixin (PMI — индикатор Китая), Kiel Institute, аналитические школы без датированных количественных прогнозов (в том числе упомянутые в карте идей, P-003 документа 07) | индикатор / текст | сохраняются в реестре идей; в ансамбль — после появления датированного архива |

## D-123 · Q-003 — данные реального времени
Основа: **ALFRED** (винтажи FRED), **Philadelphia Fed Real-Time Data Set for Macroeconomists**, архив винтажей **FRED-MD/FRED-QD**. Критерий ворот R2: восстановление «что было известно на дату t» для 2000–2026; выборочная проверка не менее 30 пар (ряд, дата) должна совпасть с первичным релизом того времени с точностью до округления. Пока ворота не пройдены, винтажи не считаются подтверждёнными.

## D-124 · Q-004 — базовые модели
Набор: RW, AO (Atkeson–Ohanian), AR по BIC, BVAR Миннесота, DFM на FRED-MD/QD, пробит по кривой доходности (T3), медиана SPF, внешние наукасты (T2, горизонт 0), равновесная комбинация. «Сильным базовым уровнем» для каждой пары (цель, горизонт) считается **основной компаратор**: модель с наименьшей потерей на окне отбора 1985–1989, определяется до оценки кандидатов. Кандидат сравнивается, кроме того, с каждой из остальных базовых моделей, и результат по каждой публикуется.

## D-125 · Q-005 — что считать фактом
Две цели оценки, результаты **не смешиваются**: основная — первая публикация значения; вторичная — значение в винтаже через 12 месяцев после отчётного периода. CPI почти не пересматривается, для ВВП различие существенно. Для T3 берётся хронология NBER на дату оценки.

## D-126 · Q-006 — критерии допуска новой модели
Допуск **по паре (цель, горизонт)**: модель может быть ACTIVE для одной пары и не допущена для другой. Одновременно выполняются условия:

| № | Условие |
|---|---|
| C1 | относительная потеря (кандидат / основной компаратор) ≤ 0,97 отдельно на окнах W1 (1990–2006) и W2 (2007–2019) |
| C2 | тест условной прогнозной способности Giacomini–White, HAC с h−1 лагом и поправкой малой выборки, односторонний p < 0,10 на W1 и на W2 |
| C3 | кандидат входит в Model Confidence Set 90 % против всех базовых моделей |
| C4 | относительная потеря ≤ 1,00 в месяцы рецессий NBER; если таких месяцев меньше 12, вердикт «неубедительно» |
| C5 | не значимо хуже основного компаратора на вторичной цели (D-125) |
| C6 | 12 подряд месяцев журнала будущих прогнозов: накопленная относительная потеря ≤ 1,00, фактическое покрытие интервалов в пределах 10 процентных пунктов от номинального |

Переходы статусов (P05, D-101): CANDIDATE → SHADOW_TEST по C1–C5; SHADOW_TEST → LIMITED_DEPLOYMENT по C6; LIMITED_DEPLOYMENT → ACTIVE при повторе C6 во втором непересекающемся блоке из 12 месяцев без срабатывания триггеров дрейфа.
**Множественные проверки:** все оценённые кандидаты, включая отклонённые, записываются, их число входит в каждый отчёт; контроль доли ложных открытий Benjamini–Hochberg при q = 0,10, а при более чем 20 кандидатах против одного компаратора — White Reality Check или Hansen SPA.
**Триггеры дрейфа:** тест Giacomini–Rossi на срыв прогноза при 10 %; покрытие интервалов за последние 24 месяца вне номинального ±15 п.п. Действие: SUSPENDED и пересмотр по D-101, откат только к предыдущей ACTIVE-версии.

## Окна оценки и честность
| Окно | Период | Роль |
|---|---|---|
| отбор | 1985-01…1989-12 | выбор основного компаратора; настройка кандидатов запрещена |
| W1 | 1990-01…2006-12 | оценка |
| W2 | 2007-01…2019-12 | оценка |
| W3 | 2020-01…2026-11 | только отчёт о стрессе: исследователь и ИИ-агенты знают этот эпизод |
| журнал будущих прогнозов | с первого коммита журнала, без задним числом | **единственное неискажённое окно** |

W1–W3 нельзя считать чистой проверкой: знание истории проникает через выбор моделей. Поэтому C6 — обязательное условие для любого допуска выше SHADOW_TEST.

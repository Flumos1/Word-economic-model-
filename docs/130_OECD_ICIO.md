## 1. Что удалось скачать (автоматически, официальный канал)

Глубокий проход (Data Explorer JS/конфиги, SDMX, CDX, availability API, старые страницы)
показал: файлы ICIO **не** публикуются в SDMX/Data Explorer, но официальные per-year архивы
OECD **сохранены в Internet Archive** и были скачаны плейбэком Wayback (без обхода защиты, без
сторонних зеркал — это объекты `www.oecd.org`):

| Параметр | Значение |
|---|---|
| Редакция | **OECD ICIO 2016 edition** (ISIC Rev. 3), релиз April 2017 |
| Файлы | `ICIO2016_1995.zip` … `ICIO2016_2011.zip` — **17 файлов**, 4,40–5,90 МБ (всего ≈ **88,4 МБ**) |
| Архивный URL (пример 2011) | `https://web.archive.org/web/20210310170654id_/http://www.oecd.org/sti/ind/ICIO2016_2011.zip` |
| Контент | один CSV на файл (`ICIO2016_<year>.csv`, ≈26,7 МБ для 2011), current prices **USD million** |
| Годы | **1995–2011** |
| Экономики | **71** (63 страны + China CN1–CN4, Mexico MX1–MX3, ROW) |
| Отрасли | **34** (ISIC Rev.3: C01T05AGR … C95PVH) |
| Лицензия | OECD Terms and Conditions (принятие — на стороне пользователя; архив официальный) |

Проверка целостности: каждый zip проверен по magic-байтам (`PK`) и распакован; CSV
распарсен полностью; SHA-256 датасетов записаны в отчёт конвертации. Команда воспроизведения:

```powershell
python tools/oecd_import.py --wayback --convert --jobs 3 --root "F:\Мировая экономика модель\data\mrio\oecd_icio"
```

## 2. Что было проверено для «главного» релиза 2025 (и почему автоматически нельзя)

| Канал | Проверка 2026-11-14 | Результат |
|---|---|---|
| `oecd.org/en/data/datasets/inter-country-input-output-tables.html` | браузерные заголовки+сессия+cookies | 200 (HTML), прямых файлов нет; файловые URL на `www.oecd.org` → **403** (Cloudflare) |
| Data Explorer | JS bundle `static/index.wd2pJFxa.js` (1,67 МБ) разобран | бэкенд `sdmx.oecd.org/public/rest` (dotstat v2), export = SDMX CSV/JSON по dataflow; **сырых ICIO dataflow нет** |
| Полный список dataflow | 1 553 dataflow (10,4 МБ) | ICIO как таблиц нет; есть только производные GHGFP (`DSD_ICIO_GHG_*`) и TiVA/TiM — не Z/VA |
| SDMX v2 ICIO-догадки | `DSD_ICIO@DF_ICIO`, `_2023`, `_2025` | **204/404** (dataflow отсутствует) |
| `stats.oecd.org/wbos/fileview2.aspx?IDFile=<guid>` | проверено на известных GUID | **работает** (отдаёт PDF/XLSX 200), но GUID'ов ICIO в открытых страницах/снапшотах нет |
| Wayback availability для `ICIO2018/2021/2023/2025_<year>.zip` | скан 100+ вариантов | **0 снапшотов** (архивирована только редакция 2016) |
| DAM-пути `content/dam/...icio...` | догадки + CDX | 404/504, снапшотов нет |
| Старые страницы 2017 (Wayback) | найдены прямые per-year URL | **использованы для загрузки** (§1) |

**Причина:** релизы 2018+ распространяются только через браузерную страницу OECD/Data Explorer,
их файловых URL нет ни в открытом доступе, ни в архиве; SDMX ICIO не публикует. Это не
блокировка защиты, а отсутствие официального машинного канала.

## 3. Конвертация и D1

Парсер `tools/oecd_import.py` расширен раскладкой **ICIO 2016 matrix**: строки
`<ISO3>_<INDUSTRY>` + нижние строки `VA+TAXSUB` и `OUT`; колонки — промежуточный спрос
`<ISO3>_<INDUSTRY>`, конечный спрос `<PREFIX>_<ISO3>` (HFCE, NPS, GGFC, GFCF, INV, DIRP) и
колонка `DISC` (статистическое расхождение). Схема **`amfe.mrio.dataset.v1.1`**: `Z`, `x`, `va`,
`y` (без INV), `inventory_changes` (INV, может быть отрицательным), `discrepancy` (DISC).
Идентичности: `x = Z·1 + y + inventory_changes + discrepancy`; `x = 1'Z + va`;
`Σva = Σ(y + inventory + discrepancy)`.

Результат (`--convert --jobs 3`, затем `--d1`):

| Годы | Статус | Стран × отраслей | max abs column residual | D1 |
|---|---|---|---|---|
| **2000–2011 (12 файлов)** | **AVAILABLE** | 71 × 34 (n=2414) | 0,120–0,856 USD млн | **PASS** (row/col/global/неотрицательность) |
| 1995–1999 (5 файлов) | FAIL_D1 | 71 × 34 | — | **FAIL только non_negativity**: 1 отрицательная ячейка `y` (min **−912,02 USD млн**), остальное сходится |

Покрытие ВВП (12 датасетов): доля мировой ДС вне RoW — **95,35–95,47%** (гейт ≥80% — PASS),
кросс-проверка: **52 страны** сопоставлены с World Bank GDP (`data/mrio/wb/…`, соседний трек).
Пример 2011: датасет 29,15 МБ, SHA-256 `e74bd5ef…e806`, max |column residual| = 0,196 USD млн
при общем выпуске 139 182 202 USD млн (1,4·10⁻⁹).

## 7. Ограничения

- Скачанная редакция — **2016** (ISIC Rev.3, 34 отрасли, 1995–2011), а не 2025 (45 отраслей,
  1995–2022): это максимум, что доступно автоматически из официального архива.
- 1995–1999 не проходят D1 только из-за одной отрицательной ячейки конечного спроса
  (−912 USD млн); датасеты не записаны (fail-closed). Остальные 12 лет — D1 PASS.
- China/Mexico в редакции 2016 разделены на регионы (CN1–CN4, MX1–MX3); их конечный спрос
  консолидирован в национальных колонках CHN/MEX, поэтому у региональных строк `y` мал/нулевой
  — это свойство исходной таблицы, зафиксировано в `notes` датасета.
- Лицензия OECD Terms: тексты не читались автоматически, принятие — за пользователем.
- `src/amfe/mrio/schema.py` пока читает только v1; документы v1.1 пишет/валидирует инструмент.
- Не коммитилось, не пушилось; frozen-файлы, registry, чужие tools не изменялись.

# AMFE-17 — завершение учебного контура ступеней 4–7 этапа 2
Дата: 2026-11-11. Реализация: tests/test_sfc_accounts_v05.py. **Статус: учебный SFC-контур, не полные национальные счета и не завершённый этап 2.**

## Лестница 4–7
**4. Счета секторов:** для каждого из четырёх секторов ведутся подписанные финансовые позиции, товарные запасы фирмы, изменение чистой стоимости, изменение реальных активов и изменение чистых финансовых активов. Операции классифицированы: выпуск, зарплаты/трансферты/сборы, конечные покупки, кредит, облигации, проценты и погашение. Нет отдельной полной системы счетов производства, образования и распределения доходов по SNA 2008.
**5. Матрица и уравнения:** каждая проводка имеет парные финансовые записи; по каждому сектору ΔNW = ΔNFA + ΔRealAssets. Сумма финансовых позиций всех секторов = 0. Сумма ΔNW = Δinventory (поскольку других нефинансовых активов нет). Обязательно различать **нулевую сумму финансовых активов и обязательств** и **ненулевое изменение реального богатства**. Транзакционная матрица реализована как проверяемый набор типизированных проводок; явный табличный экспорт матрицы пока не реализован.
**6. Время:** остатки предыдущего периода становятся начальными остатками следующего; при переходе сохраняются долговые и депозитные позиции и товарный запас. Отчёт по каждому периоду содержит начальную и конечную чистую стоимость секторов и её изменение. Проверка второго периода: новый выпуск 0, потребление 10, изменение запасов −10, выпуск по расходам 0.
**7. Испытания:** тесты базового сценария, госдолга, двух периодов, десятичных дробей, атомарного отката и 432 комбинаций параметров. Локальный прототип с аналогичными уравнениями прошёл 6 отдельных тестов и 432 комбинации; GitHub-версия v05 содержит 5 тестовых функций, включая сетку. Удалённый CI пока не подтверждён.

## Счётные тождества
Финансовые позиции F имеют знак плюс для актива и минус для обязательства. Для сектора s:
NW_s(t) = Σ_a F_(s,a)(t) + I_s(t).
ΔNW_s = ΔNFA_s + ΔI_s.
Σ_s ΔNFA_s = 0.
Σ_s ΔNW_s = ΔI_firm.
Y_t = C_household,t + C_government,t + ΔI_t, где выпуск/потребление/запасы выражены в одной условной стоимости, цена = 1.
**Важное уточнение:** ΔNW в этой игрушечной модели — не полный показатель сбережений по SNA. Не применять формулы к внешней торговле, капитальным товарам, переоценке и иным реальным активам без расширения классификации.

## Проверка базового сценария
Кредит 100, выпуск 100, зарплата 100, потребление 70, прямой сбор 30, трансферт 10, госзакупки 15, проценты 5, погашение 50.
Конечная чистая стоимость: домохозяйства +40, фирмы −35, банки +5, государство +5; сумма +15 равна остатку товарных запасов. У фирмы ΔNFA = −50, ΔRealAssets = +15, ΔNW = −35.
Госдолг: банковская покупка облигаций государства на 20; проверяется нулевой остаток государственного депозита и долг −20.

## Критерии и ограничения
- Ступень 4: **условно пройдена для учебного примера**; полный план счетов SNA не готов.
- Ступень 5: **условно пройдена для заданных типов операций**; нет общего генератора матриц и расширенной типизации активов.
- Ступень 6: **пройдена для двух периодов**; динамическое поведение и оценка параметров отсутствуют.
- Ступень 7: **локальная проверка экспериментального алгоритма пройдена**; точное удалённое исполнение версии GitHub требует CI-подтверждения.
- V1: частичная формальная проверка. V2: NOT_APPLICABLE (нет реальных данных). V3: NOT_APPLICABLE (нет прогнозов).
- Непрерывная регрессия v01–v05 предусмотрена в GitHub Actions, статус удалённого запуска не подтверждён.

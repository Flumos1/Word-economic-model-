# 98. Калибровка мирового ядра на 19 рядах + V2

Дата: 2026-11-12. Инструмент: `tools/calibrate_world.py`. Отчёт:
`protocols/world_calibration.json` (`content_sha256` = `62a8eb1a…`). Тесты:
`tests/test_world_calibration.py` (19 тестов, `Ran 19 tests … OK`). Связанные документы: docs/85
(мировое ядро), docs/92 (калибровка этапа 2, 5 параметров), docs/42 (дорожная карта), docs/38
(классы механизмов и инварианты), docs/79 (физический слой), docs/84 (лицензионная гигиена).

**Статус: калибровка выполнена и воспроизводима; это стартовые значения для мирового ядра, а не
структурная оценка.** V1 пройден: детерминизм, только агрегаты, отсутствие сырых значений,
19/19 рядов покрыты, 20 параметров, 15 V2-проверок (PASS 7 / CONDITIONAL 3 / NOT_APPLICABLE 5).
V2: на данных держатся тождества роста и сбережений-инвестиций в разностях; уровневые тождества —
CONDITIONAL из-за цепной неаддитивности (как в docs/92); доходная сторона, номинальный слой,
капитал/энергия/IO и мировая агрегация — NOT_APPLICABLE по отсутствию рядов в плане.
V3 (OOS) — NOT_APPLICABLE: отчёт не прогнозирует. Базовый прогон `WorldCore` с
откалиброванной конфигурацией даёт детерминированный digest.

## 1. Что сделано

1. **Калибратор** `tools/calibrate_world.py` расширяет калибровку docs/92 на расширенный план
   v0.4.0 (19 рядов): доли C/I/G/NX, нормализованные доли физического слоя, темп роста
   (A191RL + кросс-проверка по GDPC1), три меры инфляции, рынок труда (PAYEMS/UNRATE,
   NAIRU-прокси), промышленное производство (INDPRO), розница (RSAFS), тренд выпуска на
   занятого. Только агрегаты: средние/разброс/мин/макс по окнам, OLS-коэффициенты и стандартные
   ошибки, корреляции, счётчики. Сырые ряды читаются из `data/raw` (git-ignored) и в отчёт не
   попадают — вместо них SHA-256 входных файлов.
2. **Отчёт** `protocols/world_calibration.json`: параметры с окнами/разбросом/источниками,
   маппинг в `WorldConfig`/`CountryConfig`/`PhysicalConfig`, производные агрегаты, 15 V2-проверок
   со статусами PASS/CONDITIONAL/NOT_APPLICABLE и порогами, `criteria.v2_thresholds`, источники
   (19 записей: ряд, файл, rows, first/last observation, SHA-256, register, licence_label),
   ограничения, следующие шаги, `content_sha256` (без `generated_at`) и базовый digest
   `WorldCore`.
3. **Базовый прогон world-core**: `WorldCore(config, baseline_scenario()).run(periods=8)`;
   страна A — калиброванная (US-прокси), страна B — прежний placeholder (не-US данных в плане
   нет). Записаны `config_sha256`, digest прогона, `ok`/`all_periods_ok`, число периодов.
4. **Тесты** `tests/test_world_calibration.py` (19): структура, детерминизм, content hash,
   отсутствие raw-значений, покрытие plan/licence, разумные диапазоны параметров, пересборка и
   валидность `WorldConfig`, три-статусный словарь V2, сбережения-инвестиции/рост/NAIRU-инфляция,
   NOT_APPLICABLE с причинами, digest и детерминизм world-core baseline, missing-data режим
   (PARTIAL) и строгий режим (ошибка), CLI, гигиенический сканер, самосогласованность
   закоммиченного отчёта.

## 2. Данные и окна

- План `protocols/data_plan.json` v0.4.0: 19 рядов, все с меткой OPEN-совместимой
  (`Public Domain: Citation Requested`) и якорем в реестре (ALFRED:\*, BEA_PRIMARY, BLS_PRIMARY,
  FRED_ALFRED_SERVICES); в отчёте — `register`, `licence_label`, `source` и SHA-256 файла.
- Окна: **baseline 1990Q1–2019Q4** (120 кварталов, допандемийный период), **recent
  2020Q1–2026Q3**, **latest20** — последние 20 кварталов, **NAIRU-прокси 2015-01…2019-12**.
  Месячные ряды приводятся к кварталам средним (уровни/ставки), квартальные — как есть.
  Пропуски FRED (`.`) отбрасываются, не заменяются нулём.
- **Latest tape, не PIT**: это калибровка уровня; REAL_TIME/PSEUDO-версия на винтажах — следующий
  шаг (плотный винтажный архив уже собирается, docs/75).

**сбережения-инвестиции в темпах**; уровневые тождества приближённы из-за цепного
индексирования (известное свойство, docs/92); **связь NAIRU-разрыва и инфляции слабая**
(t≈−1.1): простая кривая Филлипса на разрыве безработицы не идентифицируется, поэтому
`inflation_slope` — CONDITIONAL-прокси (0.058), а не структурная оценка. `V2_labour_activity`
CONDITIONAL по той же причине: занятость — запаздывающий индикатор.

## 6. Границы применимости

1. **Latest tape, не point-in-time**; REAL_TIME-версия стартовых значений — следующий шаг.
2. **Только US**: мировая агрегация NOT_APPLICABLE; страна B — placeholder.
3. **Нет доходной стороны** (оплата труда, валовая прибыль, налоги), часов/участия и капитала:
   доходно-расходное тождество, факторные доли и TFP не идентифицируются.
4. **Нет IO/энергетических данных**: физический слой мирового ядра остаётся со сценарными
   параметрами (docs/79, docs/85); калибровка их не заменяет.
5. **Нет номинального ВВП**: дефлятор — отношение, номинальное тождество не проверяется независимо.
6. **NAIRU-прокси и наклон Филлипса — описательные**, не структурные оценки; связь слабая.
7. **RSAFS номинальный**, PCECC96 реальный: корреляция отражает совместную динамику активности, не
   реальное тождество.
8. Калиброванные параметры — стартовые значения для ядра; базовый прогон — plumb-line, не прогноз.

## 8. Воспроизведение

```powershell
python tools/calibrate_world.py --out protocols/world_calibration.json
python tools/calibrate_world.py --skip-world-core --out <tmp>.json       # только диагностика
python tools/calibrate_world.py --allow-missing --out <tmp>.json         # missing-data режим
python -m unittest tests.test_world_calibration -v                       # 19 тестов
```

Сырые данные (`data/raw`) не коммитятся; отчёт воспроизводим при наличии локальной загрузки
(артефакт data-refresh, docs/75). Frozen-файлы и модули `src/**` не изменялись.

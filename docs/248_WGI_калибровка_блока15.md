## 1. Зачем

Правило владельца: **платные лицензии не используем, только открытые данные S1–S3** (docs/238).
Блок 15 (институты, docs/203) работал на иллюстративных `EXAMPLE-*`-профилях
(`source=ILLUSTRATIVE`, «геометрические примеры, не страны»). Это ограничение зафиксировано в
docs/203 §0 и docs/238; статус блока — `data_status=ASSUMPTION_BASED`, `not_calibrated=true`.

World Bank **Worldwide Governance Indicators (WGI)** — открытый источник (CC BY 4.0, атрибуция
обязательна, класс S1) с шестью измерениями, которые один-в-один совпадают с ключами блока 15:
voice/accountability, political stability, government effectiveness, regulatory quality, rule of
law, control of corruption. Поэтому WGI — естественный первый кандидат на калибровку **как
дополнительный режим**: текущие числа не трогаются, а пользователь может явно построить профиль
из WGI и увидеть те же сценарные каналы на откалиброванных индикаторах.

**Чего это НЕ делает:** не валидирует блок, не оценивает его веса/эластичности, не меняет
`admission`/`gating`, не делает блок «допущенной моделью» и не превращает WGI в фактическое
измерение институтов (WGI — восприятие).

### Замена кодов индикаторов (важно, честно)

В задаче названы «классические» коды `VA.EST`, `PS.EST`, `GE.EST`, `RQ.EST`, `RL.EST`, `CC.EST`.
При обращении 2026-11-26 API отдаёт их метаданные как **архивные** (`source = WDI Database
Archives`), и data-эндпоинт по ним возвращает «indicator not found». Актуальные WGI-ряды
публикуются под кодами **`GOV_WGI_*.EST`** (`source = Worldwide Governance Indicators`):
`GOV_WGI_VA.EST`, `GOV_WGI_GE.EST`, `GOV_WGI_RQ.EST`, `GOV_WGI_RL.EST`, `GOV_WGI_CC.EST` и
**`GOV_WGI_PV.EST`** для political stability (код `PS.EST` архивный; PV = political stability and
absence of violence). Соответствие шести измерениям блока — один-в-один, зафиксировано в
`WGI_INDICATOR_CODES` и `meta.code_note`; тест сверяет `meta.indicators` с константами модуля.

**Имя файла:** задача предлагала `worldbank_wgi_2023.csv`, но фактический последний полный год на
дату извлечения — 2025; пин назван `worldbank_wgi_2025.csv` (год в имени = году данных), чтобы не
было расхождения между именем и содержимым. Если Lead хочет 2023, это отдельное решение (данные за
2023 в API есть и также полные); текущий пин — 2025.

## 3. Формула и провенанс

Каждое WGI-значение переводится в блочную шкалу 0–100 линейно и клиппируется:

```
score = (value − WGI_SCALE_MIN) / (WGI_SCALE_MAX − WGI_SCALE_MIN) · 100
      = (value + 2.5) / 5 · 100,     затем score = max(0, min(100, score))
```

Проверки шкалы: −2.5 → 0, 0 → 50, +2.5 → 100, значения вне диапазона клиппируются (тесты),
нечисловые значения — отказ (`InstitutionError`). Это **не ранг и не перцентиль** — линейное
отображение WGI-оценки; WGI-оценки — восприятие, а не факт.

Провенанс: профиль `source="WGI_CALIBRATED"` хранит исходные значения, год и ISO3 в
`profile.wgi_provenance` (`iso3`, `year`, `raw_values`, `source_note`, `indicator_codes`).
В отчёты (profile.to_dict, scenario_overlay, run_all, modifier) попадают только:
0–100-индикаторы, `classification="WGI_CALIBRATED"`, `data_status="WGI_CALIBRATED_OPEN_DATA"`,
санированные `wgi_provenance` (iso3, year, source_note, коды индикаторов, шкала, лицензия,
атрибуция, `raw_values_in_report=false`) — **сырые WGI-значения в отчёт не попадают**; это
проверяется тестами (`no_raw_data`, отсутствие ключа `raw_values`, отсутствие repr-значений).
Блок при этом остаётся `not_calibrated=true` в смысле «не валидирован и не допущен»: калибровка
индикаторов ≠ валидация модели и не admission.

## 4. Как включить режим (аддитивно)

Новый API в `amfe.world.institutions` (все функции экспортированы в `__all__`):

```python
from amfe.world import institutions as ins

# шесть WGI-оценок (шкала примерно −2.5…+2.5)
profile = ins.profile_from_wgi(
    {"voice": 0.64, "stability": -0.30, "effectiveness": 1.19,
     "regulatory": 1.01, "rule_of_law": 0.79, "corruption": 0.87},
    iso3="USA", year=2025,
)
profile.source            # 'WGI_CALIBRATED'
profile.indicators        # 0–100 после формулы
profile.wgi_provenance    # сырые значения + год + ISO3 (только в памяти профиля)

report = ins.scenario_overlay(profile, ins.default_scenarios()[1])  # REFORM
report["data_status"]     # 'WGI_CALIBRATED_OPEN_DATA'
report["checks"]["no_raw_data"]  # True
```

- `InstitutionProfile.from_wgi(...)` — classmethod-обёртка; `profile_from_wgi` — модульная функция.
- `wgi_score(value)` — формула/клиппинг отдельно; `wgi_indicators_metadata()` — коды/шкала/лицензия.
- `WGI_SOURCE`, `WGI_INDICATOR_CODES`, `WGI_SCALE_MIN/MAX`, `WGI_LICENSE`, `WGI_ATTRIBUTION`,
  `WGI_DATA_STATUS`, `WGI_NOTES`, `PROFILE_SOURCES`.
- Конфиг-JSON (для `profile_from_config`): `{"name": ..., "indicators": {0–100}, "source":
  "WGI_CALIBRATED", "note": "...", "wgi_provenance": {...}}`; без `wgi_provenance` — ошибка; для
  `source=ILLUSTRATIVE/USER_INPUT` поле `wgi_provenance` запрещено.
- **По умолчанию ничего не меняется:** `EXAMPLE-*`-профили, `DEFAULT_WEIGHTS`, Simulator, CLI
  `tools/institutions_scenarios.py` и все существующие отчёты работают как раньше. CLI-флаг для WGI
  в этой задаче **не добавлялся** (границы: только `institutions.py`, тесты, data, docs) — если нужен
  пользовательский флаг `--wgi`, это отдельное решение Lead/следующая задача.

## 7. Ограничения

1. **WGI — восприятие, не факт.** Это агрегированные опросные/экспертные оценки качества
   управления; они не измеряют институты напрямую и не являются причинной величиной.
2. **Один год, нет PIT/винтажей.** Запинен только 2025 год; WGI-оценки пересматриваются между
   изданиями, а даты публикации/винтажи не моделируются. Для PIT-использования нужен архив
   изданий (отдельная лицензионная/инженерная задача), здесь его нет.
3. **Не полная панель.** 20 крупных экономик × последний год; это не покрытие «всех стран» и не
   временной ряд. `data/public/worldbank_wgi_2025.csv` — компактный агрегат, не bulk-выгрузка.
4. **Веса, эластичности и сценарии остаются допущениями A1–A10.** Калибровка индикаторов не
   калибрует модель: блок по-прежнему не валидирован, `admission=false`, `gating=false`,
   `not_calibrated=true` в смысле допуска. Нельзя заявлять «блок 15 откалиброван на страны» как
   допуск, рейтинг или доказанный эффект.
5. **Лицензионные обязанности:** CC BY 4.0 требует атрибуции World Bank в любом использовании;
   значения не перепродаются; в отчётах блока сырые значения не публикуются (только производные
   баллы и провенанс). Значения — сторонние, но открытые (S1); платные лицензии не использовались.
6. **Режим не подключён к CLI/Simulator по умолчанию** — это дополнительный программный API;
   автоматического переключения нет (защита текущего поведения).
7. **`GOV_WGI_*` vs старые коды:** используем текущие коды; если Lead предпочтёт архивные
   `VA.EST/PS.EST`, данные придётся брать из WDI Database Archives (другой источник/лицензионная
   проверка) — сейчас это сознательно не делалось.

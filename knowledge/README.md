# AMFE — четыре исследовательских реестра
Версия 0.1 · 2026-11-10

Этот каталог содержит четыре **раздельных, но связанных** накопителя знаний:
1. `literature/` — научная библиотека (источники и библиография).
2. `ideas/` — банк идей и гипотез, включая неиспользованные и отвергнутые.
3. `methods/` — энциклопедия математических и исследовательских методов.
4. `research/` — лаборатория исследований, опросов, мозговых штурмов и AI-агентов.

## Общий стандарт
У каждой записи: устойчивый ID, название, дата создания и обновления, происхождение/автор, статус, теги, связи с другими ID, уровень уверенности, ссылка на первоисточник или диалог, ограничения и история изменений. Никакое предложение не становится научным фактом только из-за генерации ИИ.

## Граф знаний
Узлы: Источник (LIT), Идея (IDEA), Метод (METH), Эксперимент (EXP), Результат (RESULT), Решение (D), Вопрос (Q), Переменная (VAR), Экономическая связь (EDGE).
Рёбра: поддерживает, опровергает, мотивирует, использует, проверяет, заменяет, относится-к, зависит-от. Хранить доказательную цепочку от источника до решения.

## Политика сохранения
Сначала фиксировать оригинальную мысль и контекст, затем интерпретацию. Не стирать старые записи: статус «отклонена» или «отложена» не равен удалению. Не хранить защищённые авторским правом полные тексты без разрешения. Для DOI/URL сохранять метаданные, аннотацию собственными словами и дату проверки.

## Начальная стадия
Git Markdown/CSV — человекочитаемый первичный реестр; позже возможно перенести индекс в PostgreSQL, графовую БД и векторный поиск, сохранив идентификаторы и Git-историю. Реестры являются архитектурной заготовкой, не уже действующей автоматической исследовательской системой.

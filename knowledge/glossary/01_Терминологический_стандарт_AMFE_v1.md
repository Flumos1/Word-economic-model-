# AMFE — терминологический стандарт и устранение неоднозначностей
Версия 1.0 · 2026-11-11. Дополняет, но не переписывает исторический glossary/README.md.

## Правило терминологии
Термин = {term_id, preferred_ru, preferred_en, definition, domain, unit_or_type, non_equivalences, examples, status, source_refs, revision}. Не смешивать обыденное, философское, статистическое и математическое значения. Одинаковые названия в разных дисциплинах — отдельные понятия с квалификатором.

## Нормативные различения
| Предпочтительный термин | Операциональное определение | НЕ отождествлять |
|---|---|---|
| Онтология предметной области | типы экономических сущностей, отношений и допустимых состояний | с философским учением о бытии |
| Эпистемический статус | состояние доказательной поддержки утверждения в области | с процессом исследования и разрешением на эксплуатацию |
| Контекстный научный допуск | решение об использовании утверждения для конкретной научной цели | с истинностью или новизной |
| Эксплуатационный допуск | разрешение использовать конкретную модель в прогнозном ядре | с признанием причинной теории |
| Гипотеза | явно сформулированное проверяемое утверждение | с «непроверенным фактом» |
| Научное объяснение | ответ на почему/как с явными основаниями и границами | с точностью прогноза |
| Причинная идентификация | определимость эффекта вмешательства при допущениях | с корреляцией или хорошим прогнозом |
| Наблюдательная эквивалентность | неразличимость моделей по заданному классу наблюдений | с логической или причинной эквивалентностью |
| Структурная согласованность | выполнение определённых ограничений, балансов и агрегаций | с эмпирической истинностью или причинностью |
| Тождество | равенство, следующее из согласованных определений и правил учёта | с оценённой эконометрической закономерностью |
| Эмпирическая регулярность | статистически обнаруженная зависимость с областью применимости | с неизменным законом |
| Запас (stock) | величина состояния на момент времени | с потоком за период |
| Поток (flow) | количество/стоимость за временной интервал | с запасом на дату |
| Изменение запаса | разность состояний, связанная с потоками, переоценкой и другими изменениями | с одним только чистым потоком |
| Валовой/чистый поток | до/после вычета определённой встречной величины | с номинальный/реальный |
| Номинальный/реальный показатель | денежная оценка в текущих ценах / скорректированная на цены согласно методу | с физическими единицами |
| Измерительная невязка | расхождение наблюдаемых/оценённых величин с идеальным учётным равенством | с логическим опровержением тождества |
| Калибровка прогноза | соответствие заявленных вероятностей эмпирическим частотам в определённом протоколе | с точностью точечного прогноза |
| Воспроизводимость вычисления | повторение анализа с теми же данными/кодом/условиями | с независимой репликацией на новых данных |
| Независимая репликация | отдельная проверка с оценённой независимостью данных и процедуры | с несколькими агентами, цитирующими один источник |
| Происхождение (provenance) | цепочка происхождения и преобразования данных, доказательств и выводов | с библиографической ссылкой как таковой |
| Винтаж данных (data vintage) | версия данных, доступная на определённую дату | с датой наблюдаемого периода |
| Структурный сдвиг | изменение порождающего механизма/параметров относительно заданной модели | с обычным случайным шумом |
| Мера (философская, AMFE) | рабочая гипотеза о соотношениях, ограничениях и переходах состояний | с мерой в теории меры |
| Мера (математическая) | счётно-аддитивная функция на σ-алгебре с неотрицательными значениями (в стандартном случае) | с философской «мерой» |
| Уровень анализа | микро/мезо/макро по явному правилу агрегации | с административным уровнем без определения |
| Согласование прогнозов | преобразование прогнозов для выполнения заданных агрегационных ограничений | с причинной валидацией |

## Выявленные исправления
1. В docs/12 статус UNDER_REVIEW и в docs/29 warrant UNDER_REVIEW неоднозначны; docs/31 определяет отдельно жизненный цикл, эпистемический вердикт и допуск. Считать docs/31 нормативным словарём статусов; прежние записи сохранять как исторические.
2. В docs/29 «контекстно обоснованное положение» — характеристика поддержки, а не универсальное разрешение использования; разрешение всегда отдельное.
3. В docs/31 «исполняемый протокол» — **операциональная спецификация**, не готовое ПО. Не писать «проверено программно».
4. В glossary/README.md формулировка «фальсифицируемость = допускает опровергающее наблюдение» требует указания вспомогательных предпосылок и правил измерения; одиночный аномальный факт не всегда опровергает целую теорию.
5. «Воспроизводимость» и «репликация» имеют разную конвенцию в дисциплинах: AMFE фиксирует значения выше как внутренний стандарт, не претендуя на единственно возможное употребление.
6. Философская «мера» — кандидатная концепция AMFE, не закон физики и не математическая аксиома.
7. Слово «доказательство» использовать строго: формальное доказательство — вывод из аксиом; эмпирическая поддержка — не дедуктивная доказанность.
8. «Уверенность» без уточнения запрещена: указывать субъективную вероятность, доверительный интервал, степень доказательной поддержки либо оценку качества данных.

## Соглашения для математической архитектуры
Индексы i,j — экономические агенты/секторы; c — страна; k — товар/отрасль; t — момент; [t,t+Δt] — период; u — единица; v — дата публикации винтажа; s — сценарий. Каждая величина получает metadata: {unit, currency, price_basis, geographic_scope, sector_scope, time_reference, vintage, source, uncertainty, accounting_convention}. Символы закрепляются в конкретной модели; не объявлять их универсальными во всех моделях.

## Контроль качества определений
Определение проходит проверку, если (a) не циклическое; (b) различает соседние понятия; (c) содержит область; (d) задаёт операциональные последствия; (e) отделяет историческое/рабочее определение; (f) приписываемый источник проверен на нужном уровне. Неустранённые случаи маркировать OPEN, а не подменять уверенной формулировкой.

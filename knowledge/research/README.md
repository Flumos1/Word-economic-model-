# EXP — исследовательская лаборатория
Исследовательский цикл: вопрос → поиск литературы → конкурирующие гипотезы → протокол → предрегистрация метрик и теста → эксперимент → независимая критика → результат → решение → архив.

## Предложенные AI-роли
1. **Библиограф**: поиск и проверка первоисточников, DOI, лицензий.
2. **Генератор гипотез**: альтернативные механизмы и объяснения.
3. **Математик**: формализация, размерности, идентифицируемость.
4. **Скептик/редтим**: контрпримеры, ошибки, data leakage.
5. **Экспериментатор**: воспроизводимый дизайн, baselines, метрики.
6. **Арбитр**: протокол разногласий и решение о следующем тесте.

Модели/агенты могут разделять ошибки и обучающие данные; число согласных агентов не является мерой истины. Каждый существенный вывод проверять первоисточником, формальной проверкой или независимыми данными.

## Дополнительные исследовательские механизмы
- Delphi-подобные раунды независимых экспертных оценок с контролируемой обратной связью.
- Опросы и прогнозные турниры с проверкой калибровки и последующей оценкой.
- Мозговой штурм с обязательным этапом фальсификации.
- Конкурирующие протоколы, preregistration, negative-results registry.
- Анализ ценности следующего исследования с учётом цены данных и вычислений.

## Публичные архитектурные аналоги
Изучать Palantir Ontology (data–logic–action–security), а также открытые подходы к научным workflow, knowledge graphs и provenance. Не считать внутренние методы коммерческих платформ общедоступными и не утверждать, что их можно воспроизвести без лицензии.

## Первые экспериментальные задачи
- EXP-001: проверить, улучшают ли данные о морских перевозках прогноз инфляции на 6 месяцев.
- EXP-002: сравнить MRIO-показатели связности с простыми торговыми агрегатами.
- EXP-003: сравнить гипотезы от нескольких агентов с гипотезами одного агента по качеству последующих проверок.
- EXP-004 (добавлено 2026-11-11, исходный вопрос диалога): оценка прогнозных утверждений источников «альтернативных школ» (бюллетень «Итоги недели» фонда Хазина и др.). Дизайн: выборка выпусков без отбора по яркости; извлечение утверждений до просмотра исходов, с дословной цитатой, датой, ссылкой и хешем архивной копии, двойной кодировкой; деление на факт, интерпретацию, прогноз; для прогнозов — направление, масштаб, срок, условность; правила разрешимости до оценки; оценка по строгим правилам, где указана вероятность, иначе доля попаданий с доверительным интервалом (Вильсона) и отдельным счётчиком неразрешимых утверждений; сравнение с простыми базовыми, МВФ и SPF; проспективная ветка: захват новых выпусков с сегодняшнего дня в журнал будущих прогнозов. Проверить условия сайта и авторские права при хранении текстов. См. docs/59 G1, G7.
Статус всех: **предложены, не запускались**.

# LIT — научная библиотека и библиография
Каждая запись: LIT-ID, полная ссылка, авторы, год, DOI/ISBN/URL, тип публикации, журнал/издательство, доступ/лицензия, ключевые положения, методология, ограничения, статус проверки, цитирования, связанные IDEA/METH/EXP.

**Правила:** отделять первичную работу от вторичного обзора; отмечать рецензирование, исправления/ретракции и конфликтующие результаты; не выдавать наличие метаданных за чтение полного текста. Приоритет — проверяемые оригинальные источники.

## Проверенные стартовые ресурсы (документация)
- LIT-001: OpenAlex API, https://help.openalex.org/api/ — научные публикации, авторы, организации, темы; документация проверена 2026-11-10.
- LIT-002: Crossref REST API, https://www.crossref.org/documentation/retrieve-metadata/rest-api — библиографические метаданные, DOI, лицензии, обновления; документация проверена 2026-11-10.
- LIT-003: Palantir Platform overview, https://www.palantir.com/docs/foundry/platform-overview/overview/index.html — концепция Ontology: данные, логика, действия; публичная документация, не доказательство превосходства технологии; проверено 2026-11-10.
- LIT-004: Palantir Ontology system, https://www.palantir.com/docs/foundry/architecture-center/ontology-system — объекты, связи, решения, безопасность; публичная документация; проверено 2026-11-10.
- LIT-005: NIST AI RMF Generative AI Profile, https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence — управление рисками генеративного ИИ, 2024; проверено 2026-11-10.

**Дальнейшие направления поиска:** Леонтьев и MRIO; OECD ICIO, WIOD, Eora, EXIOBASE; SFC, динамические факторные модели, Kalman, вероятностное прогнозирование, каузальный вывод, активное обучение, design of experiments, прогнозные турниры. Это темы для отбора, а не уже проверенная библиография.

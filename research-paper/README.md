# AMFE — научная рукопись и история научного рассуждения
Дата: 2026-11-10. Статус: исследовательская заготовка, не опубликованная статья и не диссертация.

## Цель
Вести AMFE как воспроизводимую научно-исследовательскую программу, сохраняя не только выводы, но и последовательности рассуждений: постановка проблемы → исходные предпосылки → гипотезы → формализация → методы → эксперимент → критика → вывод → пересмотр.

## Принцип научной преемственности
Каждый существенный вывод должен иметь прослеживаемую историю возникновения, обоснования, проверки и пересмотра. Сохранять оригинальные формулировки при наличии, различать цитату и парафраз, фиксировать происхождение, даты, версии, альтернативы, возражения, отрицательные результаты и степень уверенности.

## Правила научной добросовестности
- Концепция не равна подтверждённой теории.
- Строгая формула не заменяет проверку допущений и эмпирическую валидацию.
- Новизна требует систематического сравнения с предшествующей литературой.
- Научный прорыв — возможный результат, не исходное утверждение.
- Не использовать язык «доказано», «впервые» и «универсально» без оснований.
- ИИ-генерированные гипотезы и тексты требуют проверки человеком и источниками.
- Не удалять конкурирующие объяснения, ограничения и отрицательные результаты.

## Связь с главной линией
Это **сквозной научный артефакт**, не новый основной этап. Ближайший основной этап: методология научного исследования AMFE (см. docs/08). Рукопись пополняется параллельно, по мере подтверждения результатов.

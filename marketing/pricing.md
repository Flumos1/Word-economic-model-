# Ценообразование и офферы

Все цены — **ориентиры для пилота в РФ**, требуют подтверждения на discovery. Валюта — RUB,
без НДС; скидки только за счёт объёма/срока.

| Оффер | Что входит | Срок | Цена, ₽ |
|---|---|---|---:|
| **Диагностика** | 1 встреча, разбор 2–3 решений, one-pager с рамкой | 1 неделя | 0 (бесплатно) |
| **Пилот: сценарии** | 1–2 категории/решения, база + 2 стресса, Excel/PDF/JSON, воркшоп | 4–6 недель | 600–900 тыс. |
| **Пилот: закупки (FLAKS)** | 2–4 категории, TCO/риск/бюджет, анонимизация, CFO-отчёт | 4 недели | 600–900 тыс. |
| **Полный сценарий** | 3–5 сценариев, страна/отрасль/логистика, API/Excel, 2 воркшопа | 8–12 недель | 1,8–2,7 млн |
| **Подписка** | обновления, 2–4 сценария/квартал, поддержка, API | 12 мес | 2–8 млн/год |
| **API-интеграция** | ключи, квоты, OpenAPI, SLA-заготовка, 1 интеграция | 4–8 недель | 1,5–3 млн + подписка |

## Логика

- Пилот должен быть **дешевле внутренней альтернативы** (2–3 недели аналитика + консультант).
- Цена привязана к **решению**, а не к числу прогнозов: чем дороже ошибка, тем выше ценность.
- В пилот не входит покупка сторонних данных (Consensus/Platts/ICE) — оплачивается отдельно или
  заменяется публичными агрегатами.
- Данные клиента не хранятся дольше проекта; NDA; удаление по запросу.

## Что не обещаем

- «Точность выше рынка» — нет допущенной модели; продаём прозрачность/скорость/аудит.
- «ЗаменаBloomberg/WoodMac» — нет; дополняем там, где нужен свой сценарий и закупочный контур.
- «Гарантированную экономию X%» — считаем на данных клиента, без гарантий.
